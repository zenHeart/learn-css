# 暗黑模式

##  采用 css 全局变量
1. 定义两套变量表示亮和暗两个模式
2. 采用 [prefers-color-scheme](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-color-scheme#Examples) 设置亮暗模式
3. 在 chrome 下,查看 [stackoverflow](https://stackoverflow.com/questions/57606960/how-can-i-emulate-prefers-color-scheme-media-query-in-chrome) 切换模式
