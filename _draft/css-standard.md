# css 规范简述

## 规范历史简述

## 规范状态于推荐过程
1. `working draft` 草案阶段,被接受为 css 组成部分,社区评审中
	> 工作草案发展到下一阶段之前,状态会修订为 `Last Call` 代表文档审核周期即将结束
2. `candidate recommendation` 推荐标准,草案审核通过后会变为此阶段,此时浏览器厂商会开始实现文档中的属性,收集现实世界的反馈
3. `Proposed Recommendation` 当两个或多个浏览器以相同方式实现了这些属性,并且没有抛出严重的技术问题达到此阶段
4. `recommendation` 该提案被 W3C 顾问委员会批准通过,则成为推荐标准

> **推荐过程与实现过程并不总是以相同的方式运作**
