# selector

**css 选择器详解**

---


## 选择器特殊性 (selector specificity)
选择器特殊性叫做 **selector specificity** .
当采用不同选择器在一个元素上申明相同 css 属性时,
浏览器为了解决哪个 css 规则被采用定义的一套规范.


### 概念
不同选择器在设定元素属性时具有不同权重,
权重等级如下:

* 内联选择器权重为 `1,0,0,0`
* id 选择器权重为 `0,1,0,0`
* 类选择器,属性选择器,伪类选择器 `0,0,1,0`
* 元素选择器,伪元素选择器权重为 `0,0,0,1`


此外还有如下规则

* 通用选择器 `*` 没有权重
* 结合符对选择器没有贡献
 
范例参考 [selector specificity](../../tests/selector-specificity.html)

## 选择器类型
* **简单选择器** 
* **属性选择器** 
* **伪类选择器** 状态,位置
* **伪元素选择器** 
* **接合器选择器**
* **多位选择器**

### 简单选择器
常用的包含如下几种。

* **元素选择器** 利用标签名选择
* **类选择器**
* **id 选择器**
	> 出现同名 id 选择器时,有一些浏览器只会是被第一个 id 元素,忽略剩余元素
* **通用选择器**

### 属性选择器
属性选择器基于属性及值搜索元素。
典型的属性选择器包含如下几种。
* **[attr]** 包含此属性值的元素均会被选中
