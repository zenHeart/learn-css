选择器特殊性
====

**讲解 css 选择器特殊性规则**

----


## 概述
选择器特殊性叫做 **selector specificity** .
当采用不同选择器在一个元素上申明相同 css 属性时,
浏览器为了解决哪个 css 规则被采用定义的一套规范.


## 概念
不同选择器在设定元素属性时具有不同权重,
权重等级如下:

* 内联选择器权重为 `1,0,0,0`
* id 选择器权重为 `0,1,0,0`
* 类选择器,属性选择器,伪类选择器 `0,0,1,0`
* 元素选择器,伪元素选择器权重为 `0,0,0,1`


此外还有如下规则

* 通用选择器 `*` 没有权重
* 结合符对选择器没有贡献
 
范例参考 [selecotor specificity](../../demo/selector-specificity.html)
