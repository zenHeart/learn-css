# 盒模型

## 盒模型定义
盒模型定义了 css 如何转换文档树中的元素.

## 盒模型的结构
参考 [css 2.2 盒模型](https://www.w3.org/TR/CSS22/box.html#box-dimensions) 盒模型结构如下:


![](https://www.w3.org/TR/CSS22/images/boxdim.png)

整个盒模型由内到外被四种类型的边框包围
1. **内容框(content edge)**
2. **内边距框(padding edge)**
3. **边线框(border edge)**
4. **外边线距(margin edge)**


除了内容边框,其余的边框又可细分为上下左右四部分,例如内边距边框可细分为
* 上内边距(Top padding) 简写为 **TP**
* 右内边距(Right padding) 简写为 **RP**
* 下内边距(Bottom padding) 简写为 **BP**
* 左内边距(Left padding) 简写为 **LP**

查看 [盒模型示例](./examples/box-model.html)
