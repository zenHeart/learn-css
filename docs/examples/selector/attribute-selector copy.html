常用属性选择器

  1. element[attr]匹配包含属性名的元素

  2. element[attr=value]匹配包含属性名,且值等于 value 的属性

    1. value 的值的外部可以不带引号,也不区分单引号和双引号

  3. element[attr~=value]匹配包含属性名,且属性的值是以空格分隔的一系列值,其中包含value 元素

  4. element[attr|=value]匹配包含属性名,其属性值以 value 开头并连接 - 符号

    多用于语言匹配例如 span[lang|=en] english

  5. element[attr^=value]匹配包含属性名且以value开头的元素

  6. element[attr*=value]匹配包含属性名且值中包含 value 的元素

  7. element[attr$=value]匹配包含属性名且值以value结尾的元素

  8. element[attr operator value i]匹配包含元素且按照匹配值且忽略值的大小写的元素
