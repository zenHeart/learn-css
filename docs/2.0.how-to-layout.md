## 引言
笔者在使用 CSS 的初期一直存在如下困惑？
1. 块级元素和块级盒有什么区别？
2. 块容器，包含块是什么意思？
3. 块格式化语境和行内格式化语境是如何产生的？
凡此种种于是笔者仔细研读了 CSS2.2 总结了如下知识，希望能让大家更好的理解 css 布局的概念！

## 基本概念
把网页显示想象成报纸的印刷过程，`元素(element)`就是报纸上面的内容，`盒模型(box model)`就是元素内容的空间。
`包含块(containing block)`类似于板块，包含了不同的内容。视图就是整张报纸。而视觉格式化就是，在编辑
编写好内容(html),美工设计好排版(css)后，印刷机器`浏览器(user agent)`将它打印在白纸`(view point)`上面的操作。
理解了以上概念，再看一下实际的视觉格式化过程。

在浏览器生成了 html 元素的文档树结构后，根据 CSS 来生成每个元素的盒模型。主要考虑一下几个方面。
1. 每个盒子的大小和类型
2. 每个盒模型在视图中的位置
3. 视图的尺寸或其他参数对盒子的影响

这里有几个难点:
1. 对于嵌套的文档树如何解决父元素尺寸的确定
2. 子元素的相对位置参考系是谁

考虑到这些问题，包含块的概念就体现的尤为重要。
因为盒模型只是说明了单个元素的呈现方式，并没有指出嵌套元素之间父级元素的内容区如何确定大小。
而有了包含块的概念，就实现了元素呈现的堆叠特性。比如下面的例子：

```html
<!DOCTYPE HTML>
<HTML>
   <HEAD>
      <TITLE>Illustration of containing blocks</TITLE>
   </HEAD>
   <BODY id="body">
      <DIV id="div1">
      <P id="p1">This is text in the first paragraph...</P>
      <P id="p2">This is text <EM id="em1"> in the 
      <STRONG id="strong1">second</STRONG> paragraph.</EM></P>
      </DIV>
   </BODY>
</HTML>
```
上面代码的包含块结构如下：

盒模型|包含块|
:---:|:---:|
html|视图区，用户代理决定
body|html
div1|body
p1|div1
p2|div1
em1|p2
strong1|p2

有哪些盒类型，这是由`display`这个选型决定的

参数|含义|
:---:|:---|
block|前后产生空行的盒
inline-block|内容区是盒模型，相对于父元素为行内盒
inline|元素为行内盒
list-item|产生内容盒和标记盒
none|元素不产生盒模型
table...|关于表布局的盒模型

注意这个地方的对应关系，在html规范中定义了每种元素的类型而 css 也规定了盒模型的各种类型。
[html 元素类型](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Element)
它们两个的区别在于前者为内容的模型后者为布局的方式。   

## 块级盒
块级盒有如下几种
1. html 块级元素比如`div`、`p`
2. display 属性被设置为`block`、`list-item`、`table` 的元素

### 块容器
除了表格和替换元素，其余块级元素都是块容器。它的作用是用来包含多个块。
1. 块容器只包含块元素时，为块级格式化
2. 只包含行内元素时为行内格式化。


行内格式化
不包含块盒的块容器会创建行内格式化环境。在行内格式化语境中，盒子从包含块顶端一个接一个的水平排列。



### 行内格式化环境   
行内格式化环境有由块容器和建立。

这些元素都会按照块格式化环境进行布局

## 视觉格式化模型
当采用 html 编写好文档结构时,浏览器如何依据 css 的规则来渲染文档内容呢?
根据 css 规范,浏览器会将文档中的每个元素转换为一个个盒子,而这套将元素装换为视图盒的规则即为视觉格式化模型。

决定元素盒的布局有如下因素决定。
* 盒子的尺寸
* 盒子的类型,规范中包含如下典型类型
  * 行内盒子(inline)
  * 行内级盒子(inline-level)
  * 原子行内级盒子(atomic inline-level)
  * 块盒子(block)
* 定位的方案(positioning scheme)
  * 普通流布局
  * 浮动定位
  * 绝对定位
* 文档树中其他元素:该盒的子元素或兄弟元素
* 视口尺寸与位置
* 所包含的图片的尺寸
* 其他的某些外部因素

若出现嵌套关系,则父元素的内容区作为子元素布局空间(包含块),但是子元素大小不受父元素空间限制,当子元素超出父元素布局限制时称为溢出。

## 术语表
* `块(block)` 抽象概念,在文档流中一个独立的布局区域,块与块在垂直方向上一次堆叠
* `包含块(containing block)` 包含其他盒子的块称为包含块
* `盒子(box)` 一个布局抽象概念
  > 注意盒子和元素不一定是一一对应,有时多个元素会生成一个盒子,有时一个元素会生成多个盒子(如匿名盒子)

## 什么是布局
每当打开一个网页的时候，每个网页都会有自己组织能容的方式，布局就是一门呈现内容的艺术。   
在组织你的页面的时候，一个好的布局可以加大的提高页面的可维护性，整个过程我将概括为以下几步:
1. 划分页面结构(切图)   
2. 更具结构实现布局   
3. 对每个单独结构进行修饰
4. 组合

## 页面布局   
页面布局就就是内容块的划分与排列。再细化步骤如下:
1. 确定块大小   
2. 确定块位置   
3. 组合排列   

上面的步骤很简单，但是会涉及很多 CSS 规范中的坑。

### 理解文档流
写尽量少的好代码。这个原则要求你会利用文档布局特性，不要做浏览器本来就会去做的事情。  
换句话说在布局之前，因该知道文档流本就有自己的排列规则。在利用已有规则的情况下符合设计要求。

## 布局类型

典型的布局风格,包括
* **正常的布局流** 采用用户代理默认布局行为进行布局
* **flexbox** 流式布局
* **grids** 栅格布局
* **floats** 浮动布局
* **position** 定位布局
* **multiple-column** 多列布局
* **legacy layout** 遗留的布局系统
