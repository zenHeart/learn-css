# column
使用 column 实现多栏布局。


## 概述
在报刊和杂志上可以看到两栏或三栏的图文布局。
使用 column 相关属性可以达到同样的效果。





## 属性列表




### column-count
控制列的数量 

1. 会产生新的 BFC ,不出现 margin 塌陷。


问题:
* [ ] 只有首列有 margin
* [ ] 列跟换的规则
* [ ] 空隙计算的规则

### column-width
限制列的最小宽度,浏览器会根据容器宽度,平均分配各列


### columns
结合 `column-count` 和 `column-width` 简化列的设置

> **注意容器的宽度表示的是最小可允许宽度,实际宽度会大于此值**


### column-gap
设置列的间隙,默认为 `1em`

通过容器宽度可以精确设定各列的宽度。

### column-style
设置每列的边栏样式
