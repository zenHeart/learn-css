## 属性选择器

属性选择器基于元素的属性进行匹配的选择器。
常用选择器如下:

-   **[attr]** 包含此属性值的元素均会被选中
-   **[attr=value]** 包含属性且属性值等于 value 的元素
-   **[attr~=value]** 包含属性且为以空格分隔的值中包含 value 的元素
-   **[attr|=value]** 包含属性且值已 value 开头后接 `-` 的元素
    > 多用于语言属性的选择
-   **[attr^=value]** 包含属性且属性值以 value 开头的元素
-   **[attr*=value]** 包含属性且属性值中有 value 的元素
-   **[att$=value]** 包含属性且属性值以 value 结尾的元素

额外的特性包括

-   **[attr operator value i]** 其中 i 为修饰符表示忽略对值大小写的比较,例如 `a[href="TEST" i]` 匹配超链接中包含 `TEST` 的字符其中忽略大小写。参看例子 [属性 i](./examples/selector/ignore-case-selector.html)
