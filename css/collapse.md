## 塌陷原因分析
塌陷可以理解为包含块高度异常。包含块的概念如下:

每个元素都有自己的盒模型，当多个盒模型存在嵌套关系时，就会产生包含块。它是指内部元素的父元素内容区。   
CSS 规范中指出，包含块是决定元素的布局和定位的外部边界。   

之所以发生异常就是在包含块的高度没有赋值的情况下，子元素的尺寸没有触发父元素的尺寸变化。
阅读 css 规范发现如下内容。[块元素高度确定](https://www.w3.org/TR/CSS22/visudet.html#root-height)

![](../img/css_collapse3.png) 

1. 绝对定位元素在计算包含块高度时会被忽略。   
2. 此外，如果元素有任何浮动后代元素，子元素下底边缘低于父元素内容的底部，高度将会自动扩张包含这个底部。
但是只有当该父元素本身也包含浮动的时候才会成立。对于父元素内部的浮动和绝对定位或者其他的非该父元素的浮动都不起作用。  

先看第二句，告诉了我们在父元素内部包含浮动元素的情况下，父元素的高度不会扩张除非父元素本身也包含浮动。
先验证一下。参看如下示例:   

[利用父元素浮动特性清除塌陷](http://jsrun.net/ntKKp?uid=530)

![](../img/css_collapse4.png) 

可以看到父元素的浮动被清除，注意代码中 body 元素也存在塌陷所以也使用了清除。   
可是我们看到这么操作又产生了新的问题，父元素的宽度不在是视图宽度。此外手册也并没说明绝对定位产生塌陷的解决方法。
暂时先忽略这些问题，让我们看一下解决浮动还有那些方案：[方法汇总示例](http://jsrun.net/CtKKp?uid=530)
1. 利用伪类清除浮动   
原理：利用`clear:both`在浮动框下生成了一个空的子元素块，扩张了父元素的下边界。
2. 在浮动元素下添加清除浮动框   
原理:是第一种方法的变式   
3. 利用溢出属性清除浮动   
原理:`overflow:auto`告知代理溢出，由用户代理处理
4. 父元素浮动清除溢出   
原理:根据规范实现的防止塌陷，但是这种行为可能会导致该父元素的祖先塌陷。所以不建议使用，这里只是为了验证规范中的内容。
5. 父元素高度赋值   
6. 父元素变为行内元素清除浮动   
原理：行内元素框的计算方式不同于块元素，不会出现溢出
7. 父元素变为表格清除浮动   
原理：和方法 6 差不多，也是改变了包含块的计算方式  

这里由于`2、4、5、6、7`对父元素的结构造成了破坏，不建议使用。
所以实际上有两种方法：
1. 利用父元素添加空伪类来清除浮动
2. 利用`overflow`来清除伪类   

第一种很好理解基于子元素让父元素自动填充
第二种就不好理解了，为什么`overflow`可以让父元素不塌陷，通过阅读 css 规范找到了如下内容。

![](../img/css_collapse5.png)
翻译如下:

浮动元素、绝对定位元素、块的容器(例如行内块、单元格和表头)都不是块状盒，当块状盒的`overflow`属性值
不是`visible`时(排除这个值被传播到视图窗口的情况)，将会针对其中的内容建立一个新的块格式化环境。

在一个块格式化环境中，盒子从包含块的顶端一个接一个的垂直排列。
两个兄弟盒之间的垂直距离，由`margin`属性决定。相邻的两个块级盒之间会出现合并。   

在块格式化环境中，每一个盒子的左边缘挨着包含块的边界(对从右到左的格式，右边界接触)。
这种情况在存在浮动的时候也成立(尽管盒子边界可能由于浮动产生收缩)，除非该盒子又建立了一个新的格式化环境。
(在这种情况下，盒子可能变窄由于浮动)
...

可以看到文档中明确说明当**采用`overflow`属性时会生成新的格式化环境**。
这是一个非常重要的知识点。由于生成了新的格式化上下文，盒模型的计算方式发生了改变。   


 
下面再看一下绝对定位塌陷的解决办法:
1. 父元素改为相对定位，子元素设定与父元素低端距离
2. 父元素相对定位，并设定包含子元素的高度

规范中已明确说明父元素中包含绝对定位元素时，该元素会脱离文档流。
这意味绝对定位不会使父元素的尺寸发生变化。所以在使用绝对定位时最好指定，父元素的高度。
或者在绝对定位中加入相对于父元素底边的偏移，使父元素的尺寸得以扩张。

## 浮动和绝对定位的区别
虽然这两种方式都产生了父元素在尺寸上的塌陷，但是又存在差别。看下面两张图:

1. 浮动塌陷
![](../img/css_collpase1.png) 
2. 绝对定位塌陷
![](../img/css_collapse2.png) 

根据绝对定位的元素会脱离文档流。不占据空间，所以可以看到图2中的底栏和父元素之间形成了重叠。
而浮动塌陷中，属于父元素的左栏对底栏的空间产生了侵蚀。造成底栏的文本流相对与正常位置出现了下移。
这里说明了如下特点:   
1. 浮动元素会使块级元素表现出流式元素的特点。
2. 块级元素不属于正常文档流，不会对别的元素产生侵占。
