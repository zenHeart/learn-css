# 布局

**详细讲解 css 各种布局**

---


## 什么是布局
每当打开一个网页的时候，每个网页都会有自己组织能容的方式，布局就是一门呈现内容的艺术。   
在组织你的页面的时候，一个好的布局可以加大的提高页面的可维护性，整个过程我将概括为以下几步:
1. 划分页面结构(切图)   
2. 更具结构实现布局   
3. 对每个单独结构进行修饰
4. 组合

## 页面布局   
页面布局就就是内容块的划分与排列。再细化步骤如下:
1. 确定块大小   
2. 确定块位置   
3. 组合排列   

上面的步骤很简单，但是会涉及很多 CSS 规范中的坑。

### 理解文档流
写尽量少的好代码。这个原则要求你会利用文档布局特性，不要做浏览器本来就会去做的事情。  
换句话说在布局之前，因该知道文档流本就有自己的排列规则。在利用已有规则的情况下符合设计要求。
**了解浏览器本身的布局特性**   
**利用基本特性的基础上添加特性**

## 布局类型

典型的布局风格,包括
* **正常的布局流** 采用用户代理默认布局行为进行布局
* **flexbox** 流式布局
* **grids** 栅格布局
* **floats** 浮动布局
* **position** 定位布局
* **multiple-column** 多列布局
* **legacy layout** 遗留的布局系统
