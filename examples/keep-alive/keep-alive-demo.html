Keep-Alive 是什么

Keep-Alive 是 Vue 3 内置的抽象组件，用于缓存动态组件或路由组件，避免重复销毁和创建。

常见问题解答

Q: Keep-Alive 缓存的组件何时会被销毁？
当组件符合以下任一条件时会被销毁：
1. 使用 v-if="false" 直接卸载
2. 组件不在 include 列表中（但在 exclude 中）
3. 缓存数量超过 max 限制（最早的会被销毁）
4. 页面/路由完全切换，Keep-Alive 组件被销毁
Q: 组件在 Keep-Alive 中，数据会过期吗？
是的！Keep-Alive 只缓存组件实例和 DOM，不会自动刷新数据。
建议在 activated 钩子中获取最新数据：
onActivated(() => { fetchLatestData() })
Q: Keep-Alive 和 v-show 有什么区别？
v-show 只是 CSS 显示/隐藏，组件始终存在；
Keep-Alive 会真正停用组件，触发 deactivated 钩子，但保留完整状态。
v-show 不支持 activated/deactivated 生命周期。
Q: 为什么组件更新后没有重新渲染？
Keep-Alive 缓存的是组件实例，如果组件依赖的 props 变化但组件内部没有正确响应，可能不会更新。
解决：使用 watch 监听 props 变化，或在 activated 中刷新数据。
