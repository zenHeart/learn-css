什么是 Sentry？

Sentry 是一个开源的错误追踪和性能监控平台，帮助开发者：

  • 实时发现和诊断应用错误
  • 追踪性能问题
  • 了解用户遇到错误时的上下文
  • 通过会话回放重现问题

工作流程

错误发生
→
SDK 捕获
→
发送到 Sentry
→
创建 Issue
→
通知开发者

核心功能

📊 Issues

自动报告未捕获的异常、Promise rejections、语法错误等。

⚡ Tracing

分布式追踪，查看请求在多个系统间的完整链路。

🎥 Session Replay

类似视频回放用户操作过程，快速定位问题。

📝 Logs

集中化日志管理，与错误和性能问题关联分析。

👤 User Feedback

用户遇到错误时收集反馈，获取更多上下文。

🗺️ Source Maps

还原压缩代码为原始源码，快速定位错误位置。

SDK 安装对比

方式 优点 缺点 适用场景
npm 完整功能、类型提示 需要构建 生产项目
Loader Script 零配置、快速接入 功能受限 快速原型、简单页面
CDN Bundle 无需打包工具 无法 tree-shaking legacy 项目

安装与配置

方式一: npm 安装

# npm
npm install @sentry/browser --save

# yarn
yarn add @sentry/browser

# pnpm
pnpm add @sentry/browser

初始化代码

import * as Sentry from "@sentry/browser";

Sentry.init({
  // 数据源标识符，从 Sentry 项目设置获取
  dsn: "https://xxxx@sentry.io/xxxx",

  // 应用发布版本，用于 Source Maps 关联
  release: "my-app@1.0.0",

  // 环境名称
  environment: "production",

  // 是否发送用户 IP 等 PII
  sendDefaultPii: false,

  // 采样率 0-1
  tracesSampleRate: 1.0,

  // 集成
  integrations: [
    Sentry.browserTracingIntegration(),
    Sentry.replayIntegration(),
  ],
});

方式二: Loader Script（最简单）

<!-- 在 Sentry Settings → Projects → SDK Setup 获取 -->
<script src="https://browser.sentry-cdn.com/7.x/1.0.0/bundle.min.js"></script>
<script>
  Sentry.init({
    dsn: "https://xxxx@sentry.io/xxxx"
  });
</script>

常用配置选项

选项 类型 说明
dsn string 数据源标识符，必填
release string 发布版本，用于 Source Maps
environment string 环境名称 (production/staging)
sendDefaultPii boolean 是否发送 IP、用户名等
debug boolean 是否输出调试信息
tracesSampleRate number 性能追踪采样率 0-1
tracePropagationTargets array 哪些域名请求包含 trace

捕获错误的方式

1. 自动捕获

Sentry 默认自动捕获：

  • 未处理的异常 (uncaught exceptions)
  • 未处理的 Promise rejections
  • 语法错误 (SyntaxError)
// Sentry 自动捕获
throw new Error("Oops!");

2. 手动捕获

// 捕获异常
try {
  riskyOperation();
} catch (e) {
  Sentry.captureException(e);
}

// 捕获消息
Sentry.captureMessage("User not found", "warning");

// 捕获自定义事件
Sentry.captureEvent({
  message: "Custom event",
  level: "info",
});

3. 设置上下文

// 设置用户
Sentry.setUser({
  id: "user-123",
  email: "user@example.com",
  username: "johndoe"
});

// 设置标签
Sentry.setTag("version", "1.0.0");

// 设置额外数据
Sentry.setExtra("memory", process.memoryUsage());

// 设置上下文
Sentry.setContext("profile", {
  name: "John Doe",
  role: "admin"
});

4. Breadcrumbs（面包屑）

Sentry 自动记录用户操作链，便于问题排查：

// 添加自定义 breadcrumb
Sentry.addBreadcrumb({
  message: "User clicked submit",
  category: "ui.click",
  data: { buttonId: "submit-btn" },
  level: "info"
});

// 清除 breadcrumbs
Sentry.clearBreadcrumbs();

5. 作用域管理

// 方式一: configureScope
Sentry.configureScope((scope) => {
  scope.setTag("feature", "new-checkout");
});

// 方式二: withScope（推荐，自动恢复）
Sentry.withScope((scope) => {
  scope.setTag("feature", "checkout");
  Sentry.captureException(error);
});

常见错误处理场景

异步错误

// 异步操作中的错误
async function fetchData() {
  throw new Error("API Error");
}

// Promise rejection
Promise.reject("Failed");

资源加载失败

// 图片加载失败
img.src = "invalid-url";

// Script 加载失败
const script = document.createElement("script");
script.src = "missing.js";

beforeSend 过滤器

Sentry.init({
  dsn: "...",
  
  // 在发送前过滤或修改事件
  beforeSend(event) {
    // 移除敏感数据
    delete event.user.ip_address;
    delete event.request.data.password;
    
    // 过滤特定错误
    if (event.message === "Ignore me") {
      return null;
    }
    
    return event;
  },
});

Source Maps 配置

为什么需要 Source Maps？

生产环境代码通常是压缩过的，错误堆栈难以阅读：

// 压缩前
function calculateTotal(items) {
  return items.reduce((sum, item) => sum + item.price, 0);
}

// 压缩后 (sourcemap 帮助还原)
function n(o) { return o.reduce((n,t) => n+t.price, 0); }

使用 Sentry Wizard（推荐）

# 自动配置 source maps 上传
npx @sentry/wizard@latest -i sourcemaps

# Wizard 会：
# 1. 安装 @sentry/webpack-plugin
# 2. 配置 webpack
# 3. 设置环境变量

手动配置 Webpack

# 安装插件
npm install @sentry/webpack-plugin --save-dev
// webpack.config.js
const SentryWebpackPlugin = require("@sentry/webpack-plugin");

module.exports = {
  output: {
    sourceMapFilename: "~/sourcemaps/[hash].js.map",
  },
  plugins: [
    new SentryWebpackPlugin({
      include: "./dist",
      ignore: ["node_modules", "test"],
      org: "your-org",
      project: "your-project",
      authToken: process.env.SENTRY_AUTH_TOKEN,
    }),
  ],
};

环境变量

# .env 文件
SENTRY_AUTH_TOKEN=your_auth_token_here
SENTRY_ORG=your-org-slug
SENTRY_PROJECT=your-project-slug

获取 Auth Token

  1. 登录 Sentry
  2. 访问 Settings → Auth Tokens
  3. 创建新的 Token，需要 `project:write` 权限
  4. 将 Token 复制到环境变量

验证 Source Maps

在 Sentry Issue 详情页检查：

  • ✓ 显示原始文件名和行号 → Source Maps 生效
  • ✗ 显示压缩后的文件名 → 需要检查配置
