什么是数据漏斗

数据漏斗（Conversion Funnel）是一种分析和可视化用户流程的模型，展示用户在完成目标过程中，每一步的转化和流失情况。

关键公式

指标公式说明
转化率 本阶段用户 / 上一阶段用户 × 100% 衡量每步转化效率
流失率 (上一阶段 - 本阶段) / 上一阶段 × 100% 1 - 转化率
LTV ARPU × 平均生命周期（月） 用户总价值
ROI (LTV - CAC) / CAC × 100% 投资回报率，健康值 > 300%
CAC 营销总支出 / 新增用户数 单用户获客成本

漏斗计算

const stages = [
  { name: '访问', users: 10000 },
  { name: '注册', users: 6000 },
  { name: '激活', users: 2400 },
  { name: '付费', users: 800 },
  { name: '复购', users: 200 }
];

const funnel = stages.map((stage, i) => {
  const prev = i === 0 ? stage.users : stages[i-1].users;
  return {
    ...stage,
    conversionRate: stage.users / prev,
    dropRate: (prev - stage.users) / prev
  };
});

// 输出：转化率和流失率
funnel.forEach(s => {
  console.log(`${s.name}: ${(s.conversionRate*100).toFixed(1)}% | 流失: ${(s.dropRate*100).toFixed(1)}%`);
});
