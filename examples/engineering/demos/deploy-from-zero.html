1. 代码打包

构建产物（dist/） = 打包后的 HTML/CSS/JS/图片 等静态资源

主流构建工具

# Vite（推荐，现代项目） npm create vite@latest my-app -- --template vue cd my-app npm install npm run build # 输出到 dist/ # Webpack（大型项目） npm run build # webpack --mode production # Parcel（零配置） npx parcel index.html

打包优化配置

// vite.config.js export default { build: { target: 'es2015', // 兼容目标 cssCodeSplit: true, // CSS 代码分割 rollupOptions: { output: { manualChunks: { // 拆包策略 vendor: ['vue', 'vue-router'], element-plus: ['element-plus'] } } }, terserOptions: { // JS 压缩配置 compress: { drop_console: true, // 移除 console drop_debugger: true } } } }

2. 资源优化

静态资源处理

  • ✓ 代码压缩：JS/CSS/HTML minify，移除注释和空格
  • ✓ Gzip/Brotli：服务器开启压缩，体积减少 60-80%
  • ✓ 图片优化：WebP 格式、懒加载、CDN 加速
  • ✓ 长缓存：静态资源使用 contenthash 命名
  • ✓ CDN 分发：将静态资源部署到 CDN

关键 HTTP Headers

# Nginx 配置关键响应头 add_header Cache-Control "public, max-age=31536000, immutable"; # 静态资源一年 add_header Strict-Transport-Security "max-age=63072000"; # HSTS add_header X-Content-Type-Options "nosniff"; # 防止 MIME 嗅探 add_header X-Frame-Options "SAMEORIGIN"; # 防点击劫持

3. 服务器配置

Nginx 部署 SPA（单页应用）

# /etc/nginx/conf.d/vue-app.conf server { listen 80; server_name example.com; root /var/www/my-app/dist; # 构建产物目录 index index.html; # Gzip 压缩 gzip on; gzip_types text/plain application/javascript application/json text/css application/xml; gzip_min_length 1000; # SPA 路由 fallback 到 index.html location / { try_files $uri $uri/ /index.html; # ← 关键！ } # 静态资源缓存 location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ { expires 1y; add_header Cache-Control "public, immutable"; } # API 代理（可选） location /api/ { proxy_pass http://localhost:3000/; proxy_set_header Host $host; } }

HTTPS 配置（Let's Encrypt 免费证书）

# 安装 Certbot apt install certbot python3-certbot-nginx # 获取证书（自动配置 Nginx） certbot --nginx -d example.com -d www.example.com # 自动续期（Certbot 已配置 cron） certbot renew --dry-run

Docker 部署

# Dockerfile FROM nginx:alpine COPY dist/ /usr/share/nginx/html/ COPY nginx.conf /etc/nginx/conf.d/default.conf EXPOSE 80 CMD ["nginx", "-g", "daemon off;"] # docker-compose.yml services: web: build: . ports: - "80:80" restart: unless-stopped

4. CI/CD 自动化

GitHub Actions 部署流程

# .github/workflows/deploy.yml name: Deploy on: push: branches: [main] jobs: deploy: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - name: Setup Node uses: actions/setup-node@v4 with: node-version: '20' cache: 'npm' - name: Install & Build run: | npm ci npm run build - name: Deploy to Server uses: appleboy/scp-action@master with: host: ${{ secrets.SERVER_HOST }} username: ubuntu key: ${{ secrets.SERVER_SSH_KEY }} source: dist/* target: /var/www/my-app strip_components: 0 - name: Restart Nginx uses: appleboy/ssh-action@master with: host: ${{ secrets.SERVER_HOST }} username: ubuntu key: ${{ secrets.SERVER_SSH_KEY }} script: | sudo nginx -t && sudo systemctl reload nginx

5. 监控与回滚

健康检查

# Nginx 健康检查配置 location /health { access_log off; return 200 "ok"; add_header Content-Type "text/plain"; }

快速回滚方案

# 方案一：软链接切换（推荐） /var/www/ ├── my-app-v1.0.0/ # 版本 1 ├── my-app-v1.1.0/ # 版本 2（新版本） └── current -> my-app-v1.1.0/ # 软链接指向当前版本 # 回滚：切换软链接即可 ln -sfn /var/www/my-app-v1.0.0 /var/www/current sudo systemctl reload nginx

监控指标

  • ✓ 99 线：P99 响应时间 < 1s
  • ✓ 错误率：5xx 错误率 < 1%
  • ✓ 可用性：SLA 99.9%（年停机 < 8.7h）
  • ✓ 资源使用：CPU < 70%, Memory < 80%

✅ 部署检查清单

  • ✓ 环境变量：生产环境 .env.production 配置正确
  • ✓ API 地址：后端 API 地址切换到生产环境
  • ✓ 代码压缩：production 模式构建，console 已移除
  • ✓ SPA 路由：Nginx try_files fallback 已配置
  • ✓ HTTPS：证书有效，HTTP 自动跳转 HTTPS
  • ✓ 静态缓存：contenthash 命名 + 1年缓存
  • ✓ CDN：静态资源已部署到 CDN
  • ✓ 域名解析：DNS A 记录指向服务器 IP
  • ✓ 跨域配置：CORS 白名单已配置
  • ✓ 回滚方案：软链接切换 + 一键回滚脚本
