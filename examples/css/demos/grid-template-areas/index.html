通过可视化方式定义 CSS Grid 布局

工作原理

grid-template-areas 允许你用字符串形式在 CSS 中"画"出布局，每个名称对应一个网格区域

.container { display: grid; grid-template-columns: repeat(3, 1fr); grid-template-areas: "header header header" "sidebar main aside" "footer footer footer"; } /* 将元素分配到区域 */ .header { grid-area: header; } .sidebar { grid-area: sidebar; } .main { grid-area: main; } .aside { grid-area: aside; } .footer { grid-area: footer; }

最佳实践

  • 使用语义化的区域名称（header、sidebar、main、footer）
  • 确保每个区域形成矩形（不能是 L 形或更复杂的形状）
  • 使用 `.` 表示空单元格，不要留空格
  • 结合媒体查询实现响应式布局
  • 复杂布局可以拆分为多个嵌套的网格
  • 使用 gap 属性控制区域之间的间距
