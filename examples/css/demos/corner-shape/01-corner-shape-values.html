CSS corner-shape 角形状属性

配合 border-radius 使用，创建独特的角形状效果

round（默认圆角）

corner-shape: round;

squircle（平滑过渡）

corner-shape: squircle;

scoop（勺形/内凹）

corner-shape: scoop;

bevel（斜面）

corner-shape: bevel;

notch（凹口）

corner-shape: notch;

square（正方形）

corner-shape: square;

需要 Chrome 139+ 版本才能看到效果
