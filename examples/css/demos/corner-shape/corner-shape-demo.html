浏览器兼容性

浏览器 支持情况 备注
Chrome 不支持 需要开启实验特性
Firefox 不支持 考虑使用 SVG
Safari 部分支持 WebKit 内核
Edge 不支持 依赖 Chromium

代码示例

/* 基本用法 */ .element { corner-shape: circle; border-radius: 50%; } /* 单独控制各角 */ .card { border-top-start-radius: 30px; border-top-end-radius: 10px; border-bottom-end-radius: 30px; border-bottom-start-radius: 10px; } /* 兼容性处理 */ .fallback { border-radius: 20px; /* 所有浏览器支持 */ } @supports (corner-shape: circle) { .fallback { corner-shape: circle; border-radius: 50%; } }
提示：corner-shape 属性目前浏览器支持有限。演示中的效果使用了 border-radius 作为降级方案。在生产环境中使用时，请确保提供适当的降级样式。
