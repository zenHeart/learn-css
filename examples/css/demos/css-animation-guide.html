CSS Animation 交互演示

@keyframes + animation 属性详解 | 基于 learn-css 仓库示例风格

@keyframes 语法 — 0% / from / to

三种写法完全等价：0% = from（起始帧），100% = to（结束帧）。中间可以插任意百分比的帧。

/* 百分比写法 */ @keyframes slideRight { 0% { transform: translateX(0); opacity: 1; } 50% { transform: translateX(100px); opacity: 0.8; } 100% { transform: translateX(200px); opacity: 0.5; } } /* from / to 写法（仅两帧时常用） */ @keyframes fadeSlide { from { opacity: 0; transform: translateY(10px); } to { opacity: 1; transform: translateY(0); } }

animation 缩写属性顺序

▶
animation: name duration timing-function delay iteration-count direction fill-mode play-state;

缩写顺序记忆口诀：名 时 缓 延 次 方 模 态（name / duration / timing-function / delay / iteration-count / direction / fill-mode / play-state）

animation: 2s ease 0.5s;
animation: ease 2s 0.5s;
ease 和 2s 顺序颠倒，浏览器按 值类型 解析

animation-name & animation-duration

▶
animation: slideRight 1s;

animation-timing-function 缓动函数

▶
animation-timing-function: ease;

贝塞尔曲线对比：ease = cubic-bezier(0.25, 0.1, 0.25, 1) | linear = cubic-bezier(0, 0, 1, 1) | ease-in = cubic-bezier(0.42, 0, 1, 1) 慢开始快结束

animation-delay 延迟

▶
animation-delay: 0s;

负值会让动画从中间的那个时间点开始播放。例如 -1s 表示"跳过第1秒，从第2秒开始"。

animation-iteration-count 播放次数

▶
animation-iteration-count: 1;

animation-direction 播放方向

▶
animation-direction: normal;

alternate常用于 loading 动画或呼吸效果，正向反向交替使运动更自然。

animation-fill-mode 填充模式

▶
animation-fill-mode: none;

none：动画前后都不受关键帧影响 | forwards：停在最后一帧 | backwards：在 delay 期间显示第一帧 | both：delay期间显示第一帧 + 结束后停在最后帧

steps() 步进缓动函数

animation-timing-function: steps(4, start);

steps(n, start)：跳到每段的起点（共 n 步）| steps(n, end)：停在每段的终点（共 n 步）
适用于：Sprite 动画、进度条、帧动画。左侧对比 linear 平滑过渡。

多动画并行

多动
/* 多个动画用逗号分隔，同时播放 */ .ball { animation: slideRight 2s infinite alternate, pulse 1s infinite alternate; }

左侧球同时执行平移（slideRight）+ 缩放（pulse）两个动画。用逗号分隔即可，无数量限制。

animation-play-state 暂停/继续

转
animation-play-state: running;

常配合 :hover 使用：悬停时暂停，鼠标移开继续播放。

Animation vs Transition 对比

Transition

• 需要 触发条件（:hover、:active、JS）
• 只能描述 两帧之间的过渡
• 不能循环
• 性能更好（GPU加速）
• 适合：状态切换反馈

Animation

• 自动播放，无需触发
• 支持 多帧关键帧
• 可以循环
• 可暂停/控制
• 适合：复杂序列、循环动画、进入/退出动画

/* Transition：需要 hover 触发 */ .box { transition: transform 0.3s ease; } .box:hover { transform: scale(1.2); } /* Animation：自动播放，定义多帧 */ .box { animation: pulse 2s infinite; } @keyframes pulse { 0%, 100% { transform: scale(1); } 50% { transform: scale(1.2); } }

非缩写属性（独立设置）

独立
/* 当只需要修改某一个动画属性时，使用非缩写属性更清晰 */ animation-name: slideRight; animation-duration: 1.5s; animation-timing-function: ease-in-out; animation-delay: 0.3s; animation-iteration-count: infinite; animation-direction: alternate; animation-fill-mode: forwards; animation-play-state: running;

缩写会重置所有未写的子属性为初始值。修改单个属性时，使用非缩写写法更安全。
