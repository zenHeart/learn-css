font-variation-settings 可变字体演示

💡 什么是可变字体？

可变字体（Variable Fonts）是 OpenType 字体规范的发展，它允许在单个字体文件中包含多个变体， 通过轴（axis）来控制字体的外观。相比传统字体，可变字体文件更小，功能更强大。

常用特性轴

轴名 全称 说明 典型范围
wght Weight 字重（粗细） 100 - 900
wdth Width 字宽（压缩/扩展） 75 - 125
ital Italic 斜体（0=正体，1=斜体） 0 - 1
slnt Slant 倾斜角度 -10 - 0
opsz Optical Size 光学尺寸（字号相关） 6 - 144
GRAD Grade 字重等级（不影响布局） -50 - 150
XTRA Contrast 轮廓对比度 63 - 1000

交互式演示

拖动滑块实时调整可变字体的各个轴：

Roboto Flex 可变字体控制

wght 400
wdth 100
slnt 0
opsz 14
可变字体

font-variation-settings: 'wght' 400, 'wdth' 100, 'slnt' 0, 'opsz' 14

CSS 语法

/* 基本语法 */
.element {
  font-family: 'Roboto Flex', sans-serif;
  font-variation-settings: 'wght' 400;
}

/* 多个轴同时设置 */
.heading {
  font-family: 'Roboto Flex', sans-serif;
  font-variation-settings: 'wght' 700, 'wdth' 100;
  font-size: 48px;
}

/* 与普通字体属性配合使用 */
.text {
  font-family: 'Roboto Flex', sans-serif;
  font-weight: 500;        /* 标准属性 */
  font-variation-settings: 'wght' 500, 'wdth' 95;  /* 可变字体轴 */
}

注意事项

  • 兼容性：现代浏览器都支持可变字体，但需要使用支持可变字体的字体文件
  • 性能：使用 font-display: optional 可在网络不佳时跳过字体加载
  • 回退：为不支持可变字体的浏览器提供 fallback 字体
  • Google Fonts：Google Fonts 上的可变字体 URL 包含完整的轴范围

常用可变字体推荐

  • Roboto Flex - Google Fonts，支持 wght, wdth, slnt, opsz
  • Inter - Google Fonts，支持 wght
  • Recursive - Google Fonts，支持 wght, slnt, MONO, CASL, CRSV
  • Source Sans 3 - Google Fonts，支持 wght, wdth, ital, slnt, SOFT, ZERO
  • Amstelvar - Google Fonts，支持 wght, opsz, XTRA, YOPQ 等
