典型使用场景

🎯 吸顶导航

导航栏在滚动到顶部时固定，滚动时保持在视口顶部。

🔘 浮动操作按钮

固定在视口某个位置，常用于主操作如"新建"、"分享"。

🏷️ 卡片角标

固定在父容器的角落，如"新品"、"热门"等标签。

📌 吸附侧边栏

侧边栏固定在视口，但相对于某个内容区域定位。

定位方式对比

定位属性对比
包含块规则
常见坑点
定位方式 定位上下文 随滚动移动 适用场景
static 正常文档流 是 默认布局
relative 自身原始位置 是 微调位置、创建子元素定位上下文
absolute 最近已定位祖先 是 绝对定位浮层、下拉菜单
fixed 视口（无 transform 祖先） 否 固定导航、浮动按钮、模态框
fixed + transform transform 祖先 否（相对于祖先固定） 相对父容器固定、吸附效果
sticky 最近滚动容器 条件 表头吸附、分类导航

注意：transform、perspective、filter 属性会改变 absolute 和 fixed 的定位上下文。

坑点 问题描述 解决方案
性能问题 过多 transform 导致合成层爆炸 限制使用，合理分层
文字模糊 transform 触发亚像素渲染 使用 translateZ(0) 强制 GPU
滚动越界 fixed 元素随滚动"跑出"父容器 JS 动态计算位置
z-index 层叠 transform 创建独立层叠上下文 统一规划 z-index 层级

Fixed + Transform

总结：transform 属性会改变 fixed 的定位上下文，使其相对于应用了 transform 的祖先元素定位，而非视口。这允许我们实现"相对父元素固定"的布局效果，是现代前端实现吸附、浮动等交互的重要技术。
