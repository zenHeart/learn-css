isolation 的作用

isolation: isolate 创建一个新的层叠上下文，阻止混合模式影响父元素外部的内容。 这在需要将混合效果限制在某个区域内时非常有用。

无隔离 isolation: auto

页面黄色背景参与了混合

Multiply
Screen
有隔离 isolation: isolate

混合只在容器内，黄色背景不参与

Multiply
Screen
/* 无隔离：混合会传播到父元素背景 */
.outer {
  background: #fbbf24; /* 这会影响混合结果 */
}
.inner {
  mix-blend-mode: multiply;
  background: #ff6b6b;
}

/* 有隔离：混合只在容器内 */
.container {
  isolation: isolate; /* 创建隔离层 */
}
.container .layer {
  mix-blend-mode: multiply;
}

文字层叠混合

多层文字使用不同的混合模式叠加在一起：

HELLO CSS BLEND 
/* 文字层叠混合 */
.text-stack {
  position: relative;
  background: linear-gradient(180deg, #1e1e1e, #2d2d2d);
}

.word-1 {
  top: 20%;
  left: 10%;
  color: #ff6b6b;
  mix-blend-mode: multiply;
}

.word-2 {
  top: 40%;
  left: 25%;
  color: #4ecdc4;
  mix-blend-mode: screen;
}

.word-3 {
  top: 60%;
  left: 40%;
  color: #ffe66d;
  mix-blend-mode: overlay;
}

SVG 与 HTML 混合

SVG 图形与 HTML 内容的混合效果：

SVG BLEND
/* SVG 与 HTML 内容的混合 */
.svg-blend-demo {
  position: relative;
  background: #764ba2;
}

.svg-blend-demo svg {
  position: absolute;
  width: 100%;
  height: 100%;
}

.svg-blend-demo svg circle {
  mix-blend-mode: screen; /* SVG 元素也可使用混合模式 */
}

.text-overlay {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  color: white;
  mix-blend-mode: multiply;
}
