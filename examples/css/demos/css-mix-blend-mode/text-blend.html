📝 文字与背景混合模式

不同混合模式下的文字效果

白色文字叠加在渐变背景上，不同混合模式产生不同视觉效果：

BLEND
mix-blend-mode: multiply
SCREEN
mix-blend-mode: screen
OVERLAY
mix-blend-mode: overlay

文字描边 + 混合模式

结合文字描边和混合模式，创造独特的文字效果：

Hello World
/* 文字描边 + 混合模式 */
.stroke-text {
  font-size: 72px;
  font-weight: 900;
  color: white;
  -webkit-text-stroke: 2px white; /* 文字描边 */
  paint-order: stroke fill; /* 先描边后填充 */
  mix-blend-mode: multiply; /* 与背景混合 */
}

多行文字不同混合模式

同一区域内，多行文字可以设置不同的混合模式：

HELLO WORLD 
/* 多行文字不同混合模式 */
.big-text {
  display: flex;
  flex-direction: column;
}

.big-text span:nth-child(1) {
  mix-blend-mode: multiply; /* 白色文字在渐变上变暗 */
}

.big-text span:nth-child(2) {
  mix-blend-mode: screen; /* 黄色文字在渐变上变亮 */
  color: #ffe66d;
}
