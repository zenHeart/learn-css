网格叠加效果

图片上叠加网格线，使用 multiply 混合让网格融入图片：

/* 网格叠加 - 使用 multiply 让网格融入图片 */
.grid-overlay {
  position: absolute;
  inset: 0;
  background-image:
    linear-gradient(rgba(255,255,255,0.3) 1px, transparent 1px),
    linear-gradient(90deg, rgba(255,255,255,0.3) 1px, transparent 1px);
  background-size: 30px 30px;
  mix-blend-mode: multiply; /* 白色网格融入图片 */
}
