💡 什么是混合模式？

混合模式控制两个图层叠加时的视觉效果。当元素放在其它内容之上时， 通过设置不同的混合模式，可以创造出丰富的视觉效果，如同 Photoshop 中的图层混合。

混合模式原理对比

模式 原理 效果特点
multiply 前景 × 背景 黑色完全变黑，白色保持不变
screen 1 - (1-前景) × (1-背景) 与 multiply 相反，白色完全保留
overlay 根据背景交替使用 multiply/screen 暗部加深，亮部提亮
darken 取较暗的颜色 保留较暗的像素
lighten 取较亮的颜色 保留较亮的像素
difference |前景 - 背景| 高对比度，产生负片效果

核心代码示例

/* 基础用法：文字与背景混合 */
.text-blend {
  position: relative;
  background: linear-gradient(135deg, #667eea, #764ba2);
}

.text-blend h1 {
  mix-blend-mode: multiply; /* 文字与背景混合 */
  color: white;
}

/* 与 background-blend-mode 的区别 */
.bg-blend {
  background-image: url('image.jpg');
  background-blend-mode: multiply; /* 仅背景图片之间混合 */
}

.content-blend {
  background-image: url('image.jpg');
  mix-blend-mode: multiply; /* 包括文字在内整体混合 */
}

/* 使用 isolation 隔离混合效果 */
.container {
  isolation: isolate; /* 混合只在容器内生效 */
}

混用 vs 隔离：isolation 的作用

不隔离：混合效果会传播到父元素外部
隔离（isolation: isolate）：混合效果只在当前容器内生效 

/* 不隔离：.inner 的混合会影响整个页面背景 */
.outer {
  background: #764ba2;
}
.inner {
  mix-blend-mode: multiply;
  background: #ff6b6b;
}

/* 隔离：混合只在 .group 内生效 */
.group {
  isolation: isolate;
}
