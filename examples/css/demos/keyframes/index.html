CSS @keyframes 交互演示

@keyframes 语法 · 关键帧顺序 · fill-mode · direction · composition

关键帧顺序与时序

浏览器按百分比值自动排序，书写顺序不影响播放时间。0% = from，100% = to

顺序
@keyframes orderDemo { 0% { transform: translateX(0); background: #3b82f6; } 50% { transform: translateX(100px); background: #a371f7; } 100% { transform: translateX(200px); background: #3fb950; } }

animation-fill-mode 填充模式

fill
animation: fillForwards 1.5s 1 none;

none 动画前后保持原样 | forwards 停在最后一帧 | backwards delay 期间显示第一帧 | both both = backwards + forwards

animation-direction 播放方向

方向
animation: slideRight 2s infinite normal;

normal 正向 0%→100% | reverse 反向 100%→0% | alternate 交替（正→反→正...） | alternate-reverse 反向交替

animation-iteration-count 播放次数

次数
animation: slideRight 1.5s 1;

具体数字 播放指定次数后停止 | infinite 无限循环，需配合 animation-play-state: paused 控制停止

animation-composition 动画组合 CSS 2024

当多个动画作用于同一元素时，决定如何组合效果。Chrome 112+ 支持。

组合
animation-composition: replace;

replace 后动画替换前一个（最终只有 scale）
add 两个 transform 叠加（平移+缩放）
accumulate 数值相乘 translateY(30px)+translateY(60px)=translateY(90px)

/* 演示用动画定义 */ @keyframes slideX { to { transform: translateX(150px); } } @keyframes scaleUp { to { transform: scale(1.5); } } @keyframes translateY10 { to { transform: translateY(30px); } } @keyframes translateY20 { to { transform: translateY(60px); } } #comp-ball { animation: slideX 1.5s infinite alternate, scaleUp 1.5s infinite alternate; animation-composition: replace; /* 切换此值观察效果 */ }

百分比 vs from/to

淡入上移
@keyframes fadeInUp { 0% { opacity: 0; transform: translateY(20px); } 100% { opacity: 1; transform: translateY(0); } }

0% = from（起始帧）， 100% = to（结束帧）。 三帧以上必须用百分比。

常见错误演示

① 名称不匹配

不运行
/* @keyframes 定义为 slideRight，但 animation-name 写成 wrongName */ @keyframes slideRight { to { transform: translateX(200px); } } animation-name: wrongName; /* ❌ 拼写错误，动画不运行 */

② 缺少 animation-duration

无时长
/* 默认为 0s，动画不会播放 */ animation-name: slideRight; /* ✅ 必须指定 animation-duration: 1.5s; */

③ infinite 无停止机制（移动端注意）

无限循环
/* hover 暂停在桌面有效，但移动端无法 hover */ .box:hover { animation-play-state: paused; } /* ✅ 提供 JS 控制或媒体查询 */ @media (hover: none) { .box { animation: none; } }

Animation vs Transition 对比

Transition

· 需要触发条件：hover、active、JS
· 只能描述两态之间的过渡
· 不能循环
· GPU 加速，性能好
· 适合：状态切换反哺

@keyframes Animation

· 自动播放，无需触发
· 支持多关键帧定义复杂轨迹
· 可以循环
· 可暂停/控制
· 适合：循环动画、入场序列、复杂动画

/* Transition：需要 hover 触发 */ .box { transition: transform 0.3s ease; } .box:hover { transform: scale(1.2); } /* Animation：自动播放，定义多帧 */ .box { animation: pulse 2s infinite; } @keyframes pulse { 0%, 100% { transform: scale(1); } 50% { transform: scale(1.2); } }

CSS @keyframes 支持所有现代浏览器。animation-composition 为 CSS 2024 新增属性，请确认浏览器支持情况。
