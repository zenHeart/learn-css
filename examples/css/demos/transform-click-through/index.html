CSS Transform Click-Through 问题演示

学习 transform 属性如何影响 pointer-events 和 hit-testing

Demo 1: 幻灯片切换与点击穿透

⚠️ 问题说明

幻灯片切换动画过程中，非活跃幻灯片虽然视觉上移出了视口，但可能仍在视口范围内， 导致点击时被这些不可见的幻灯片捕获。解决方案：非活跃幻灯片设置 pointer-events: none。

Demo 2: Hover Scale 与点击区域

⚠️ 问题说明

当使用 transform: scale() 实现 hover 放大效果时，元素的视觉边界扩大了， 但实际的点击区域（hit-box）是否也跟着扩大？这取决于父元素和具体浏览器实现。

Demo 3: Overlay 遮罩层点击穿透

⚠️ 问题说明

遮罩层（overlay）在隐藏时使用 opacity: 0，但 pointer-events 仍可能有效， 导致点击底层元素时无效。正确做法是同时设置 pointer-events: none。
