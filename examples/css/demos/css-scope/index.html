2. Donut Scope（带下限的作用域） 排除子树

通过 to (.donut-card__footer) 设置下限，下限内的元素被排除在作用域外。

3. 主题作用域与 Scoping Proximity 邻近性

CSS 级联新增 Scoping Proximity 步骤。嵌套主题时，跳数更少的作用域优先。

外部浅色主题：蓝色链接

浅色盒子

嵌套深色主题：浅蓝色链接

深色盒子

再次嵌套回浅色：蓝色链接（虽被 dark 包裹，但离 .theme--light 更近）

浅色盒子（嵌套层离它更近）
@scope (.theme--light) { a { color: #1976d2; } } @scope (.theme--dark) { a { color: #90caf9; } } /* 级联顺序: specificity -> scoping-proximity -> order */ /* 第三个链接离浅色主题 1 跳，离深色 2 跳，浅色优先 */

4. 组件样式隔离

不同容器的同名类可以有不同的样式，无需 BEM 复杂命名。

5. 嵌套组件与 & 选择器 & 嵌套

6. 重要提示：选择器隔离 ≠ 样式隔离

@scope 限制的是选择器的触及范围，但继承属性（如 color）仍然会穿透下限继承到子元素。
样式继承示例

在作用域内，继承了 color: #d32f2f

跳出了作用域，但 color 仍然继承自父级

@scope (.card) to (.card__content) { :scope { color: hotpink; } /* 继承属性会穿透下限 */ }
