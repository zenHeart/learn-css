scroll-snap-type: y mandatory;

mandatory：滚动停止后强制吸附到最近的 snap point，行为可预期 | proximity：仅当停止位置接近 snap point 时才吸附，行为更柔和 | none：禁用滚动吸附

scroll-snap-align 对齐方式

🎵 音乐推荐
📚 读书笔记（高度更大）
🎬 影视点评
🍜 美食探店
💻 科技评测

start：子元素顶部对齐容器顶部（默认）| center：子元素中心对齐容器中心 | end：子元素底部对齐容器底部

核心代码

/* 容器：定义滚动轴向和吸附模式 */ .snap-list { height: 320px; overflow-y: auto; scroll-snap-type: y mandatory; } /* 子元素：定义吸附对齐点 */ .list-item { height: 100px; scroll-snap-align: start; /* 元素顶部对齐容器顶部 */ }

容器需要明确的高度（或通过内容撑开），并设置 `overflow` 使其可滚动。子元素通过 `scroll-snap-align` 声明对齐方式。

CSS Scroll Snap 支持所有现代浏览器。示例基于 learn-css 仓库风格。
