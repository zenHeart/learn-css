html { scroll-snap-type: y mandatory; } .section { height: 100vh; /* 全屏高度 */ scroll-snap-align: start; /* 吸附到顶部 */ }

100vh：每屏占满整个视口 | start：吸附到视口顶部 | 适合：落地页、H5 长页面、问答流程

.grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 8px; overflow: auto; scroll-snap-type: both mandatory; } .cell { scroll-snap-align: start; /* 左上角对齐 */ }

both：水平和垂直方向同时吸附 | start：每个格子的左上角作为吸附点 | 适合：图片画廊、产品网格、仪表盘

.quiz-card { scroll-snap-align: start; scroll-snap-stop: always; /* 强制停在此项，禁止跳过 */ }

scroll-snap-stop: always：强制滚动必须在每个 snap point 处停下，不能跳过。适合问卷、答题等禁止跳过的场景。

.margin-card { scroll-snap-align: start; scroll-margin: 20px; /* 吸附后与容器左边缘保持 20px 间距 */ }

scroll-margin：单独调整某个子元素的吸附位置，类似于给元素加外边距。常用于多卡片轮播中让第一张不完全贴左边缘。

核心代码：全屏垂直滚动

/* 关键点： 1. html/body 不能设 height: 100%，需要靠内容撑开 2. 每个 section 高度 100vh 独占一屏 3. scroll-snap-type: y mandatory 强制垂直吸附 */ html { scroll-snap-type: y mandatory; height: 100%; } section { height: 100vh; scroll-snap-align: start; /* section 顶部对齐视口顶部 */ }

tip Safari 不支持在 html 上使用 scroll-snap，必要时可改用 body。
