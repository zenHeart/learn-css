.carousel { display: flex; overflow-x: auto; scroll-snap-type: x mandatory; -webkit-overflow-scrolling: touch; /* iOS 惯性滚动 */ } .carousel::-webkit-scrollbar { display: none; } /* 隐藏滚动条 */ .carousel__item { flex: 0 0 75%; /* 每项占 75% 宽度，露出下一张提示可滑动 */ scroll-snap-align: center; /* 居中对齐 */ }

flex: 0 0 75%：每张卡片占 75% 宽度，两侧各露出部分下一张/上一张 | center：吸附到视口中央，视觉焦点明确 | -webkit-overflow-scrolling: touch：iOS 设备惯性滚动

scroll-padding 控制吸附位置

scroll-padding：调整容器内边距，使吸附点偏离容器边缘。常用于留出固定导航/广告位。

不同对齐方式对比

🎯 专注工作（80%）
📖 深度阅读（70%）
🏃 夜跑计划（90%）
🎨 创意写作（65%）
🧘 睡前拉伸（75%）

不同对齐方式会影响吸附后的视觉效果。居中对齐适合轮播图，左对齐适合列表浏览。

核心代码模板

/* 1. 容器：水平滚动 + 强制吸附 */ .carousel { display: flex; overflow-x: auto; scroll-snap-type: x mandatory; -webkit-overflow-scrolling: touch; /* iOS 惯性滚动 */ gap: 12px; padding: 0 20px; } .carousel::-webkit-scrollbar { display: none; } /* 2. 子元素：非整除宽度 + 居中对齐 */ .carousel__item { flex: 0 0 75%; /* 非 100%，露出下一张 */ height: 280px; scroll-snap-align: center; /* 吸附到视口中央 */ border-radius: 16px; } /* 3. 配合 scroll-padding 调整吸附区域（可选） */ .carousel { scroll-padding: 20px; }

推荐配置：flex: 0 0 75%~85% + scroll-snap-align: center + gap: 12px
