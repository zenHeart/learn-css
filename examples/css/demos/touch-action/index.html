CSS touch-action 触摸操作控制

移动端触摸手势控制 | 交互演示

touch-action 属性值

提示：这些演示需要在移动设备或触摸模拟器（如 Chrome DevTools）上测试才能看到效果。

auto - 浏览器处理所有触摸手势（默认）

none - 禁止所有触摸手势

pan-x - 只允许水平平移

pan-y - 只允许垂直平移

manipulation - 允许平移和缩放，禁用双击缩放

.element { touch-action: auto | none | pan-x | pan-y | manipulation; }

实际应用场景

/* 1. 移除按钮点击延迟 */ .button { touch-action: manipulation; padding: 12px 24px; } /* 2. 游戏区域完全自定义控制 */ .game-canvas { touch-action: none; /* 自定义触摸处理 */ } /* 3. 轮播图只允许滑动切换 */ .carousel { touch-action: pan-y; /* 垂直方向滑动切换幻灯片 */ overflow-x: auto; } /* 4. 地图控件 */ .map-overlay { touch-action: none; /* 让地图库处理手势 */ } .map-button { touch-action: manipulation; /* 按钮需要正常点击 */ }
