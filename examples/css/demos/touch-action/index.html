CSS `touch-action` 属性演示

auto（默认） touch-action: auto
浏览器处理所有触摸手势：滚动、缩放、双击等

尝试滑动、捏合缩放
所有默认手势可用

none touch-action: none
完全禁用触摸手势 - 适用于游戏控件

滑动、缩放、双击
全部被禁用

manipulation touch-action: manipulation
允许滚动和缩放，禁用双击缩放 - 移动端推荐

可滚动、可捏合缩放
双击缩放被禁用

pan-x touch-action: pan-x
仅允许水平滚动（左右滑动）

← 左右滑动试试 →
上下滑动会被阻止

pan-y touch-action: pan-y
仅允许垂直滚动（上下滑动）

↑ 上下滑动试试 ↓
左右滑动会被阻止

pan-left touch-action: pan-left
仅允许向左滑动 - 抽屉导航场景

← 向左滑动打开
其他方向被阻止

pan-right touch-action: pan-right
仅允许向右滑动

→ 向右滑动试试
其他方向被阻止

pan-up touch-action: pan-up
仅允许向上滑动

↑ 向上滑动试试
其他方向被阻止

pan-down touch-action: pan-down
仅允许向下滑动

↓ 向下滑动试试
其他方向被阻止

touch-action vs pointer-events

特性 touch-action pointer-events
作用对象 触摸手势（滚动、缩放等） 指针事件（鼠标/触摸/触控笔点击）
主要用途 控制浏览器默认触摸行为 控制元素是否成为事件目标
典型场景 禁用缩放、限制滚动方向 禁用元素点击、事件穿透
常见值 auto, none, pan-x, pan-y auto, none, all, visiblePainted
