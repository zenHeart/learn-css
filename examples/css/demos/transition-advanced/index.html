多属性同时过渡

/* 多个属性分开定义 */ .multi { transition-property: background-color, transform, opacity; transition-duration: 0.3s, 0.5s, 0.2s; transition-timing-function: ease, ease-out, linear; } /* 或简写 */ .multi { transition: background-color 0.3s ease, transform 0.5s ease-out, opacity 0.2s linear; }
