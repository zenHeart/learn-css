🔑 嵌套滚动隔离的原理

当一个可滚动元素设置了 overscroll-behavior: contain，其内部的滚动到边界后，不会「溢」到父容器或其他兄弟元素。

本例中，聊天列表和侧边栏各自独立滚动，互不影响。

/* 聊天列表和侧边栏的共同样式 */
.chat-list, .sidebar {
  overscroll-behavior: contain;
  overflow-y: auto;
}

滚动隔离 vs 未隔离对比

✅ overscroll-behavior: contain 每个区域滚动边界独立
不会互相影响
❌ 无隔离（默认 auto） 子区域滚到边界后会「穿透」
到父容器或其他滚动区域
