🔑 关键 CSS 组合

.carousel {
  overflow-x: auto;
  
  /* ① 横向滚动到边界后，阻止向父容器传播垂直滚动 */
  overscroll-behavior-x: contain;
  
  /* ② 禁止此元素的垂直方向触摸默认行为，让手势优先处理水平滚动 */
  /* 这样用户稍微倾斜的手指动作也会被识别为水平滚动 */
  touch-action: pan-y;
  
  /* ③ iOS 原生惯性滚动（iOS Safari 16+ 可省略） */
  -webkit-overflow-scrolling: touch;
}

加了 vs 没加 对比

✅ 有 overscroll-behavior

  • 轮播横向滚到头，继续拖动 → 轮播有轻微回弹
  • 背景页面 保持不动
  • 用户意图被正确识别为「继续横向滚动」

❌ 没有 overscroll-behavior

  • 轮播横向滚到头，继续拖动 →
  • 背景页面开始垂直滚动（滚动穿透）
  • 用户无法在轮播上正常滚动
