CSS 逻辑属性

margin-inline/block | 书写模式无关 | RTL 适配

案例 1基础边距对比

物理属性 margin-top/bottom, padding-left/right

border-left 固定在左侧

逻辑属性 margin-block, padding-inline

border-inline-start 自动适配方向

/* 物理属性（固定方向） */ .card-physical { margin-top: 16px; margin-bottom: 16px; padding-left: 16px; padding-right: 16px; border-left: 3px solid #f59e0b; } /* 逻辑属性（自动适配方向） */ .card-logical { margin-block: 16px; padding-inline: 16px; border-inline-start: 3px solid #3b82f6; }

逻辑属性根据书写方向自动调整，物理属性方向固定。

案例 2RTL 布局适配

引用文本

边框自动显示在正确的一侧

/* 输入框 - RTL 自动适配 */ .input-field { border-inline-start: 3px solid #3b82f6; padding-inline-start: 12px; } /* 引用块 */ .blockquote { border-inline-start: 4px solid #22c55e; padding-inline-start: 16px; }

点击按钮切换 LTR/RTL 模式，观察边框位置的变化。

案例 3垂直书写模式

横向文本 writing-mode: horizontal-tb
垂直文本 writing-mode: vertical-rl
/* 垂直书写模式 */ .vertical-card { writing-mode: vertical-rl; inline-size: 150px; block-size: auto; padding-block: 20px; padding-inline: 16px; border-inline-end: 4px solid #a855f7; }

垂直模式下，inline 方向变为垂直方向，border-inline-end 会显示在上方或下方。

案例 4流式布局

侧边栏

float: inline-start

这是一段正文内容。使用逻辑属性实现流式布局，在不同书写模式下侧边栏会自动漂浮到正确的位置。

段落的最大宽度使用 max-inline-size 控制，这样可以保证行长度适中，提高可读性。

/* 侧边栏 */ .sidebar { float: inline-start; /* LTR: left, RTL: right */ inline-size: 120px; margin-inline-end: 16px; } /* 内容区 */ .article { max-inline-size: 65ch; /* 最大行内尺寸 */ margin-inline: auto; /* 水平居中 */ padding-inline: 16px; }

float: inline-start 会根据文字方向自动漂浮到开始侧。
