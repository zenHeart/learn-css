user-select CSS 属性演示

1. user-select: none - 完全禁用选择

👆 尝试用鼠标选择下面的文字，你会发现无法选中

这是一段受保护的内容。

你无法通过鼠标选中文本。

适用于版权保护、验证码、游戏界面等场景。

.protected {
  user-select: none;
  -webkit-user-select: none;
}

2. user-select: text - 只允许文本选择

👆 只能选中文本，图标和装饰元素无法选中

📝 这段文字可以选中

🔒 这个图标无法选中

✨ 纯文本内容都可以选择

.text-only {
  user-select: text;
  -webkit-user-select: text;
}

3. user-select: all - 单击全选

👆 只需单击一次，整个元素就会被选中

单击这里，所有文字都会被选中！非常适合「全选」场景。

.click-select-all {
  user-select: all;
  -webkit-user-select: all;
}

4. 混合选择 - 部分可选择

👆 绿色部分可选择，红色部分不可选择

✅ 这段文字可以自由选择复制

🚫 这段文字受保护，无法选择

✅ 这段也可以正常选择

.allowed {
  user-select: text;
  -webkit-user-select: text;
}

.protected {
  user-select: none;
  -webkit-user-select: none;
}

5. 可编辑区域 - 工具栏不可选择

👆 工具栏无法选择，但编辑器内可以正常选中文本

在这里输入文本... 用鼠标选中文本试试，工具栏的文字不会被选中。 
.toolbar {
  user-select: none;
  -webkit-user-select: none;
}

.editor {
  user-select: text;
  -webkit-user-select: text;
}

6. 移动端适配 - iOS Safari

📱 在 iOS 设备上，还需要禁用 -webkit-touch-callout 防止长按弹出菜单

iOS 长按此区域不会弹出复制菜单

.mobile-safe {
  user-select: none;
  -webkit-user-select: none;
  -webkit-touch-callout: none; /* 禁用 iOS 长按菜单 */
}
