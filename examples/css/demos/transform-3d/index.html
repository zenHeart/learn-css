CSS 3D Transform 交互演示

涵盖 rotate3d、scale3d、translate3d、perspective 及常用 3D 效果

rotate3d — 绕任意轴旋转

调整 x、y、z 三个轴的分量，观察元素如何绕任意方向向量旋转。angle 决定旋转角度。

transform: rotate3d(1, 0, 0, 45deg);
旋转元素

拖动滑块调整旋转轴和角度

2D vs 3D Transform 对比

相同的 rotate 值在 2D（rotate）和 3D（rotateY）下的视觉效果差异。注意 2D rotate 仅在平面内旋转，3D rotateY 产生纵深感。

2D rotate(45deg)

2D

元素在 xOy 平面内顺时针旋转 45°，没有纵深变化

3D rotateY(45deg)

3D

绕 Y 轴旋转，元素产生纵深感，右半部看起来更近

3D 立方体

translateZ — 纵深移动

translateZ 正值使元素远离观察者（放大），负值使其靠近（缩小）。需配合 perspective 使用才可见效果。

-80px

远离（缩小）

0

原始位置

+80px

靠近（放大）

scale3d — 3D 缩放

scale3d(sx, sy, sz) 同时在三个轴向上缩放。scaleZ 需要元素有厚度或在 3D 上下文中才明显。

sx=1.5

x 方向放大

sy=0.6

y 方向压缩

sz=2

z 方向放大（厚度）
