OKLCH vs HSL vs RGB 对比

亮度感知对比

HSL 的 L 值与 RGB 一样基于简单算术平均，与人眼实际感知不完全匹配。
OKLCH 的 L 值基于视觉感知模型，更准确反映人眼对明暗的判断。

纯色亮度对比（相同 L 值）

HSL 有问题

红 H=0
L=50%
黄 H=60
L=50%
绿 H=120
L=50%
蓝 H=240
L=50%

问题

虽然 L 都是 50%，但蓝色看起来比黄色暗得多。HSL 的 L 无法准确反映视觉亮度。

OKLCH 正确

红 H=25
L=55%
黄 H=85
L=80%
绿 H=145
L=60%
蓝 H=265
L=45%
✅ 每个颜色的 L 值都经过调整，使其在视觉上亮度一致。

灰度陷阱

HSL 在色相间插值时，颜色容易经过低饱和度的灰色区域，造成"褪色"效果。

红 → 蓝 渐变插值

HSL 灰度陷阱

hsl(0 100% 50%) → ... → hsl(240 100% 50%)

中间色明显发灰，饱和度下降

OKLCH 平滑

oklch(55% 0.22 25) → oklch(45% 0.22 265)

色彩饱和度保持一致，过渡平滑

色阶构建对比

使用 HSL 构建色阶时，通常需要同时调整 H、S、L 三个值才能保持视觉一致性。
OKLCH 只需要调整 L 值即可，因为 C 和 H 是固定的。

蓝色阶（L 值变化）

HSL 需要调 S

hsl(240 100% 95%)
hsl(240 80% 88%)
...

OKLCH 只需调 L

oklch(97% 0.02 250)
oklch(93% 0.04 250)
...
