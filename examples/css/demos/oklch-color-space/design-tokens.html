OKLCH 设计 Token 策略

策略 1：色相饱和度分离

将 H（色相）和 C（饱和度）作为基础变量，通过调整单一变量实现整体色调变化。
当前品牌色相：240°

固定色相，改变亮度构建色阶

oklch(var(--L) var(--brand-chroma) var(--brand-hue))

固定亮度和色相，改变色度（饱和度）

策略 2：语义化 Token

从基础色构建语义化 token（primary、success、danger 等），使设计系统层级清晰。

功能色按钮

语义化背景与文字

卡片标题

这是一张使用语义化 token 的卡片，背景色、文字色都通过 CSS 变量引用。

策略 3：暗色模式适配

OKLCH 的感知均匀性让暗色模式转换更可控。
注意暗色模式下通常需要降低 C 值，避免过于鲜艳。

卡片 1

暗色模式下，饱和度适当降低，避免视觉疲劳。

卡片 2

背景色使用低色度值，保持中性不偏色。

完整 Token 示例

:root { /* 品牌变量 */ --brand-hue: 240; --brand-chroma: 0.22; --brand-lightness-base: 0.55; /* 语义化 token */ --color-primary: oklch(var(--brand-lightness-base) var(--brand-chroma) var(--brand-hue)); --color-primary-hover: oklch(48% var(--brand-chroma) var(--brand-hue)); --color-success: oklch(60% 0.18 145); --color-warning: oklch(75% 0.18 85); --color-danger: oklch(55% 0.22 25); /* 中性色 */ --gray-50: oklch(98% 0.01 var(--brand-hue)); --gray-100: oklch(95% 0.01 var(--brand-hue)); --gray-200: oklch(85% 0.02 var(--brand-hue)); --gray-300: oklch(70% 0.02 var(--brand-hue)); --gray-400: oklch(55% 0.02 var(--brand-hue)); --gray-500: oklch(45% 0.02 var(--brand-hue)); --gray-600: oklch(35% 0.02 var(--brand-hue)); --gray-700: oklch(25% 0.02 var(--brand-hue)); --gray-800: oklch(18% 0.02 var(--brand-hue)); --gray-900: oklch(12% 0.01 var(--brand-hue)); }
