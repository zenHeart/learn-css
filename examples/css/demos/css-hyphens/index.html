CSS hyphens 自动断字演示

💡 hyphens 简介

hyphens 属性控制文本在换行时如何添加连字符（hyphen），可以让文本排版更加美观自然，避免行尾出现大空白。

hyphens 基本原理

hyphens 属性有三个取值：

值 行为 适用场景
none 不添加连字符 不希望断字
manual 只在标记位置断字 精确控制断字位置
auto 浏览器自动断字 多语言内容 
hyphens: auto;

/* 需要配合 lang 属性指定语言 */
html[lang="en"] {
  hyphens: auto;
}

交互式预览

选择断字模式

The Hyphenation algorithm is used to automatically insert hyphens into words so that they wrap across multiple lines. This algorithm is essential for high-quality typography in justified text layouts. It uses a dictionary of hyphenation points to determine where breaks can occur.

软连字符与硬连字符

软连字符 (SHY)

只在需要断行时显示，用于在 HTML 中标记可断字位置：

super&shy;califragilistic&shy;expialidocious 
<!-- HTML 中使用 -->
super&shy;califragilistic

或使用 Unicode：
super­califragilistic

硬连字符

始终显示在文本中：

32-bit architecture, mother-in-law, well-known fact 
<!-- 普通连字符始终显示 -->
mother-in-law
well-known

实际应用场景

文章排版

Typography and Hyphenation

Good typography is essential for readability and overall user experience. The proper use of hyphenation helps maintain consistent line lengths and prevents awkward gaps at the end of lines. When implementing hyphenation on the web, the CSS hyphens property provides fine-grained control over how words are broken across lines. Modern browsers support automatic hyphenation based on language dictionaries, which can significantly improve the visual quality of text layouts. 

article {
  hyphens: auto;
  text-align: justify;
  line-height: 1.8;
}

多语言网站

Typografie und Silbentrennung

Gute Typografie ist für die Lesbarkeit und das Gesamterlebnis unerlässlich. Die korrekte Verwendung von Silbentrennung hilft, gleichmäßige Zeilenlängen beizubehalten und unschöne Lücken am Zeilenende zu vermeiden. 

:lang(de) {
  hyphens: auto;
}

:lang(fr) {
  hyphens: auto;
}
