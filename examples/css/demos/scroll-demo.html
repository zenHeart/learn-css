3. scroll-behavior — 平滑滚动

点击左侧导航，右侧内容区会平滑滚动到对应章节。对比 auto（立即跳转）与 smooth（平滑滚动）。

简介 overflow 详解 scroll-snap 移动端滚动 隐藏滚动条 固定表头

简介

CSS 滚动机制涵盖内容溢出处理、滚动吸附、平滑滚动动画、惯性滚动等多个维度。合理运用这些属性可以显著提升用户滚动体验。

overflow 详解

overflow 属性控制内容超出元素边界时的行为。visible（默认）让内容溢出显示；hidden 裁剪溢出内容；scroll 始终显示滚动条；auto 则在内容溢出时才显示滚动条。合理选择 overflow 值是构建可滚动区域的基础。

scroll-snap

scroll-snap-type 定义滚动吸附的方向和严格程度（mandatory 强制吸附，proximity 接近时吸附）。配合 scroll-snap-align 使用，可以让轮播图、相册等场景达到精确分页效果。scroll-snap-align 可选 start、center、end 三种对齐方式。

移动端滚动

-webkit-overflow-scrolling: touch 在 iOS Safari 中启用惯性滚动（触摸拖拽后的惯性效果）。现代 iOS Safari 已默认启用该行为。overscroll-behavior 可以控制滚动到达边界时的拉扯效果（pull-to-refresh 类行为）。

隐藏滚动条

常见方法有：::-webkit-scrollbar { display: none }（WebKit）、scrollbar-width: none（Firefox）、以及通过 padding 或 margin 技巧腾出空间。隐藏滚动条后需要确保键盘可访问性（tabindex + focus 样式）。

固定表头

固定表头的常用方案：display: block 将表头和表体分成两个独立的 table；position: sticky 让 th 固定在滚动容器的顶部。sticky 方案更简洁，但需要注意 z-index 层级和背景色覆盖问题。

scroll-behavior: smooth;
