CSS @container — 图片画廊布局

画廊容器自动根据宽度调整列数：
· <300px：单列
· 300-600px：双列
· 600-900px：三列
· >=900px：四列

核心代码

.gallery-wrapper { container-type: inline-size; container-name: gallery; } .gallery { display: grid; } /* 单列 */ @container gallery (width < 300px) { .gallery { grid-template-columns: 1fr; } } /* 双列 */ @container gallery (300px <= width < 600px) { .gallery { grid-template-columns: repeat(2, 1fr); } } /* 三列 */ @container gallery (600px <= width < 900px) { .gallery { grid-template-columns: repeat(3, 1fr); } } /* 四列 */ @container gallery (width >= 900px) { .gallery { grid-template-columns: repeat(4, 1fr); } }

容器查询长度单位

cqi — 容器内联尺寸的 1%（相对于容器宽度）
cqw — 容器宽度的 1%（同 cqi）
cqh — 容器高度的 1%
cqmin — cqi 和 cqb 中的较小值
cqmax — cqi 和 cqb 中的较大值
/* 使用 cqi 单位 */ .card-title { font-size: max(1.5em, 1.23em + 2cqi); } .card-image { height: 50cqw; }
