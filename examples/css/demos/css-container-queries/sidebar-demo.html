CSS @container — 侧边栏响应式

侧边栏在不同宽度下呈现不同布局模式：
· 窄（<250px）：垂直堆叠图标模式
· 中等（250-400px）：水平wrap模式
· 宽（>400px）：完整垂直菜单模式

核心代码

.sidebar-wrapper { container-type: inline-size; container-name: sidebar; } /* 窄容器 */ .sidebar-nav { flex-direction: column; } /* 中等容器 */ @container sidebar (width > 250px) { .sidebar-nav { flex-direction: row; flex-wrap: wrap; } } /* 大容器 */ @container sidebar (width > 400px) { .sidebar-nav { flex-direction: column; } }
