基础语法

相对颜色语法：oklch(from <origin-color> <L通道> <C通道> <H通道>)

基准颜色
oklch(55% 0.2 245)
提亮 L+0.2
calc(L + 0.2)
变暗 L-0.2
calc(L - 0.2)
增加色度 *1.5
calc(c * 1.5)
色相偏移 +60°
calc(h + 60)

.button:hover { background: oklch(from var(--primary) calc(L + 0.1) c h); } .button:active { background: oklch(from var(--primary) calc(L - 0.1) c h); }
