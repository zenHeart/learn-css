0.5px 像素实现演示

当前屏幕 DPR: 。在 Retina 屏幕（dpr≥2）下，0.5px 才能显示为真正的细线。

五种方案对比

普通 1px（参考）
height: 1px;
方案一: scale
transform: scaleY(0.5); transform-origin: left top;
方案二: box-shadow
box-shadow: 0 0.5px 0 #color;
方案三: SVG
background-image: url("data:image/svg+xml,...");
方案四: gradient
background: linear-gradient(to bottom, color 50%, transparent 50%); background-size: 100% 2px;
方案五: 原生 0.5px
height: 0.5px;

进阶场景

四边细线边框
position: relative; ::after { border: 1px solid; transform: scale(0.5); }
圆角 + 细线
border-radius: 8px; box-shadow: 0 0 0 0.5px #color;
