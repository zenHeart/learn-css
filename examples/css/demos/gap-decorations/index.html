CSS gap decorations 间隙装饰

为 grid 和 flex 容器的间隙添加样式的 CSS 新特性

gap decorations 属性

属性 说明 候选值
gap-decoration-type 装饰类型 none, corners, sides, edges, all
gap-color 间隙颜色 <color>
gap-width 间隙宽度 <length>, <percentage>
gap-style 间隙样式 solid, dashed, dotted, groove, ridge, inset, outset

gap-decoration-type 各值效果

gap-decoration-type 控制哪些间隙部分应用装饰

none

无装饰效果

corners

只在交叉处装饰（四格交汇点）

sides

只装饰内部边（分隔线）

edges

只装饰外侧边缘

all

所有间隙都装饰（完整网格线）

gap-style 样式效果

gap-style 支持类似 border-style 的各种样式

solid
dashed
dotted
groove
ridge
inset

⚠️ gap decorations 是实验性功能，建议使用 @supports 检测或使用 CSS 背景模拟作为回退方案。

/* @supports 回退 */ @supports (gap-decoration-type: all) { .grid-container { gap-decoration-type: all; gap-color: #e0e0e0; gap-width: 2px; gap-style: solid; } }
