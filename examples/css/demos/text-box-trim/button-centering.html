text-box-trim: 按钮垂直居中

对比：传统 padding vs text-box-trim

传统方式 padding-block: 5px
text-box: trim-both cap alphabetic

左侧红色虚线边框显示元素实际占据的空间。

使用 text-box: trim-both cap alphabetic 后，padding: 10px 在四个方向上真正相等，

无需手动调整上下 padding 来补偿半行距。

不同字体的效果

每种字体的半行距不同，但 text-box-trim 可以统一修剪效果
