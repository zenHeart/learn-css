prefers-color-scheme 暗色模式演示

📝 说明

本页面使用 CSS 变量 + @media (prefers-color-scheme: dark) 实现自动主题切换。

尝试以下方式触发暗色模式：

  • macOS: 系统设置 → 外观 → 暗色
  • Windows: 设置 → 个性化 → 颜色 → 选择暗色
  • iOS: 设置 → 显示与亮度 → 暗色
  • 或使用浏览器开发者工具模拟

4. CSS 实现代码

/* 1. 定义 CSS 变量（默认亮色） */
:root {
  --bg-primary: #ffffff;
  --text-primary: #1a1a1a;
  --link-color: #0066cc;
}

/* 2. 暗色模式覆盖 */
@media (prefers-color-scheme: dark) {
  :root {
    --bg-primary: #1a1a1a;
    --text-primary: #ffffff;
    --link-color: #66b3ff;
  }
}

/* 3. 使用变量 */
body {
  background: var(--bg-primary);
  color: var(--text-primary);
}

a {
  color: var(--link-color);
}

5. JavaScript 检测

// 检测当前主题
const isDark = window.matchMedia('(prefers-color-scheme: dark)').matches;

// 监听主题变化
window.matchMedia('(prefers-color-scheme: dark)')
  .addEventListener('change', (e) => {
    if (e.matches) {
      console.log('切换到暗色模式');
    } else {
      console.log('切换到亮色模式');
    }
  });
