多列布局（Multi-column Layout）是 CSS2.1 之后引入的重要布局模块。它允许我们使用纯 CSS 将一段连续文本内容分布到多列中，呈现出类似报纸、杂志的排版效果。与 Flexbox 和 Grid 布局不同，columns 面向的是连续文本内容，而非独立盒子的排列。

💡 核心原则：columns 不是把"一个个盒子"排成列，而是把一段连续文本切分成多列。

columns 属性接受两个值：列宽和列数。例如 columns: 200px 3 表示列宽至少 200px，最多 3 列。浏览器会根据容器实际宽度自动计算最终列数——如果容器宽度足够放下 3 列，就显示 3 列；如果只够 2 列，则自动调整为 2 列。

column-width 单独使用时表示"最小列宽"，浏览器会尽可能多地分列。column-count 单独使用时表示"最大列数"，如果内容不足以填满所有列，最后一列可能会留空。

📌 column-gap 默认值是 normal（约 1em），不是 0。设置 column-gap: 0 才能让列与列之间无缝隙。

在实际项目中，columns 常用于文章详情页的分栏、词条列表的紧凑排列、或者瀑布流文字墙效果。配合媒体查询可以轻松实现响应式：在大屏上显示多列，在小屏上自动切换为单列。

column-rule 属性用于在列之间添加分割线，语法与 border 完全一致。它由宽度（column-rule-width）、样式（column-rule-style）和颜色（column-rule-color）三部分组成。column-rule 不会占用 column-gap 的空间——它绘制在列间距的中间。

columns: <column-width> <column-count>
当前: columns: 200px 3;

column-span：跨列元素

column-span: all 让子元素跨越所有列，常用于章节标题、插图等需要贯穿全栏的元素。

column-span 使用场景

场景说明
章节标题文章分栏后，H2/H3 标题跨越所有列作为章节分隔

引用块大段引用跨越所有列，突出显示

✅ balance（默认）：各列高度尽可能接近，适合文章阅读

📌 在固定高度容器下，两种模式差异最明显

Columns vs Flexbox vs Grid 场景对比

三种布局方式有各自擅长的场景，理解本质差异才能做出正确选择。

📰

本质差异总结：
Columns：把连续文本切分成列 → 内容驱动
Flexbox：把独立 item 排成一行/列 → 方向驱动
Grid：在二维空间中精确放置 item → 空间驱动

Q3: justify-content: center 在 columns 布局中是否生效？

B. 不生效，columns 不是弹性盒子

D. 取决于 column-count 的值

Q4: column-span: all 的作用是？

A. 元素跨越所有列，但保持原有宽度
B. 元素跨越所有列，脱离列布局流
C. 元素跨越两列（默认值）
D. 元素宽度变为所有列宽之和

Q5: column-fill: auto vs balance 的主要区别是？

A. auto 让列数更多，balance 让列数更少
B. balance 只适用于单列，auto 适用于多列
C. balance 让各列高度均衡，auto 先填满第一列
D. 两者没有区别，只是浏览器优化不同
