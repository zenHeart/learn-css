滚动模式切换

html { scroll-behavior: smooth; }

提示 点击上方导航链接或下方按钮测试滚动行为。

1

第一章：开始

这是第一章的内容。scroll-behavior 属性可以让你在点击锚点链接时实现平滑滚动效果，而不是立即跳转到目标位置。

这个属性在创建单页应用（SPA）和长页面导航时特别有用，可以提供更好的用户体验。

平滑滚动可以配合 CSS 的 scroll-margin-top 属性来调整滚动位置，避免固定导航栏遮挡内容。

2

第二章：语法

scroll-behavior 属性的语法非常简单，只需要在 html 元素上设置即可：

scroll-behavior: auto - 默认值，浏览器立即跳转到目标位置

scroll-behavior: smooth - 使用平滑动画过渡到目标位置

3

第三章：应用场景

1. 单页应用导航 - 创建平滑的章节切换效果

2. 目录导航 - 让用户快速定位内容

3. 返回顶部按钮 - 平滑滚动回页面顶部

4. 图片画廊 - 平滑滚动到特定图片

4

第四章：JavaScript 配合

除了 CSS 属性，你还可以使用 JavaScript 实现更复杂的滚动效果：

element.scrollIntoView({ behavior: 'smooth' }) - 平滑滚动到元素

window.scrollTo({ top: 0, behavior: 'smooth' }) - 平滑滚动到顶部

5

第五章：注意事项

使用 scroll-behavior 时需要注意：

1. 性能考虑 - 平滑滚动会增加浏览器渲染负担

2. 尊重用户偏好 - 使用 prefers-reduced-motion 媒体查询

3. 移动端适配 - 确保在触摸设备上也能正常工作
