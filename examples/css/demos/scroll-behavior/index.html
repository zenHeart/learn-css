简介

scroll-behavior 是 CSS 属性，用于控制用户点击锚点链接或程序触发滚动时，浏览器的滚动行为方式。 设置为 smooth 时，浏览器会以平滑动画的方式滚动到目标位置； 设置为 auto 或 instant 时，则是即时跳转。

核心概念

scroll-behavior: smooth 开启后，所有通过锚点链接（<a href="#id">） 触发的滚动都会使用平滑动画过渡。这种行为对于长页面导航特别有用，可以帮助用户理解自己在页面中的位置。

注意：scroll-behavior 不仅可以应用于 <html> 元素， 还可以应用于任何可滚动的容器元素，控制该容器内部的滚动行为。

使用场景

单页应用（SPA）：在单页应用中，平滑滚动可以帮助用户感知页面结构。

文档导航：长文档中使用平滑滚动到锚点，提升阅读体验。

固定导航栏：配合 scroll-padding-top 可以防止内容被固定导航栏遮挡。

最佳实践

1. 尊重用户偏好：使用 @media (prefers-reduced-motion: reduce) 为减少动画偏好用户关闭平滑滚动。

2. 配合 scroll-padding：使用固定导航栏时，记得设置 scroll-padding-top 防止内容被遮挡。

3. 性能考虑：在性能敏感的场景下，可考虑使用即时滚动。

JavaScript scrollIntoView() 对比

点击下方按钮，使用 JavaScript 方式滚动到目标区域。注意：JS 的 scrollIntoView() 会覆盖 CSS 的 scroll-behavior 设置。 

const element = document.getElementById('section-3');
element.scrollIntoView({
  behavior: 'smooth',  // 或 'instant', 'auto'
  block: 'start'      // 'center', 'end', 'nearest'
});
