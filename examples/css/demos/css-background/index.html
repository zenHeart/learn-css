CSS background 背景属性详解

涵盖 background-color, background-image, background-repeat, background-position, background-size, background-attachment, background-clip, background-origin

1. background-image 渐变背景

background: linear-gradient(135deg, #667eea, #764ba2, #f093fb);

2. background-repeat 重复方式

background-repeat: no-repeat;

3. background-attachment 固定方式

background-attachment: scroll;

4. background-clip 裁剪区域

background-clip: border-box;

5. 多层背景叠加

background-image: url('pattern.svg'), linear-gradient(135deg, #667eea, #764ba2); background-size: 50px 50px, 100% 100%;
