CSS letter-spacing 响应式调整

响应式 letter-spacing 原理

随着字体大小增加，字符间距自动收紧。使用 calc((1em - 1rem) / -10) 建立字号与间距的关联，clamp() 限定范围。

16px
字号: 16px
当前 letter-spacing: 0em
效果: 正常间距
响应式 letter-spacing 示例文字
font-size: 16px; letter-spacing: clamp(-0.05em, calc((1em - 1rem) / -10), 0em);
