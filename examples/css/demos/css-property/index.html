CSS @property 交互演示

基于 learn-css 仓库 · Houdini Properties & Values API

1. @property 基础注册

syntax定义类型 · inherits控制继承 · initial-value设置默认值

@property --size { syntax: ''; inherits: false; initial-value: 80px; }

2. 关键对比：未注册 vs 已注册自定义属性的动画

未注册的自定义属性无法做关键帧动画（浏览器不知其类型） · 已注册的属性可以平滑过渡

未注册
无法动画
已注册
平滑过渡
/* 未注册：动画无效，因为浏览器不知道 --size 是什么类型 */ .unregistered-box { width: var(--unreg-size); animation: unregAnim 1.5s ease-in-out infinite; } /* 已注册：明确 syntax: ''，动画正常工作 */ .registered-box { width: var(--reg-size); /* 使用注册属性 */ animation: regAnim 1.5s ease-in-out infinite; }

3. 尺寸 + 颜色联合动画

--size 控制宽高 · --bg-color 控制背景色，两者同步动画

size + color
@property --size { syntax: ''; inherits: false; initial-value: 80px; } @property --bg-color { syntax: ''; inherits: false; initial-value: #a371f7; } .size-box { width: var(--size); height: var(--size); background: var(--bg-color); } @keyframes sizePulse { 0% { --size: 60px; --bg-color: #3498db; } 50% { --size: 120px; --bg-color: #e74c3c; } 100% { --size: 60px; --bg-color: #3498db; } }

4. 角度旋转动画（--rotation）

--rotation 类型为 <angle>，支持 0deg → 360deg 旋转

旋转
@property --rotation { syntax: ''; inherits: false; initial-value: 0deg; } .rotation-box { transform: rotate(var(--rotation)); } @keyframes rotateAnim { to { --rotation: 360deg; } }

5. 进度条动画（--progress）

--progress 类型为 <percentage>，驱动 linear-gradient 颜色停止点

@property --progress { syntax: ''; inherits: false; initial-value: 25%; } .bar { background: linear-gradient(to right, #00d230 var(--progress), #1a1a1a var(--progress)); } @keyframes progressAnim { 0% { --progress: 0%; } 50% { --progress: 80%; } 100% { --progress: 0%; } }

6. 渐变色动画（--color-start / --color-end）

两个 --color-start --color-end 颜色属性同步变化

@property --color-start { syntax: ''; inherits: false; initial-value: #3498db; } @property --color-end { syntax: ''; inherits: false; initial-value: #e74c3c; } .gradient-box { background: linear-gradient(45deg, var(--color-start), var(--color-end)); } @keyframes colorShift { 0% { --color-start: #3498db; --color-end: #e74c3c; } 50% { --color-start: #9b59b6; --color-end: #f39c12; } 100% { --color-start: #3498db; --color-end: #e74c3c; } }

7. scale 缩放动画（--scale）

--scale 类型为 <number>，控制 scale() 变换

scale
@property --scale { syntax: ''; inherits: false; initial-value: 1; } .scale-box { transform: scale(var(--scale)); } @keyframes scaleAnim { 0% { --scale: 1; } 50% { --scale: 1.6; } 100% { --scale: 1; } }

CSS @property 支持所有现代浏览器（Chrome 85+、Firefox 128+、Safari 16.4+）。演示基于 learn-css 仓库示例风格。
