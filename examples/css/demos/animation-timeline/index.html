CSS animation-timeline 动画时间线

动画时间线控制 | 交互演示

浏览器支持状态

实验性 Chrome 115+（需要启用实验性功能）

不支持 Firefox / Safari / Edge

需要在 Chrome 中启用 "Experimental Web Platform Features" 标志才能使用此功能。

滚动进度条（animation-timeline: scroll()）

滚动进度

向下滚动查看进度条动画效果。

animation-timeline

将动画与滚动位置关联。

视图范围

animation-range 控制动画应用的滚动范围。

@keyframes progress { from { transform: scaleX(0); } to { transform: scaleX(1); } } .progress { animation: progress linear; animation-timeline: scroll(root block); }

视图进入动画（animation-timeline: view()）

@keyframes fade-in { from { opacity: 0; } to { opacity: 1; } } .element { animation: fade-in linear; animation-timeline: view(); animation-range: entry 0% entry 100%; }

说明 元素进入视口时触发动画。

代码示例

/* 滚动驱动动画 */ @keyframes progress { from { transform: scaleX(0); } to { transform: scaleX(1); } } .progress { animation: progress linear; animation-timeline: scroll(root block); } /* 视图驱动动画 */ @keyframes fade-in { from { opacity: 0; transform: translateY(20px); } to { opacity: 1; transform: translateY(0); } } .reveal { animation: fade-in linear; animation-timeline: view(); animation-range: entry 0% entry 100%; }
