animation-timeline: view()

CSS 原生滚动驱动动画 — 元素进入视口时触发动画

⚠️ 滚动驱动动画需要 Chrome 115+ 或 Firefox 123+。 Safari 技术预览版部分支持。

页面滚动进度条

页面顶部的进度条会随着滚动自动填充，这是通过 animation-timeline: scroll() 实现的。

滚动页面查看进度 ↑
/* 使用 scroll() 绑定到根元素滚动 */
animation: fill-progress linear both;
animation-timeline: scroll(root block);

@keyframes fill-progress {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}

/* view() 根据元素可见性进度驱动动画 */
animation: fade-slide linear both;
animation-timeline: view();

/* 交错：每个卡片延迟 8% 触发 */
animation-range: entry 0% contain 35%;   /* 第1张 */
animation-range: entry 8% contain 43%;   /* 第2张 */

@keyframes fade-slide {
  from {
    opacity: 0;
    transform: translateY(50px) scale(0.95);
  }
  to {
    opacity: 1;
    transform: translateY(0) scale(1);
  }
}
