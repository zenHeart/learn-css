prefers-reduced-motion 减少动效演示

💡 提示：本页面演示了各种 CSS 动画效果，以及它们在启用「减少动效」时的行为。
⚠️ 如何启用减少动效：
  • macOS: 系统设置 → 辅助功能 → 显示 → 减弱动态效果
  • Windows: 设置 → 轻松使用 → 显示 → 在 Windows 中显示动画
  • iOS: 设置 → 辅助功能 → 减弱动态效果

CSS 实现代码

/* 1. 禁用所有非必要动画 */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

/* 2. 保留关键动画（加载指示器） */
.loading-spinner {
  animation: spin 1s linear infinite;
}

@media (prefers-reduced-motion: reduce) {
  .loading-spinner {
    /* 加载指示器保留，但可以用静态图标替代 */
    animation: none;
  }
}

/* 3. 选择性禁用动画 */
.fade-in {
  animation: fadeIn 0.5s ease-out;
}

@media (prefers-reduced-motion: reduce) {
  .fade-in {
    animation: none;
    opacity: 1;
    transform: translateX(0);
  }
}

JavaScript 检测

// 检测用户偏好
const prefersReducedMotion = window.matchMedia(
  '(prefers-reduced-motion: reduce)'
).matches;

console.log('减少动效:', prefersReducedMotion);

// 监听变化
window.matchMedia('(prefers-reduced-motion: reduce)')
  .addEventListener('change', (e) => {
    if (e.matches) {
      console.log('用户启用了减少动效');
      // 停止非必要动画
    } else {
      console.log('用户禁用了减少动效');
      // 恢复动画
    }
  });

常见使用场景

场景 处理方式
页面入场动画 使用 prefers-reduced-motion 禁用
加载指示器 保留或用静态图标替代
模态框动画 禁用过渡效果
滚动动画 禁用 scroll-behavior
悬停效果 保留（用户可主动触发）

最佳实践

  • 尊重用户设置：优先使用媒体查询，而不是依赖 JavaScript 检测
  • 保留功能性动画：加载指示器等让用户知道系统在工作
  • 使用过渡而非动画：过渡比动画更轻量，用户更容易控制
  • 提供备选方案：考虑静态替代方案（如静态加载图标）
  • 测试：在真实设备上测试，特别是辅助功能设置
