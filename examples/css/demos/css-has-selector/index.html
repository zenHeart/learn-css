CSS :has() 关系选择器

父选择器 | 兄弟选择 | 逻辑组合 | 表单状态

案例 1父元素选择

普通卡片

无 featured 商品

Featured 卡片

包含 .featured 元素

/* 选择包含 .featured 的 section-card */ .section-card:has(.featured) { background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); border-color: #667eea; }

当卡片包含 .featured 元素时，背景会变成渐变色。

案例 2兄弟选择

主标题 H1

副标题 H2（紧跟在 H1 后面）

/* 选择紧邻 h2 的 h1 */ h1:has(+ h2) { color: #f59e0b; border-bottom: 2px solid #f59e0b; }

当 h1 后面紧跟 h2 时，h1 会获得特殊样式。

案例 3逻辑组合

无媒体
/* OR: 包含 video 或 audio */ body:has(video, audio) { --indicator: 1; } /* AND: 同时包含 video 和 audio */ body:has(video):has(audio) { --indicator: 2; } /* NOT: 不包含 .ad */ article:has(.ad):not(:has(.featured)) { opacity: 0.6; }

使用 OR (`,`) 和 AND (嵌套 :has) 关系组合选择器。

案例 4表单状态

/* 表单获得焦点时 */ form:has(input:focus) { border-color: #3b82f6; } /* 复选框选中时的 label */ label:has(input:checked) { background: #22c55e22; border-color: #22c55e; }

根据表单元素的状态改变父容器样式。

案例 5布局状态

容器内容

/* 包含溢出元素的容器 */ .container:has(.overflow) { outline: 2px dashed #f59e0b; }

检测容器内是否有溢出内容并显示指示器。
