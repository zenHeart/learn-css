CSS writing-mode 书写模式演示

💡 writing-mode 简介

writing-mode 属性定义了文本的排列方向，可以实现水平、垂直等多种书写模式，适合不同语言和设计需求。

writing-mode 取值对比

每种 writing-mode 值的文本排列方式：

值 文本方向 行方向 适用场景
horizontal-tb 水平（从左到右） 从上到下 默认，适合大多数语言
vertical-rl 垂直 从右到左 中文、日文垂直排版
vertical-lr 垂直 从左到右 特殊语言需求
sideways-rl 垂直（侧排） 从右到左 现代侧排设计
sideways-lr 垂直（侧排） 从左到右 现代侧排设计

horizontal-tb - 水平从上到下（默认值）

writing-mode: horizontal-tb

文本水平排列，行从上到下排列。这是默认值，适合大多数语言（中文、英文等）。

君不见黄河之水天上来，奔流到海不复回。
君不见高堂明镜悲白发，朝如青丝暮成雪。 
writing-mode: horizontal-tb;

vertical-rl - 垂直从右到左

writing-mode: vertical-rl

文本垂直排列，行从右到左排列。适合中文、日文等垂直书写场景。

君不见黄河之水天上来
奔流到海不复回
君不见高堂明镜悲白发
朝如青丝暮成雪 
writing-mode: vertical-rl;
height: 180px;

vertical-lr - 垂直从左到右

writing-mode: vertical-lr

文本垂直排列，行从左到右排列。适合某些特殊语言需求。

君不见黄河之水天上来
奔流到海不复回
君不见高堂明镜悲白发
朝如青丝暮成雪 
writing-mode: vertical-lr;
height: 180px;

sideways-rl - 侧排从右到左

writing-mode: sideways-rl

文本垂直排列，行从右到左排列，但文本保持正向显示。

君不见黄河之水天上来
奔流到海不复回
君不见高堂明镜悲白发
朝如青丝暮成雪 
writing-mode: sideways-rl;
height: 180px;

sideways-lr - 侧排从左到右

writing-mode: sideways-lr

文本垂直排列，行从左到右排列，但文本保持正向显示。

君不见黄河之水天上来
奔流到海不复回
君不见高堂明镜悲白发
朝如青丝暮成雪 
writing-mode: sideways-lr;
height: 180px;

实用场景示例

垂直书名

春风化雨润物无声
明月松间照
清泉石上流 
/* 垂直书名样式 */
.book-cover {
  width: 150px;
  height: 220px;
  writing-mode: vertical-rl;
  text-orientation: upright;
  font-size: 20px;
}

垂直招牌

欢迎光临
暂停营业
正在营业
/* 垂直招牌样式 */
.vertical-sign {
  writing-mode: vertical-rl;
  height: 200px;
  padding: 15px;
  border: 2px solid #f59e0b;
  border-radius: 6px;
  font-size: 24px;
}

配合 text-orientation 使用

text-orientation 属性可以控制垂直模式下字符的方向：

text-orientation 值 效果
mixed 西文字符旋转 90°，中文保持正向（默认）
upright 所有字符都保持正向
sideways 所有字符都旋转 90° 
/* 保持所有字符正向 */
.vertical-text {
  writing-mode: vertical-rl;
  text-orientation: upright;
}
