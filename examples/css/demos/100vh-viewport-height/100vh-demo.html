📐 100vh 移动端视口高度问题

理解 CSS Viewport 单位与移动端 100vh 的经典问题

Viewport 单位基础

Viewport 单位是相对于浏览器视口尺寸的 CSS 长度单位，在响应式设计中非常有用。

单位 含义 说明
vw Viewport Width 视口宽度的 1%
vh Viewport Height 视口高度的 1%
vmin Viewport Minimum vw/vh 中较小值的 1%
vmax Viewport Maximum vw/vh 中较大值的 1%

基本用法

.hero { height: 100vh; /* 100% 视口高度 */ width: 100vw; /* 100% 视口宽度 */ } .sidebar { width: 20vmin; /* 较小边的 20% */ }

动态视口单位（现代浏览器）

💡 新增单位：Chrome 108+、Safari 15+ 支持动态视口单位

单位 含义 适用场景
dvh Dynamic VH 当前可见视口高度（推荐）
svh Small VH 地址栏展开时的视口高度
lvh Large VH 地址栏收起时的视口高度

100vh 在移动端的问题

⚠️ 问题：在 iOS Safari 和 Android Chrome 中，100vh 并不等于屏幕可见区域的高度。

问题原因

移动端浏览器将 vh 基于"最大可能视口高度"计算，而非"当前可见视口高度"。

视口组成示意图
📱 地址栏 (60px) 不包含在可见区域
100vh = 全部高度

实际可见区域可能小于 100vh

📍 导航栏 (50px)

实际表现

/* 桌面浏览器：正常占满整个窗口 */ .full-height { height: 100vh; } /* 移动端 Chrome/Safari： - 地址栏展开时：底部内容被遮挡 - 地址栏收起时：底部有多余空白 - 滚动时：视口高度不断变化

浏览器兼容性

Chrome (Android) ⚠️ Safari (iOS) ⚠️ Chrome 108+ ✅ Safari 15+ ✅ Firefox 126+ ✅

解决方案

方案一：使用 dvh（推荐）

  • 最简单直接
  • 现代浏览器支持
  • 自动适应地址栏变化
  • 需要 fallback
height: 100dvh;

方案二：min-height 变通

  • 兼容性最好
  • 不需要 JavaScript
  • 可能有边界情况
  • 配合 dvh fallback
min-height: 100vh; min-height: 100dvh;

方案三：JS 动态计算

  • 完全可控
  • 所有浏览器支持
  • 需要 JavaScript
  • 可能影响性能
--vh: ${vh}px;

完整代码示例

方法 1：dvh + fallback

.full-page { /* 基础：100vh 作为 fallback */ height: 100vh; /* 增强：使用 dvh */ height: 100dvh; } /* 或使用 @supports 特性检测 */ @supports (height: 100dvh) { .full-page { height: 100dvh; } }

方法 2：JavaScript 动态计算

// JavaScript const setFullHeight = () => { const vh = window.innerHeight * 0.01; document.documentElement.style.setProperty('--vh', `\${vh}px`); }; setFullHeight(); window.addEventListener('resize', setFullHeight); // CSS .full-height { height: calc(var(--vh, 1vh) * 100); }

方法 3：处理安全区域（刘海屏）

.safe-area { padding-top: env(safe-area-inset-top); padding-bottom: env(safe-area-inset-bottom); padding-left: env(safe-area-inset-left); padding-right: env(safe-area-inset-right); }

💡 建议：优先使用 100dvh 作为主要方案，配合 100vh 作为 fallback，确保在所有浏览器中正常工作。
