Factory 模式

Factory 模式用于生成结构化的测试数据，避免手动创建每个文档。

📦 UserFactory

class UserFactory {
  static create(data = {}) {
    return {
      name: data.name || this.randomName(),
      email: data.email || this.randomEmail(),
      age: data.age || this.randomAge(),
      createdAt: new Date()
    };
  }
  
  static createMany(count) {
    return Array.from(
      { length: count }, 
      () => this.create()
    );
  }
}

🛒 OrderFactory

class OrderFactory {
  static create(data = {}) {
    return {
      orderNo: `ORD${Date.now()}`,
      userId: data.userId,
      items: data.items || [],
      totalAmount: this.calcTotal(),
      status: data.status || 'pending'
    };
  }
}

⚙️ 播种配置

const { Seeder } = require('mongo-seeding');

const seeder = new Seeder({
  mongodb: {
    host: 'localhost',
    port: 27017,
    database: 'test'
  }
});
