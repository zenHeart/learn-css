核心公式
devicePixelRatio = 屏幕物理像素分辨率 / CSS 像素分辨率 // Retina 屏幕示例 devicePixelRatio = 1920 / 960 = 2 // 含义：1 个 CSS 像素实际渲染为 2×2 = 4 个物理像素
物理像素：显示器实际发光点，由 R/G/B 子像素组成
dip / CSS 像素：CSS 和 JS 使用的抽象单位，设备无关
DPR 视觉效果对比

1 CSS px = 1×1 物理像素

DPR = 2

1 CSS px = 2×2 物理像素

DPR = 3

1 CSS px = 3×3 物理像素

Canvas 中的 DPR 处理

❌ 不考虑 DPR（模糊）

const canvas = getElementById('c1'); canvas.width = 300; canvas.height = 150;
DPR=2 时，物理像素只有 300×150，放大后模糊

✅ 考虑 DPR（清晰）

const dpr = devicePixelRatio; canvas.width = 300 * dpr; canvas.height = 150 * dpr; canvas.style.width = '300px'; canvas.style.height = '150px'; ctx.scale(dpr, dpr);
物理像素 = CSS 像素 × DPR，清晰锐利
