单行 vs 多行省略号

单行省略号

这是单行文本，超出的部分会用省略号显示。 
white-space: nowrap;
overflow: hidden;
text-overflow: ellipsis;

多行省略号 (-webkit)

这是多行文本，第二行末尾会显示省略号。超出两行的部分被隐藏。 
display: -webkit-box;
-webkit-box-orient: vertical;
-webkit-line-clamp: 2;
overflow: hidden;

line-clamp vs -webkit-line-clamp

属性浏览器支持说明
-webkit-line-clampChrome 1+, Safari 3+, Edge 17+WebKit 前缀，兼容性好
line-clamp (标准)Firefox 121+CSS Working Group 标准
/* 兼容性最佳写法：同时写两种属性 */
.line-clamp {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;   /* Safari/Chrome */
  line-clamp: 3;          /* Firefox 121+ */
  overflow: hidden;
}

  -webkit-box-orient: vertical;

}

判断题

1. 只要设置了 text-overflow: ellipsis，文本就会显示省略号？

正确
错误

答案：错误 — 必须同时设置 white-space: nowrap 和 overflow: hidden

2. word-spacing 会影响省略号 … 的位置吗？

会
不会

答案：不会 — word-spacing 只作用于空格字符，省略号不是空格

3. flex 子元素使用省略号时，为什么需要设置 min-width: 0？

正确
错误

答案：错误 — min-width: auto 是默认值，flex 子元素默认不能收缩到 0 以下

4. -webkit-line-clamp 和 line-clamp 同时写可以兼容更多浏览器？

正确
错误

答案：正确 — -webkit-line-clamp 兼容 Safari/Chrome，line-clamp 兼容 Firefox 121+
