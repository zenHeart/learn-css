clamp() CSS — 响应式值控制的利器

核心公式
clamp(最小值, 首选值, 最大值)
在最小值和最大值之间，优先使用基于视口的计算值
/* 语法 */ font-size: clamp(最小值, 首选值, 最大值); /* 示例：字体大小在 14px ~ 24px 之间响应式变化 */ font-size: clamp(14px, 2.5vw, 24px); /* 等效于 */ min(最大值, max(最小值, 首选值))

clamp() 常用场景
/* 1. 响应式字体（最常用）*/ font-size: clamp(1rem, 2.5vw, 2rem); /* 2. 响应式间距 */ padding: clamp(1rem, 3vw, 3rem); gap: clamp(8px, 2vw, 24px); /* 3. 响应式宽度/高度 */ width: clamp(200px, 70vw, 1000px); /* 4. 响应式网格列（配合 minmax） */ grid-template-columns: repeat(auto-fit, minmax(clamp(150px, 30vw, 300px), 1fr)); /* 5. 响应式圆角 */ border-radius: clamp(4px, 1vw, 20px); /* 6. 响应式阴影 */ box-shadow: 0 clamp(2px, 0.5vw, 10px) clamp(4px, 1vw, 20px) rgba(0,0,0,0.1);
