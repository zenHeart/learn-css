代码示例

/* 完整 animation 缩写 */ /* animation: name duration timing-function delay iteration-count direction fill-mode; */ .element { animation: slideIn 0.5s ease-out 0s 1 normal forwards; } /* 多个动画 */ .multi { animation: fadeIn 0.5s ease forwards, slideIn 0.5s ease 0.2s forwards, pulse 2s ease-in-out infinite 1s; }
