shape-outside 案例三：高级用法

对比展示

shape-margin 间距对比

无 shape-margin：文字紧贴着圆形边缘流动。圆形排版效果本身已经比矩形柔和很多，但文字与图片之间没有额外的呼吸空间。

在某些场景下，紧贴的设计可以最大化利用空间，适合内容密集型的页面。

有 shape-margin: 30px：文字与圆形之间保持 30px 的间距。这个间距让排版更加透气，也给了文字呼吸的空间。

shape-margin 会在 shape-outside 定义的形状外围增加指定的空白距离。

适合标题区域、重点内容展示等需要强调留白的场景。

/* 无间距 */ .shape-no-margin { shape-outside: circle(50%); } /* 有间距 */ .shape-with-margin { shape-outside: circle(50%); shape-margin: 30px; }
对称排版

双图对称环绕

左右两侧各放置一个圆形头像，中间区域让文字自由流动。这是一种经典的双栏对称排版方式。

文字从顶部开始，先绕过左侧圆形，流到中间后绕过右侧圆形，最后在底部汇合。

这种排版常见于访谈类文章、人物介绍页面。两侧的图片形成视觉锚点，中间的文字内容流畅自然。

配合不同的 shape-outside 值（圆形、椭圆、多边形），可以创造出丰富多样的对称排版效果。

.left-circle { float: left; shape-outside: circle(50% at 50% 50%); shape-margin: 20px; } .right-circle { float: right; shape-outside: circle(50% at 50% 50%); shape-margin: 20px; }
复杂形状

心形文字环绕

使用多边形可以创建任意复杂形状的文字环绕效果。心形是一种广受欢迎的图形，常用于爱情、浪漫主题的页面。

定义心形需要 16 个顶点，按照逆时针或顺时针方向依次连接。顶点数越多，心形越精细。

实际应用中，心形常用 clip-path 配合渐变背景或图片来呈现，文字则通过 shape-outside 围绕心形流动。

这种效果适合情人节专题、婚礼请柬、个人博客等浪漫主题网站。

注意：polygon 顶点数越多，浏览器计算量越大，如需高性能可考虑简化为更少顶点的近似心形。

.heart-shape { shape-outside: polygon( 50% 5%, 58% 15%, 65% 8%, 75% 18%, 82% 15%, 90% 28%, 88% 40%, 80% 52%, 50% 80%, 20% 52%, 12% 40%, 10% 28%, 18% 15%, 25% 18%, 35% 8%, 42% 15% ); }
图片形状

使用图片定义形状

使用 url() 函数可以引用图片的 Alpha 通道来定义形状。通过 shape-image-threshold 控制透明度阈值。

只有透明度超过阈值的像素才会形成文字排除区域。例如 shape-image-threshold: 0.5 表示透明度超过 50% 的区域才形成形状。

这种技术适合使用特殊形状的品牌图形，如公司 Logo、云朵、不规则徽章等。文字会围绕这些复杂形状精确流动。

配合 Shape Path Editor 等浏览器 DevTools 插件，可以实时预览和调整形状效果。

/* 使用图片定义形状 */ .shape-from-image { shape-outside: url('cloud-shape.png'); shape-image-threshold: 0.5; /* 透明度 > 50% 形成形状 */ shape-margin: 25px; }
