shape-outside 案例二：多边形文字环绕

多边形

菱形图片环绕

使用 polygon() 可以创建任意多边形形状的文字环绕。菱形是一种常见且美观的形状。

定义菱形的四个顶点：顶部中心、右中间、底部中心、左中间。文字会沿着这个菱形轮廓流动。

注意：shape-outside 定义的是文字排除区域，而 clip-path 裁剪的是元素本身的可见区域。两者配合使用才能达到最佳效果。

菱形排版常见于个人简历、作品集等展示型页面，可以突出重点图片同时保持良好的文字可读性。

.diamond-img { float: left; width: 200px; height: 200px; shape-outside: polygon(50% 0, 100% 50%, 50% 100%, 0 50%); clip-path: polygon(50% 0, 100% 50%, 50% 100%, 0 50%); shape-margin: 20px; }
斜边效果

梯形/斜边图片环绕

使用 polygon() 创建梯形效果，顶部边缘向内倾斜。这是一种经典的杂志排版风格。

梯形形状可以让文字在图片上方有更多流动空间，同时保持图片下方的完整性。

通过调整多边形顶点，可以控制斜边的角度和位置，创造出不同的视觉效果。

这种排版方式常用于采访类文章，被采访者的照片采用斜边设计，配合引用文字，层次分明。

.trapezoid-img { shape-outside: polygon( 0 0, /* 左上 */ 100% 10%, /* 右上（向内倾斜 10%） */ 100% 100%, /* 右下 */ 0 100% /* 左下 */ ); clip-path: polygon( 0 0, 100% 10%, 100% 100%, 0 100% ); }
三角形

三角形图片环绕

使用三点多边形可以创建三角形环绕效果。polygon(50% 0, 100% 100%, 0 100%) 定义了一个倒置的三角形。

三角形的顶部是文字流动的起点，底部是开放的，文字会在两侧自然流动。

三角形形状在现代网页设计中常用于创造动态感，适合科技、艺术等创意类网站。

.triangle-img { shape-outside: polygon(50% 0, 100% 100%, 0 100%); clip-path: polygon(50% 0, 100% 100%, 0 100%); }
圆角斜边

带圆角的斜边图片

使用 inset() 函数配合 round 参数可以创建带圆角的斜边形状。

inset(0 0 0 0 round 0 80px 0 0) 表示：四角中右上角有 80px 圆角，其他角为 0。

这种设计常见于产品展示页面，可以软化几何形状的硬朗感，同时保持现代感。

圆角斜边让整个页面显得更加柔和友好，适合消费品、生活方式类网站。

.slanted-img { shape-outside: inset(0 0 0 0 round 0 80px 0 0); clip-path: inset(0 0 0 0 round 0 80px 0 0); }
