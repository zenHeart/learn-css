shape-outside 案例一：圆形头像文字环绕

基础用法

圆形头像 + 文字环绕

这是一个常见的排版场景：用户头像为圆形，文章正文围绕头像流动。使用 shape-outside: circle(50%) 可以轻松实现这一效果。

文字会自然地绕过圆形头像，在其右侧和下方流动，而不是像普通浮动元素那样形成一个矩形排除区域。这使得整个排版更加自然、美观。

配合 shape-margin 可以增加文字与图片之间的间距，避免文字紧贴着圆形边缘。通过调整 shape-margin 的值，可以控制文字与图片的贴合程度。

.avatar { float: left; width: 150px; height: 150px; border-radius: 50%; object-fit: cover; shape-outside: circle(50% at 50% 50%); shape-margin: 20px; }
偏心圆

偏心圆形头像

通过调整圆心位置，可以创建偏心圆效果。circle(50% at 30% 50%) 将圆心设置在左侧 30% 的位置。

这种效果常用于引导文字流向，使图片在页面中占据更多视觉空间，同时文字仍然围绕圆形流动。

偏心圆在杂志排版中很常见，可以让图片"伸出"到页面边缘，而文字则巧妙地填充剩余空间。

.avatar-offset { shape-outside: circle(50% at 30% 50%); }
椭圆形状

椭圆头像

使用 ellipse() 可以创建椭圆形状。ellipse(50% 50%) 会创建一个填满整个元素的椭圆。

椭圆形状常用于宽银幕图片或全景图片的环绕排版。

椭圆的两个半径可以独立控制：第一个参数是 X 轴半径，第二个是 Y 轴半径。

.avatar-ellipse { width: 180px; height: 120px; shape-outside: ellipse(50% 50% at 50% 50%); }
