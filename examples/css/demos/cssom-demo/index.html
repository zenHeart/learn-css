CSSOM 操作方法演示

JavaScript CSS 样式编程接口实战

1.1 直接属性访问

通过点符号直接读写 CSS 属性，属性名使用驼峰命名法。

element.style.backgroundColor = '#2ecc71'; element.style.fontSize = '16px';
演示盒子
1.2 cssText 批量设置

一次性设置或读取整个行内样式字符串，等效于操作 HTML style 属性内容。

element.style.cssText = 'width:200px; height:200px; background:red;'; console.log(element.style.cssText);
演示盒子
1.3 setProperty() 设置带优先级的属性

以编程方式设置 CSS 属性，可选添加 !important 优先级标记。

element.style.setProperty('color', '#fff'); element.style.setProperty('opacity', '0.5', 'important');
Click buttons to compare
演示盒子
1.4 getPropertyValue() 获取属性值

从行内样式中读取指定属性的值，返回字符串。注意：只能读取行内样式，无法读取计算样式。

var val = element.style.getPropertyValue('color'); console.log(val);
box
1.5 removeProperty() 移除属性

从元素行内样式中删除指定属性，返回被删除的值。注意：会同时移除该属性的 !important 声明。

var old = element.style.removeProperty('color'); console.log('removed:', old);

2. window.getComputedStyle() 获取计算样式

获取元素经过所有样式表和继承计算后的最终样式（只读）。第二个参数可指定伪元素。

var computed = window.getComputedStyle(element); var before = window.getComputedStyle(element, '::before');
