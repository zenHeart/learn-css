CSS Houdini Paint API

通过 registerPaint 注册自定义 paint worklet，在 CSS 中绘制任意图案

⚠️ Houdini Paint API 需要通过 HTTP 服务器 访问才能运行。
启动方式：python -m http.server 8080 或 npx serve .
浏览器支持： Chrome 65+ Edge 79+ Firefox ❌ Safari ❌

基础图案示例

圆点、棋盘格、条纹渐变、六边形网格、波浪背景等 5 种基础图案的 worklet 实现。

入门级

交互式演示

Blob 动画（@property 驱动）、多边形边框、棋盘格遮罩。包含滑块控制和颜色切换。

进阶

ctx 绘图方法详解

矩形操作、渐变、路径绘制的完整演示。包含方法速查表和 inputProperties 示例。
