CSS contrast-color() 交互演示

根据背景色自动选择高对比度前景色（需浏览器支持，目前无浏览器实现）

⚠️ 浏览器支持状态

contrast-color() 是 CSS Color Level 5 的实验性功能，目前没有任何主流浏览器支持。以下演示使用 JavaScript 模拟函数行为，CSS 代码仅为语法示例。

/* CSS 语法（目前浏览器不支持） */ color: contrast-color(blue, white, black); /* 期望返回 white */

对比度计算原理（WCAG 2.1）

对比度比值 = (L1 + 0.05) / (L2 + 0.05)，其中 L1 是较亮颜色的相对亮度，L2 是较暗颜色的相对亮度。

对比度等级 AA 级要求 AAA 级要求
普通文本 ≥ 4.5:1 ≥ 7:1
大文本 (18px+) ≥ 3:1 ≥ 4.5:1
UI 组件和图形 ≥ 3:1 ≥ 3:1

CSS 代码示例

/* 基本用法 */ color: contrast-color(blue, white, black); /* 使用 CSS 变量 */ :root { --bg: #f5f5f5; --text: contrast-color(var(--bg), #1a1a1a, #ffffff); } body { background-color: var(--bg); color: var(--text); } /* 暗黑模式 */ [data-theme="dark"] { --bg: #1a1a1a; --text: contrast-color(var(--bg), #ffffff, #000000); } /* 三个颜色选项 */ .label { color: contrast-color( var(--label-bg), #fff, #000, #f0f0f0 /* 如果白和黑对比度都不够，可选第三个 */ ); }
⚠️ contrast-color() 目前无浏览器支持。以上演示使用 JavaScript 模拟函数行为。当浏览器支持后，请移除 JavaScript 模拟代码。
