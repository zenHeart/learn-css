CSS color-contrast() 函数

基于 WCAG 标准自动计算对比度颜色的 CSS 函数

WCAG 对比度标准

级别 最小对比度 适用场景
AA 4.5:1 正常文字（小于18pt或14pt粗体）
AAA 7:1 增强对比度要求
AA 大字 3:1 大字（大于等于18pt或14pt粗体）
/* 语法 */ color-contrast(<基础颜色> [<候选颜色>#]) /* 示例 */ color-contrast(#ffcc00, white, black, #333) /* 返回候选列表中第一个与 #ffcc00 对比度 >= 4.5:1 的颜色 */

/* CSS 中的使用方式（目前浏览器支持有限） */ .card { background: var(--brand-color); color: color-contrast(var(--brand-color) white, black); } /* 实际渲染结果由浏览器计算得出 */

动态主题适配

调整背景色的亮度，观察文字颜色如何自动适应

自动选择的文字颜色示例
/* 根据背景亮度自动选择黑色或白色文字 */ color: color-contrast(var(--bg) white, black);

多级候选项

提供多个候选颜色，函数按顺序选择第一个满足对比度的

浅色背景
#fff → #333
深色背景
#333 → #fff
蓝色背景
#007bff → #fff
黄色背景
#ffc107 → #333
/* 候选项按顺序检查，直到找到满足对比度的 */ color: color-contrast(#ffc107, #1a1a1a, #333, #666, #999); /* #1a1a1a (对比度 ~14:1) 即满足，无需检查后续 */
