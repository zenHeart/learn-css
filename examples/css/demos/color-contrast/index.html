CSS color-contrast() 颜色对比函数

CSS Color Level 5 规范 | 交互演示

浏览器支持状态

不支持 Chrome / Firefox / Edge
技术预览 Safari 17.4+

提示 由于浏览器支持有限，下方演示使用 JavaScript 模拟 color-contrast() 的功能。

基础用法 — 黑白色对比

对比文字
color-contrast(#0066cc vs white, black) 对比度: 4.52:1

结果 函数自动选择对比度更高的颜色（white）

多颜色候选对比

按钮文字
color-contrast(#4CAF50 vs white, black, #ffeb3b, #e91e63)

从多个候选颜色中选择对比度最高的。

WCAG 对比度级别

AA 级
4.5:1+
AA 大文本
3:1+
AAA 级
7:1+
/* AA 级（普通文本 4.5:1） */ color-contrast(bg vs candidates to AA) /* AAA 级（7:1） */ color-contrast(bg vs candidates to AAA)

实际应用：卡片系统

卡片 1 - 主要颜色
卡片 2 - 成功颜色
卡片 3 - 警告颜色
卡片 4 - 错误颜色
/* 自动选择对比度最高的文字颜色 */ .card { background-color: var(--card-color); color: color-contrast(var(--card-color) vs white, black); }

JavaScript 模拟实现

// 计算相对亮度 function getLuminance(r, g, b) { const [rs, gs, bs] = [r, g, b].map(c => { c = c / 255; return c <= 0.03928 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4); }); return 0.2126 * rs + 0.7152 * gs + 0.0722 * bs; } // 计算对比度 function getContrastRatio(color1, color2) { const l1 = getLuminance(...color1); const l2 = getLuminance(...color2); return (Math.max(l1, l2) + 0.05) / (Math.min(l1, l2) + 0.05); } // 模拟 color-contrast() function colorContrast(bgColor, candidates) { const bg = hexToRgb(bgColor); let best = candidates[0]; let bestRatio = 0; for (const candidate of candidates) { const ratio = getContrastRatio(bg, hexToRgb(candidate)); if (ratio > bestRatio) { bestRatio = ratio; best = candidate; } } return { color: best, ratio: bestRatio }; }
