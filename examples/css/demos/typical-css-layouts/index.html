CSS 布局方案总览

CSS 布局经历了从 Table 到 Float 到 Flexbox 再到 CSS Grid 的演进。以下是常见布局模式及其适用场景：

布局类型 推荐方案 适用场景 难度
单栏布局 Flexbox 博客、文档 入门
两栏布局 Flexbox/Grid 后台、侧边栏 入门
三栏布局 Grid 门户网站 中等
圣杯布局 Flexbox 管理后台 中等
卡片网格 Grid auto-fit 产品列表 入门
瀑布流 Grid + span 图片展示 中等

💡 选择建议

一维布局（导航、列表、居中）→ Flexbox
二维布局（页面框架、卡片网格）→ CSS Grid
传统 Float → 仅需了解，新项目不再使用

单栏布局 (Single Column)

内容居中，头部、主体、底部垂直排列。Flexbox 方案最简洁。

Header 头部
Main Content 主内容区，自动填充剩余高度
Footer 底部
.single-column { display: flex; flex-direction: column; min-height: 100vh; } .single-column main { flex: 1; /* 主内容自动撑满 */ }

Flexbox 优势

相比 Float，无需处理清除浮动问题。
相比 Table，语义更清晰，性能更好。
相比 absolute 定位，不会脱离文档流。

两栏布局 (Two Column)

左侧固定宽度侧栏 + 右侧自适应内容区。

Sidebar 250px
Main Content 自适应填充
.two-column { display: flex; } .sidebar { width: 250px; flex-shrink: 0; /* 禁止压缩 */ } .content { flex: 1; /* 自动填充 */ }

关键技巧

flex-shrink: 0 确保侧栏宽度固定不被压缩。
flex: 1 让内容区自动填充剩余空间。

三栏布局 (Three Column)

左右侧栏固定宽度，中间内容自适应。

Left
Main Content
Right
/* Flexbox 方案 */ .three-column { display: flex; } .left-sidebar, .right-sidebar { width: 200px; flex-shrink: 0; } .main { flex: 1; } /* Grid 方案（更简洁）*/ .three-column { display: grid; grid-template-columns: 200px 1fr 200px; }

圣杯布局 (Holy Grail)

经典五区域布局：Header + Left + Main + Right + Footer。Flexbox 一行搞定。

Header
Left
Main Content
Right
Footer
.holy-grail { display: flex; flex-direction: column; min-height: 100vh; } .holy-grail .body { display: flex; flex: 1; } .holy-grail main { flex: 1; } .holy-grail .left-sidebar, .holy-grail .right-sidebar { width: 200px; flex-shrink: 0; }

历史回顾

圣杯布局诞生于 2006 年，最初使用 Float 实现，代码复杂。
现代 Flexbox 让这个经典布局变得异常简单，10 行 CSS 即可。

布局方案对比

根据不同场景选择最合适的布局方案：

场景 推荐方案 原因
页面整体结构 Grid 二维控制，轨道定义清晰
导航栏 Flexbox 一维分布，space-between 神器
卡片列表 Grid auto-fit 自动响应式，无需 Media Query
垂直居中 Flexbox 一行搞定，兼容性好
圣杯布局 Flexbox 现代方案，代码简洁
组件内部布局 Container Queries 根据容器而非视口自适应
瀑布流 Grid + span 自动填充空隙

🎯 Grid vs Flexbox 选择决策树

需要同时控制行和列？ → Grid
只需要控制一行或一列？ → Flexbox
两者都行？ → 优先 Flexbox（兼容性更好）
