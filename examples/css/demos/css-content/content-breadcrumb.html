content 属性 - 面包屑导航

简单分隔符

首页 产品 电子产品 智能手机
.breadcrumb-sep::before { content: " / "; color: #484f58; }

使用 ::before 伪元素在分隔符 span 前添加 "/" 字符

图标分隔符

首页 产品 电子产品 智能手机
.breadcrumb-icon-sep::before { content: ""; display: inline-block; width: 10px; height: 10px; background: url("chevron-right.svg") no-repeat center; margin: 0 8px; }

使用 SVG 图标作为分隔符，替代纯文本

带编号的面包屑

  1. 首页
  2. 产品
  3. 电子产品
  4. 智能手机
ol { counter-reset: breadcrumb; } li { counter-increment: breadcrumb; } li a::before { content: counter(breadcrumb) ". "; color: #8b949e; } li::after { content: ""; display: inline-block; width: 10px; height: 10px; background: url("chevron.svg") no-repeat center; margin-left: 8px; } li:last-child::after { content: none; }

使用计数器为每个导航项添加序号
