content 属性 - 引号处理

自动引号嵌套

妈妈总是说，生活就像一盒巧克力，你永远不知道下一颗是什么。

blockquote { quotes: "«" "»" "‹" "›"; } blockquote::before { content: open-quote; } blockquote::after { content: close-quote; } q { quotes: "‹" "›"; } q::before { content: open-quote; } q::after { content: close-quote; }

通过 open-quote/close-quote 自动在 blockquote 周围添加外层引号，内部 q 元素自动使用内层引号

不同语言的引号风格

法语

Maman disait toujours, la vie, c'est comme une boîte de chocolats.

德语

Mama hat immer gesagt, Das Leben ist wie eine Schachtel Pralinen.

英语

My mama always said, Life was like a box of chocolates.

/* 法语引号 */ blockquote[lang="fr"] { quotes: "«" "»" "‹" "›"; } /* 德语引号 */ blockquote[lang="de"] { quotes: "„" """ "'" "'"; } /* 英语引号 */ blockquote[lang="en"] { quotes: """ """ "'" "'"; }

不同语言有不同的引号习惯，可以通过 lang 属性或类名区分
