手风琴模式

同时只能展开一个分支，展开新节点时会自动收起其他节点。适合信息层级较深的场景。

特点：节省屏幕空间，用户可以快速切换不同分支查看内容。

拖拽排序模式

通过拖拽重新排列项目顺序。拖拽时显示占位符，放置时显示目标位置指示。
