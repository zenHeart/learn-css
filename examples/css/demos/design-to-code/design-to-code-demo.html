什么是设计转代码？

设计转代码（Design to Code）是将 UI 设计稿转换为可维护代码的过程，核心工具是 Design Token（设计令牌）。

整体流程

🎨 设计稿
→
🏷️ Design Token
→
⚙️ 代码变量
→
🧩 组件

核心价值

  • 一致性：设计值统一管理，避免硬编码
  • 可维护性：改一处全局生效
  • 主题切换：轻松实现暗色/亮色模式
  • 多平台：一份 Token 输出 iOS/Android/Web
  • 协作：设计师和开发者使用同一语言

Design Token 三层结构

层级 说明 示例
Global 原始设计值，与品牌色板对应 --blue-500: #3B82F6
Semantic 语义化命名，描述用途 --color-primary: {blue-500}

Step 1: 设计评审

设计师交付设计稿后，团队评审以下内容：

Step 2: 提取 Design Token

从设计稿中提取设计决策，生成 Token JSON：

// tokens.json { "color": { "primary": "#3B82F6", "secondary": "#8B5CF6" }, "spacing": { "sm": "8px", "md": "16px", "lg": "24px" } }

Step 3: 代码实现

使用 Token 生成 CSS Variables 并应用到组件：

/* 定义 CSS Variables */ :root { --color-primary: #3B82F6; --spacing-md: 16px; } /* 使用 Token */ .button { background: var(--color-primary); padding: var(--spacing-md); }

自测题

Q1: Design Token 的作用是什么？

Q2: 哪种是推荐的 Token 命名方式？

Q3: Style Dictionary 的主要功能是？

答案

Q1: B - Design Token 存储设计决策，建立设计与代码的桥梁

Q2: B - 语义化命名（--color-text-primary）更易于维护和主题切换

Q3: B - Style Dictionary 将 Design Token（JSON）转换为 CSS/iOS/Android 等多平台代码
