font-display 字体显示策略演示

💡 什么是 FOIT 和 FOUT？
  • FOIT (Flash of Invisible Text)：字体加载期间文本不可见，可能造成闪烁
  • FOUT (Flash of Unstyled Text)：先用后备字体显示，加载后切换到自定义字体

font-display 取值对比

每种 font-display 策略在字体加载过程中的表现：

值 阻塞时间 后备字体 行为
auto 浏览器决定 由浏览器决定 FOIT
block 短暂（约 3s） 使用 FOIT → FOUT
swap 无 使用 FOUT
fallback 极短（约 0.1s） 使用 FOIT → 放弃
optional 无或极短 使用 由浏览器决定

swap - 立即显示后备字体

font-display: swap

特点：字体加载前立即显示后备字体，加载完成后立即切换。适合图标字体或重要文本。

The quick brown fox jumps over the lazy dog 
@font-face {
  font-family: 'MyFont';
  src: url('font.woff2') format('woff2');
  font-display: swap;
}

optional - 优先使用缓存

font-display: optional

特点：如果字体已在缓存中则使用，否则使用后备字体。适合正文文本，追求整体体验。

The quick brown fox jumps over the lazy dog 
@font-face {
  font-family: 'MyFont';
  src: url('font.woff2') format('woff2');
  font-display: optional;
}

block - 短暂阻塞后显示后备字体

font-display: block

特点：阻塞较短时间（约 3 秒）等待字体加载，超时后显示后备字体。

The quick brown fox jumps over the lazy dog 
@font-face {
  font-family: 'MyFont';
  src: url('font.woff2') format('woff2');
  font-display: block;
}

auto - 浏览器默认行为

font-display: auto

特点：使用浏览器的默认字体加载策略，通常表现为 FOIT。

The quick brown fox jumps over the lazy dog 
@font-face {
  font-family: 'MyFont';
  src: url('font.woff2') format('woff2');
  font-display: auto;
}

fallback - 快速超时

font-display: fallback

特点：阻塞极短时间（约 100ms），超时后使用后备字体。如果字体未加载，下次访问时可能使用。 

@font-face {
  font-family: 'MyFont';
  src: url('font.woff2') format('woff2');
  font-display: fallback;
}

实际应用建议

  • 图标字体：使用 swap - 图标需要立即显示
  • 正文文本：使用 optional 或 fallback - 避免文字跳动影响阅读
  • 标题文字：使用 swap - 允许轻微跳动但保证及时显示
  • 不重要装饰：使用 optional - 只在网络条件好时加载

性能优化技巧

/* 1. 使用 font-display 的同时，结合预加载 */
<link rel="preload" href="font.woff2" as="font" type="font/woff2" crossorigin>

/* 2. 使用 woff2 格式，兼容性最好且压缩率高 */
@font-face {
  font-family: 'MyFont';
  src: url('font.woff2') format('woff2');
  font-display: swap;
}

/* 3. 为不同字符集定义不同字体 */
@font-face {
  font-family: 'MyFont';
  src: url('latin.woff2') format('woff2');
  unicode-range: U+0000-00FF;
  font-display: swap;
}
