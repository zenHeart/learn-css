📚 AABB 碰撞原理

两个矩形不碰撞的条件是：其中一个矩形在另一个的左侧、右侧、上方或下方。只要不满足这四个条件之一，就发生碰撞。

不碰撞条件：
rect1.x + rect1.width ≤ rect2.x (左)
rect2.x + rect2.width ≤ rect1.x (右)
rect1.y + rect1.height ≤ rect2.y (上)
rect2.y + rect2.height ≤ rect1.y (下)
碰撞 = 以上都不满足

📚 圆形碰撞原理

圆形碰撞通过计算两个圆心之间的距离来判断。如果距离小于两圆半径之和，则发生碰撞。

碰撞条件：
distance = √((x₂-x₁)² + (y₂-y₁)²)
碰撞 = distance < radius₁ + radius₂

📚 点与矩形碰撞原理

最简单的碰撞检测之一。只需检查点的坐标是否在矩形范围内即可。

命中条件：
px ≥ rect.x AND px ≤ rect.x + rect.width
py ≥ rect.y AND py ≤ rect.y + rect.height

📚 空间分区优化

当有大量对象时，O(n²) 的两两检测会变得很慢。空间分区通过将画布划分为网格，只检测同一格子或相邻格子中的对象，大幅减少检测次数。

暴力检测 O(n²)

100个对象需 100×100 = 10,000 次检测

网格分区 O(n)

每格平均 5 个对象，仅需约 500 次检测
