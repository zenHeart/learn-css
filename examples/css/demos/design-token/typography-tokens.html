Line Heights
--line-height-tight (1.25)
紧凑行高，适用于标题。段落之间间距较小。
--line-height-normal (1.5)
标准行高，适用于正文。段落之间有适度呼吸空间。
--line-height-relaxed (1.75)
宽松行高，适用于长篇文章。段落之间有充足呼吸空间，提升阅读体验。
