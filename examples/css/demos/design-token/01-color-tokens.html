Color Tokens - 颜色令牌三层结构

Design Token 在 Web 端的实践：Option → Decision → Component

🔷 Token 层级架构

Option 选项令牌

定义原始色板，如 blue-500, gray-900。不含语义，设计师的自由创作空间。

Decision 决策令牌

语义化命名，如 primary, surface, text。表达设计意图，开发者按需使用。

Component 组件令牌

指定具体应用位置，如 button-primary-bg。组件直接引用，零思考成本。
