第三回

贾雨村夤缘复旧职，林黛玉抛父进京都。

却说雨村忙回头看时，不是别人，乃是当年同僚，姓张名如圭。他系此地人，革职后在家闲居，当下雨村即忙迎接上去。

技术文档

CSS Writing Modes 完全指南

writing-mode 属性

writing-mode 属性定义了文本的排列方向。在中文排版中，我们经常需要将文字设置为垂直方向。

常见的取值包括 vertical-rl（垂直从右到左）和 vertical-lr（垂直从左到右）。

text-orientation 属性

这个属性控制垂直模式下字符的朝向。mixed 是默认值，汉字正向，英文旋转。

upright 可让所有字符都正向站立，适合纯中文竖排场景。

目 录
核心代码： .split-header { writing-mode: horizontal-tb; }
.sidebar-title { writing-mode: vertical-rl; text-orientation: upright; }

⚖️ 示例三：竖排 vs 横排对比展示

并排展示同一内容在竖排和横排模式下的不同效果。

竖排模式（vertical-rl）

床前明月光

疑是地上霜

举头望明月

低头思故乡

横排模式（horizontal-tb）

床前明月光，疑是地上霜。

举头望明月，低头思故乡。

—— 唐·李白《静夜思》

核心代码： .compare-content.vertical { writing-mode: vertical-rl; text-orientation: upright; }
.compare-content.horizontal { writing-mode: horizontal-tb; }
