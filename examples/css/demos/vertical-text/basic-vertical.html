📜 CSS writing-mode 竖排文字基础演示

1. 水平排版（horizontal-tb）

默认的水平书写模式，从左到右，从上到下排列。

床前明月光，疑是地上霜。
举头望明月，低头思故乡。

writing-mode: horizontal-tb（默认）

writing-mode: horizontal-tb; /_ 默认值，水平从左到右 _/

2. 垂直从右到左（vertical-rl）

最符合中文传统竖排习惯的模式。上到下阅读，右边是行首，左边是行尾。

床前明月光
疑是地上霜
举头望明月
低头思故乡

vertical-rl（中文传统竖排）

writing-mode: vertical-rl; /_ 垂直从右到左，中文竖排标准写法 _/

3. 垂直从左到右（vertical-lr）

垂直模式，但左边是行首，右边是行尾。常用于蒙古文等语言。

床前明月光
疑是地上霜
举头望明月
低头思故乡

vertical-lr（垂直从左到右）

writing-mode: vertical-lr; /_ 垂直从左到右 _/

4. 三种模式对比

同一条古诗在不同 writing-mode 下的显示效果对比：

春眠不觉晓
处处闻啼鸟
夜来风雨声
花落知多少
