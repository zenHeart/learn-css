CSS 文字竖排实现与优化

writing-mode 属性对比

这是一段示例文字，用于演示 writing-mode 的效果。可以设置水平或垂直排列。
writing-mode: horizontal-tb;

horizontal-tb 水平从上到下 | vertical-rl 垂直从右到左 | vertical-lr 垂直从左到右

text-orientation 属性对比

这是一段示例文字 ABC123，包含中文和英文数字。
text-orientation: upright;

upright 字符保持直立（中文默认）| mixed 西文字母横向旋转

实际应用示例

侧边栏标签

侧边栏标签
.sidebar-label { writing-mode: vertical-rl; letter-spacing: 0.2em; }

标题竖排

竖排标题
.vertical-title { writing-mode: vertical-lr; text-orientation: upright; letter-spacing: 0.3em; }

完整竖排排版示例

床前明月光，疑是地上霜。举头望明月，低头思故乡。——李白《静夜思》 这是一段较长的中文竖排文本示例。在 CSS 中使用 writing-mode: vertical-rl 可以实现文字从右到左的竖向排列。竖排是中文传统排版方式，在现代网页中可以通过简单的 CSS 属性来实现。 竖排时需要注意行高、字间距的调整，以及标点符号的处理。
.vertical-article { writing-mode: vertical-rl; text-orientation: upright; line-height: 2.2; letter-spacing: 0.15em; font-size: 18px; }
