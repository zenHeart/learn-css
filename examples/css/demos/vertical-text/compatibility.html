解决不同浏览器和旧版本浏览器的兼容性问题

📊 浏览器支持概览

现代浏览器对 writing-mode 和 text-orientation 的支持已经非常完善，但旧版本浏览器仍需要特殊处理。

🖥️ 问题一：IE 浏览器的旧语法 IE 11

IE 浏览器使用私有的 -ms- 前缀语法，与现代浏览器标准语法不同。

IE 语法 → 标准语法对照

/* IE 11 写法 */ .writing-mode: tb-rl; /* 相当于 vertical-rl */ /* 现代浏览器写法 */ .writing-mode: vertical-rl;

完整 IE 兼容写法

.vertical-text { -ms-writing-mode: tb-rl; -webkit-writing-mode: vertical-rl; -moz-writing-mode: vertical-rl; writing-mode: vertical-rl; text-orientation: upright; }

⬇️ 问题三：垂直模式下的滚动方向

在垂直书写模式下，滚动方向可能与用户预期相反，需要注意用户体验设计。

💡 提示：垂直滚动意味着向右滚动

在 vertical-rl 模式下：

• 阅读方向是从右到左

• 向右滚动 = 向下滚动

• 滚动条位置：左侧或右侧

确保滚动条可见，方便用户理解。

🔄 问题四：双向文本（RTL 语言混排）

当垂直排版中混入阿拉伯文、希伯来文等从右到左的语言时，需要控制文本方向。

使用 dir 属性

/* HTML 中使用 dir 属性 */ <p dir="rtl">مرحبا</p> <p dir="ltr">Hello</p>

使用 bdi 元素

/* bdi 隔离双向文本 */ <p> 你好 <bdi>مرحبا</bdi> 世界 </p>

📋 完整兼容代码模板

综合所有兼容性处理的最佳实践代码：

/* =========================================== CSS 垂直排版 - 完整兼容代码 =========================================== */ /* 基础竖排类 */ .vertical-text { /* IE 11 */ -ms-writing-mode: tb-rl; /* 现代浏览器 */ -webkit-writing-mode: vertical-rl; -moz-writing-mode: vertical-rl; writing-mode: vertical-rl; /* Safari/iOS */ -webkit-text-orientation: upright; -moz-text-orientation: upright; text-orientation: upright; /* 可选：允许双向文本 */ unicode-bidi: isolate; } /* 纯中文竖排（推荐） */ .vertical-chinese { .vertical-text; text-orientation: upright; } /* 中英混排竖排 */ .vertical-mixed { .vertical-text; text-orientation: mixed; }

⚠️ 重要注意事项

  • IE 11 已经基本淘汰，除非有特殊需求，否则可以忽略 -ms- 前缀
  • iOS Safari 14+ 对 text-orientation 的支持已经完善，但仍建议保留 -webkit- 前缀
  • 使用 vertical-rl 时，滚动条默认在左侧；vertical-lr 时，滚动条在右侧
  • 打印时垂直文字可能出现问题，建议在 @media print 中切换为 horizontal-tb
  • Firefox 对 -moz-writing-mode 的支持已废弃，仅需标准写法
  • 大量垂直文字布局可能影响渲染性能，可使用 will-change: contents 优化
