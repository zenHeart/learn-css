CSS Box Alignment 盒模型对齐

统一各种 CSS 布局模型对齐方式的模块

属性概览

属性 作用轴 适用布局 说明
justify-content 主轴 flex, grid 内容在主轴上的对齐
align-items 交叉轴 flex, grid 单行内容在交叉轴对齐
align-content 交叉轴 flex, grid 多行内容在交叉轴对齐
justify-items 主轴 grid 网格项主轴对齐
justify-self 主轴 block, grid 单个项目自身主轴对齐
align-self 交叉轴 flex, grid 单个项目自身交叉轴对齐
place-items 两轴 flex, grid align-items + justify-items 简写
place-content 两轴 flex, grid align-content + justify-content 简写

justify-content 主轴对齐

justify-content 控制 flex 项目在主轴（默认水平）上的对齐方式

align-items 交叉轴对齐

align-items 控制 flex 项目在交叉轴（默认垂直）上的对齐方式

align-content 多行对齐

align-content 控制 flex 项目在交叉轴上有多行时的对齐（需要 flex-wrap: wrap）

基线对齐 (baseline)

align-items: baseline 使所有项目按文字基线对齐，适用于混合字体大小
