属性参考总表

属性 作用对象 方向 适用布局 说明
justify-content 容器 主轴 Flex Grid 主轴对齐方式
align-items 容器 交叉轴 Flex Grid 交叉轴对齐方式
align-content 容器 交叉轴（多行） Flex Grid 多行/多列整体对齐
justify-items 容器 主轴 Grid 网格项默认主轴对齐
justify-self 元素 主轴 Block Grid 自身主轴对齐
align-self 元素 交叉轴 Flex Block Grid 自身交叉轴对齐
place-items 容器 两轴 Flex Grid align-items + justify-items 简写
place-self 元素 两轴 Block Grid align-self + justify-self 简写
place-content 容器 两轴 Flex Grid align-content + justify-content 简写
gap 容器 间距 Flex Grid 元素间固定间距
