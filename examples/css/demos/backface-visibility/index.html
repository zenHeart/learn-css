.card { transform-style: preserve-3d; transition: transform 0.6s; } .card.flipped { transform: rotateY(180deg); } .card-front, .card-back { backface-visibility: hidden; } .card-back { transform: rotateY(180deg); }

对比说明

/* 背面不可见 - 常用 */ .flip { backface-visibility: hidden; } /* 当元素翻转 90 度时，完全看不到背面 */ /* 背面可见 - 特殊效果 */ .flip { backface-visibility: visible; } /* 当元素翻转 90 度时，可以看到背面的镜像 */

建议 大多数 3D 翻转效果使用 hidden。
