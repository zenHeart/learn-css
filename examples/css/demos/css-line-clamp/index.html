CSS line-clamp 多行文本截断演示

💡 line-clamp 简介

line-clamp（以 -webkit-line-clamp 形式使用）可以限制块容器中的文本行数，适合实现多行截断效果，如新闻标题、商品描述等。

line-clamp 基本原理

要实现 line-clamp 效果，需要组合使用以下 CSS 属性：

属性 作用
display: -webkit-box 将元素设为弹性盒容器
-webkit-line-clamp: N 限制最多显示 N 行
-webkit-box-orient: vertical 设置盒子方向为垂直
overflow: hidden 溢出内容隐藏 
.clamp-text {
  display: -webkit-box;
  -webkit-line-clamp: 3;
  -webkit-box-orient: vertical;
  overflow: hidden;
}

浏览器兼容性

浏览器 支持情况 说明
Chrome ✓ 支持 完全支持 -webkit-line-clamp
Safari ✓ 支持 完全支持 -webkit-line-clamp
Opera ✓ 支持 基于 Chromium，完全支持
Edge ✓ 支持 基于 Chromium，完全支持
Firefox ✗ 不支持 可以使用 line-clamp 草案属性（无前缀）
💡 兼容策略

如果需要兼容 Firefox，可以考虑使用 line-clamp（无前缀）草案属性，或使用 JavaScript 实现截断效果。
