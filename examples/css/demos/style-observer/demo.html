MutationObserver 样式监控

监控目标
点击"开始监控"按钮来监控此元素的样式变化...

MutationObserver 可以监控元素 style 属性的变化。当样式变化时，会记录变化的详细信息。 这个 API 适用于需要响应式处理样式变化的场景。
