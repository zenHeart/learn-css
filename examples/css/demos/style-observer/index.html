CSS Style Observer

监听 CSS 属性变化的 JavaScript 库

浏览器支持状态

Style Observer 利用 transition-behavior: allow-discrete 特性，需要浏览器支持 CSS 过渡行为。

工作原理

Style Observer 通过 transitionstart 事件监听 CSS 属性变化，相比轮询更加高效精准。

// 安装
import { StyleObserver } from 'style-observer';

// 创建 Observer
const observer = new StyleObserver(
element, // 观察的元素
'--my-prop', // CSS 属性名
(records) => { // 回调函数
records.forEach(r => {
console.log(r.property, r.oldValue, r.newValue);
});
}
);

// 开始观察
observer.observe();

// 改变值（触发回调）
element.style.setProperty('--my-prop', 'new-value');

应用场景

1. 高阶组件属性

通过一个 --variant 属性控制多个相关样式

const observer = new StyleObserver(element, '--variant', (records) => {
records.forEach(record => {
const variant = variants[record.newValue];
element.style.setProperty('--btn-bg', variant.bg);
element.style.setProperty('--btn-text', variant.text);
});
});

2. ARIA 属性同步

将 CSS 属性同步到 ARIA 属性

const observer = new StyleObserver(button, '--aria-expanded', (records) => {
button.setAttribute('aria-expanded', records[0].newValue);
});

3. Polyfill CSS 特性

用 JS 实现浏览器缺失的 CSS 特性

const observer = new StyleObserver(el, '--backdrop-filter', (records) => {
if (!CSS.supports('backdrop-filter', 'blur()')) {
el.style.background = 'rgba(255,255,255,0.9)';
}
});

与其他方案对比

方案 原理 精度 性能
Style Observer transitionstart 事件 高 好
轮询 (setInterval) 定时检查 低 差
MutationObserver DOM 变化监听 中 中
