时间线驱动动画

使用 DocumentTimeline 驱动 Animation Worklet，类似 Web Animations API 但运行在独立线程

⚠️ 需要通过 HTTP 服务器访问（如 python -m http.server 8080）才能运行 Animation Worklet。
⚠️ 您的浏览器不支持 Animation Worklet。请使用 Chrome 85+ 或 Edge 85+。
时间线类型： document.timeline — 基于文档时间线，动画时间与 wall clock 对齐。
与 element.animate() 的主要区别：Worklet 动画运行在独立线程，不阻塞主线程。

1. 滑动进入动画

使用 SlideAnimator，从左侧滑入。可通过按钮控制播放/暂停/反向。

SLIDE
状态: 等待播放

2. 渐变动画

使用 FadeAnimator，控制透明度在 0.2~1.0 之间循环。展示 animation iteration 的使用。

FADE
状态: 等待播放

3. 数字计数器

使用 CounterAnimator，将 currentTime (0~1) 映射为目标数字 (0~999)。

0
当前值: 0

4. 脉冲缩放动画

使用 PulseAnimator，控制 scale 在 0.8~1.2 之间循环，持续播放。

PULSE
原理: currentTime 循环映射到 scale 范围
