视差滚动效果

使用 ScrollTimeline + Animation Worklet 实现多图层不同速度的视差效果

⚠️ 需要通过 HTTP 服务器访问。滚动页面查看视差效果。
⚠️ 您的浏览器不支持 Animation Worklet。请使用 Chrome 85+ 或 Edge 85+。
原理：不同图层绑定不同 speed 参数的 animator。 星星层 speed=0.3（慢），云层 speed=0.6（中），山峦层 speed=1.0（快）。 通过 currentTime * speed 控制每个图层的 translateY。
滚动探索
星空以 0.3 倍速度移动，云层以 0.6 倍速度移动，山峦随页面同步滚动。 所有动画完全由滚动驱动，运行在独立线程。

核心实现

每个图层对应一个 ParallaxLayerAnimator 实例，通过不同的 speed 参数实现不同滚动速度。 currentTime 来自 ScrollTimeline，范围 0~1。

公式：translateY = scrollProgress * windowHeight * speed

这种方式的优点：所有视差计算都在 Worklet 线程完成，主线程上的 JS 任务（如按钮点击、DOM 更新）完全不受影响。
