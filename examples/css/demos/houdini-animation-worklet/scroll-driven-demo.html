滚动驱动动画

使用 ScrollTimeline 驱动 Animation Worklet，动画与滚动位置完全同步

工作原理：ScrollTimeline 将滚动位置（0%~100%）映射为动画进度（0~1）， 传递给 Worklet 中的 animate(currentTime, effect)，实现完全线程化的滚动动画。
⚠️ 您的浏览器不支持 Animation Worklet。请使用 Chrome 85+ 或 Edge 85+。

核心代码解析

1. 注册 Animator：通过 registerAnimator() 定义动画逻辑， currentTime 参数范围为 0~1，对应滚动范围的开始到结束。

2. 创建 ScrollTimeline：指定 scrollSource（滚动容器）、 orientation（滚动方向）和 endScrollOffset（结束位置）。

3. 创建 WorkletAnimation：将 animator、时间线和目标元素组合， 调用 .play() 开始动画。

与 CSS Scroll-Driven Animation 的对比

CSS Scroll-Driven Animation（如 animation-timeline: scroll()）是纯声明式的， 而 Animation Worklet 允许你用完整的 JavaScript 逻辑处理滚动值，实现更复杂的动画效果， 如非线性映射、多元素联动等。
