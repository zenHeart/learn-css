CSS Houdini Animation Worklet

通过 registerAnimator 注册自定义动画器，实现高性能的线程化动画

⚠️ Animation Worklet 需要通过 HTTP 服务器 或 localhost 访问。
启动方式：python -m http.server 8080 或 npx serve .
浏览器支持： Chrome 84+ Edge 84+ Firefox ❌ Safari ❌

滚动关联动画

演示基于滚动位置触发的动画效果，Animation Worklet 运行在独立线程实现流畅的 scroll-linked 动画。

核心

帧同步动画

演示基于时间轴的帧同步动画，包括滑入滑出、循环动画等模式。

进阶

Worklet 文件

  • worklets/scroll-animator.js — 滚动关联动画器
  • worklets/frame-animator.js — 帧同步动画器
