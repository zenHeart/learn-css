CSS Houdini Animation Worklet

通过 registerAnimator 注册自定义动画控制器，在独立线程运行的高性能动画

⚠️ Animation Worklet 需要通过 HTTP 服务器 访问才能运行。
启动方式：python -m http.server 8080 或 npx serve .
浏览器支持： Chrome 85+ Edge 85+ Firefox ❌ Safari ❌

滚动驱动动画

演示 ScrollTimeline 驱动的工作原理。滚动页面查看动画效果，完全独立于主线程运行。

核心功能

时间线驱动动画

使用 DocumentTimeline 驱动动画。包含滑动进入、渐变效果、数字计数等多种动画模式。

基础

视差滚动效果

多个图层以不同速度滚动，创建深度感。纯滚动驱动，无 JavaScript 动画回调。

实战
注意：Animation Worklet 与 CSS.scroll-driven-animations 不同之处在于它使用 JavaScript Worklet， 可以实现更复杂的动画逻辑，但目前仅 Chromium 浏览器支持。
