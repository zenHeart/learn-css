向下滚动查看进度条动画效果。进度条会随着滚动位置变化而变化。

CSS scroll-timeline

scroll-timeline 允许动画与滚动位置关联，实现滚动触发的动画效果。

动画时间线

animation-timeline 属性指定动画的时间线来源，可以是滚动容器或根元素。

实际应用

滚动驱动动画常用于阅读进度指示器、视差效果、滚动淡入等场景。

浏览器兼容

目前只有 Chrome 115+ 支持此功能，其他浏览器尚未实现。

/* CSS scroll-timeline 示例 */ @keyframes progress { from { transform: scaleX(0); } to { transform: scaleX(1); } } .progress-fill { animation: progress linear; animation-timeline: scroll(root block); transform-origin: left; }

滚动旋转动画

滚动触发旋转

向下滚动，紫色方块会随着滚动而旋转。

animation-timeline

通过 animation-timeline: scroll() 将动画与滚动关联。

线性动画

使用 linear 时间函数让旋转与滚动同步。

完整示例

这个演示展示了滚动驱动动画的基本概念。

@keyframes rotate { from { transform: rotate(0deg); } to { transform: rotate(360deg); } } .element { animation: rotate linear; animation-timeline: scroll(); }

JavaScript 回退方案

// 使用 Intersection Observer 检测滚动位置 const observer = new IntersectionObserver((entries) => { entries.forEach((entry) => { if (entry.isIntersecting) { entry.target.classList.add('visible'); } }); }, { threshold: 0.1 }); // 或者使用 scroll 事件 window.addEventListener('scroll', () => { const scrolled = window.scrollY; const maxScroll = document.documentElement.scrollHeight - window.innerHeight; const progress = scrolled / maxScroll; // 更新进度 document.querySelector('.progress-fill').style.transform = `scaleX(${progress})`; });

提示 在不支持 scroll-timeline 的浏览器中，可以使用 JavaScript 实现类似效果。

完整代码示例

/* 1. 定义关键帧动画 */ @keyframes reading-progress { from { transform: scaleX(0); } to { transform: scaleX(1); } } /* 2. 应用滚动时间线 */ .reading-progress { position: fixed; top: 0; left: 0; width: 100%; height: 4px; background: linear-gradient(90deg, #007bff, #00d4ff); transform-origin: left; /* 3. 关联动画和时间线 */ animation: reading-progress linear; animation-timeline: scroll(root block); } /* 4. 指定滚动轴（可选） */ /* block: 垂直滚动（默认） */ /* inline: 水平滚动 */
