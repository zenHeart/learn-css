Scroll-Driven Animations

CSS-native scroll-linked animation via scroll-timeline and animation-timeline. Scroll down to see the effects — no JavaScript required.

1. Scroll Progress Bar

The blue bar at the very top of the page fills as you scroll. It uses a single scaleX animation driven by the viewport's scroll position. 

/* Declare a named scroll timeline on the viewport */
scroll-timeline-name: --page-scroll;
scroll-timeline-axis: block;

/* Reference it on the animated element */
animation-timeline: --page-scroll;
animation-name: grow;
animation-timing-function: linear;

/* Keyframes scale from 0 → 1 across the full scroll range */
@keyframes grow {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}

2. Scroll-Linked Rotation

A dial hand that rotates a full 360° as you scroll through this section, using animation-range to scope when the animation plays.

Rotate as you scroll 
@keyframes rotate-dial {
  from { rotate: 0deg; }
  to   { rotate: 360deg; }
}

animation: rotate-dial linear both;
animation-timeline: --dial-scroll;
animation-range: entry 0% contain 60%;

scroll-timeline-name: --dial-scroll;
scroll-timeline-axis: block;

3. Reveal on Scroll

Cards animate in with staggered animation-range values. Each card starts its animation slightly after the previous one.

/* Staggered card reveals via animation-range */
@keyframes card-reveal {
  from { opacity: 0; transform: translateY(32px); }
  to   { opacity: 1; transform: translateY(0); }
}

animation: card-reveal ease-out both;
animation-timeline: --card-scroll;
animation-range: entry 0% contain 40%; /* Card 1 */
animation-range: entry 10% contain 50%; /* Card 2 — starts 10% later */
You made it! 🎉

4. How It Works

A scroll timeline maps scroll position (0% at scroll start, 100% at scroll end) to animation progress. Unlike time-based animations, the playback position is determined by how far the user has scrolled through the tracked element or viewport.

The CSS properties scroll-timeline-name and scroll-timeline-axis declare the timeline. Then animation-timeline attaches it to an animation. The animation-range property controls which portion of the scroll triggers the animation's play phase.
