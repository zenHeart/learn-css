CSS `color-scheme` 颜色方案适配

声明页面支持的色彩方案，浏览器自动调整 UI 外观。切换系统主题可查看效果。

① 分区域 color-scheme 声明

💡 说明：不同区域可以声明不同的 color-scheme。仅亮色的区域即使在系统暗黑模式下也不会应用暗黑；仅暗黑的区域即使在系统亮色模式下也会保持暗黑。

header / nav
color-scheme: only light
固定亮色，不会变暗
main / content
color-scheme: light dark
跟随系统主题变化
footer / sidebar
color-scheme: only dark
固定暗黑，不会变亮

② light-dark() 函数配合使用

💡 说明：light-dark(lightVal, darkVal) 根据当前活跃的色彩方案返回对应颜色。当前为亮色模式时返回第一个值，为暗黑模式时返回第二个值。

双主题自动适配卡片

这个卡片的背景、边框、文字颜色全部使用 light-dark() 定义，切换系统主题即可看到变化。

background light-dark(#fff, #121212)
color light-dark(#1a1a1a, #e0e0e0)
border light-dark(#e0e0e0, #333)
primary light-dark(#0066cc, #4da3ff)

③ 表单控件自动适配

💡 说明：声明 color-scheme: light dark 后，浏览器会自动调整表单控件（输入框、下拉框、按钮等）的默认颜色，无需额外 CSS。

⑤ 核心代码示例

HTML: 添加 meta 标签

<head>
  <!-- 声明支持亮色和暗黑，防止页面加载闪烁 -->
  <meta name="color-scheme" content="light dark">
  <link rel="stylesheet" href="styles.css">
</head>

CSS: 使用 light-dark() 定义主题变量

:root {
  color-scheme: light dark;
}

:root {
  --bg: light-dark(#ffffff, #121212);
  --surface: light-dark(#f5f5f5, #1e1e1e);
  --text: light-dark(#1a1a1a, #e0e0e0);
  --border: light-dark(#e0e0e0, #333333);
  --primary: light-dark(#0066cc, #4da3ff);
}

body {
  background-color: var(--bg);
  color: var(--text);
}

分区域声明

/* 固定亮色区域 */
.brand-header {
  color-scheme: only light;
  background: #007bff;
  color: #fff;
}

/* 固定暗黑区域 */
.dark-panel {
  color-scheme: only dark;
  background: #1a1a1a;
  color: #fff;
}

/* 跟随系统 */
.main-content {
  color-scheme: light dark;
}

总结：color-scheme 让浏览器知道你的页面支持哪些色彩方案，浏览器据此自动调整原生 UI 的颜色。
配合 light-dark() 函数，可以用一行 CSS 声明实现双主题适配，代码简洁且易于维护。
