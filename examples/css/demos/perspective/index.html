代码示例

/* 1. 定义透视容器 */ .scene { perspective: 500px; } /* 2. 保留 3D 空间 */ .parent { transform-style: preserve-3d; } /* 3. 子元素 3D 变换 */ .child { transform: rotateY(45deg) translateZ(100px); } /* 4. perspective-origin 定义透视原点 */ .scene { perspective-origin: center center; }
