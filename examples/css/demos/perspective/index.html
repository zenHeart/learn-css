transform-style: preserve-3d vs flat

子元素是否保留 3D 空间位置：

preserve-3d 保留 3D 空间

子元素在真正的 3D 空间中独立变换

Front
transform-style: preserve-3d;

flat 压平

子元素被压平到父元素的平面

Front
transform-style: flat; /* 默认值 */
