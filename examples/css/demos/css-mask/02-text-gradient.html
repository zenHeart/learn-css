CSS 文字渐变效果演示

传统 background-clip 方法

使用 background-clip: text 将渐变背景裁剪到文字区域，这是最常用的文字渐变方法。

渐变文字
基础渐变
background: linear-gradient(...); background-clip: text; -webkit-text-fill-color: transparent;
流光效果
动画渐变
background-size: 200% 100%; animation: shimmer 3s infinite;
金属质感
多层渐变
多层白色/灰色渐变创造金属效果
彩虹文字
彩虹渐变
7色光谱渐变

Mask 方法实现文字渐变

使用 mask-image 实现文字渐变效果，可以更灵活地控制渐变方向和过渡效果。

Mask 渐变
垂直渐变遮罩
background: linear-gradient(...); mask-image: linear-gradient(to bottom, black 50%, transparent 100%); mask-mode: luminance;
阴影渐隐
底部渐隐 + 阴影
渐变背景 + text-shadow 组合

Mask vs background-clip 对比

background-clip
background-clip: text
mask-image
mask-image 渐变
对比说明：
• background-clip: text - 兼容性更好，但只能裁剪到文字边界
• mask-image - 更灵活，支持多层遮罩和不同的遮罩混合模式
