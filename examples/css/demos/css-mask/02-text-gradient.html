CSS Mask 案例二：文字渐变效果

1. 横向渐变遮罩

GRADIENT

使用 linear-gradient 遮罩实现左右两端透明过渡的效果
mask-image 控制文字只在中间 20%-80% 区域可见

2. 扫描线动画

SCAN

利用 mask 的半透明特性实现光束扫过文字的动画效果
通过 ::after 伪元素叠加，并使用 mask 控制可见区域

3. 多色渐变 + 动态背景

RAINBOW

背景渐变 + mask 遮罩 + background-position 动画
实现彩虹渐变流动穿过文字的效果

4. 遮罩 Reveal 入场动画

REVEAL

文字上方覆盖遮罩层，动画移除遮罩的同时文字上移入场
遮罩层下移消失，文字从下方渐入

5. 光晕中心渐变

GLOW

使用 radial-gradient 遮罩实现中心亮、边缘暗的光晕效果
结合 text-shadow 增强氛围感
