CSS Mask 案例一：圆形头像裁剪

径向渐变圆形

使用 radial-gradient 创建圆形遮罩，可任意尺寸自适应

mask-image: radial-gradient( circle, black 45%, transparent 46% );

带边框效果

遮罩 + border-radius + inset shadow 实现边框效果

mask-image: radial-gradient( circle, black 45%, transparent 46% );

边缘渐隐效果

径向渐变过渡区域实现边缘柔和淡出

mask-image: radial-gradient( circle at center, black 0%, black 50%, transparent 75%, transparent 100% );

椭圆形状遮罩

使用 ellipse 创建椭圆/胶囊形状遮罩

mask-image: radial-gradient( ellipse 50% 35% at 50% 50%, black 0%, black 100%, transparent 100% );
