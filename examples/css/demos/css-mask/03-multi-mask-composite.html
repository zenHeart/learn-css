CSS Mask 多遮罩叠加演示

mask-composite 模式对比

mask-composite 属性控制多层遮罩之间的合成方式：
• add: 叠加（默认）
• subtract: 从底层减去顶层
• intersect: 只显示重叠部分
• exclude: 排除重叠部分

实际应用示例

应用场景：
• 图片处理: 实现圆形头像、圆角图片
• 文字效果: 渐变文字、光晕效果
• 图案背景: 网格、条纹、蜂窝等图案
• 过渡动画: 元素的淡入淡出、滑动消失
• 复杂裁剪: 不规则形状的裁剪和遮罩
