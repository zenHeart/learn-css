相关属性

  • mask-image - 定义遮罩图像来源
  • mask-mode - 定义遮罩混合模式（alpha/luminance/match-source）
  • mask-repeat - 控制遮罩重复方式
  • mask-position - 控制遮罩位置
  • mask-size - 控制遮罩尺寸
  • mask-composite - 定义多层遮罩合成操作
