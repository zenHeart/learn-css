CSS Mask 案例三：多遮罩叠加实现复杂图形

CSS Mask 支持多个遮罩层叠加，通过 mask-composite 属性控制各层之间的合成方式，
可以实现单一遮罩无法完成的复杂视觉效果。

底部 + 两侧渐隐叠加

叠加 linear-gradient（底部渐隐）和 radial-gradient（左右渐隐），
使用 intersect 模式保留两层遮罩的重叠区域。

mask-image: linear-gradient(to bottom, black, transparent), radial-gradient(ellipse 80% 100% at 50% 50%, ...); mask-composite: intersect;

圆形 + 十字网格遮罩

三层遮罩叠加：圆形遮罩 + 横向条 + 纵向条，
使用 intersect 保留十字形镂空效果。

mask-image: radial-gradient(circle, black 35%, transparent 36%), linear-gradient(to right, ...), /* 横向条 */ linear-gradient(to bottom, ...); /* 纵向条 */ mask-composite: intersect;

雷达扫描动画

RADAR

使用 conic-gradient 创建旋转扫描光束，
配合 radial-gradient 遮罩实现圆形探测范围。

/* 扫描光束 */ background: conic-gradient(from 0deg, transparent, rgba(0,255,136,.6) 30deg, transparent); animation: radarSweep 3s linear infinite;

条纹 + 圆形叠加

叠加圆形遮罩和重复条纹渐变，
实现透过圆窗看到条纹图案的效果。

mask-image: radial-gradient(ellipse, black 40%, transparent 41%), repeating-linear-gradient( to bottom, transparent 0px, black 8px, black 16px ); mask-composite: intersect;

渐变边框效果

BORDER

使用三层 linear-gradient 控制边框四个边的显示，
结合 intersect 保留边框同时镂空中心。

mask-image: linear-gradient(to right, black 4%, transparent 96%), linear-gradient(to bottom, black 4%, transparent 96%); mask-composite: intersect;

对角线切割形状

使用 polygon 遮罩实现两个对角三角形叠加，
切割出独特的斜角边缘效果。

mask-image: polygon(0 0, 60% 0, 0 60%), polygon(100% 100%, 40% 100%, 100% 40%); mask-composite: intersect;
