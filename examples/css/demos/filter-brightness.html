CSS filter brightness() 交互演示

brightness() 调整元素亮度，0%=全黑，100%=原图，>100%=更亮

1. 基础亮度调整

100%
filter: brightness(100%);

0% = 完全黑色，100% = 默认原图，>100% = 更亮。brightness() 只改变亮度，保持色相不变。

3. 与其他 filter 函数组合

filter: brightness(1.2) contrast(1.1);

filter 属性可同时应用多个函数，用空格分隔。

4. 常用 filter 函数一览

函数作用示例值
brightness()调整亮度0% ~ 200%
blur()高斯模糊0px ~ 10px
contrast()对比度0% ~ 200%
grayscale()灰度转换0% ~ 100%
sepia()棕褐色调0% ~ 100%
saturate()饱和度0% ~ 200%
opacity()透明度0% ~ 100%
hue-rotate()色相旋转0deg ~ 360deg

6. 实用场景

filter: brightness(1.2); /* 悬停提亮 */

常见场景：悬停效果、禁用状态、深色模式适配、内容强调。配合 transition 实现平滑过渡。
