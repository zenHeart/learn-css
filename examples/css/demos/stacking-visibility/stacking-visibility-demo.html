CSS 层叠上下文与组件可见性判断

什么是层叠上下文（Stacking Context）

层叠上下文是 HTML 文档中的一个三维概念。同一个层叠上下文内的元素，按照从低到高的顺序排列：background/border → z-index负值 → block → float → inline → z-index:0 → z-index正数。

关键原则：子元素无论 z-index 多大，都无法超越父层叠上下文的边界。

层叠顺序公式（从低到高）
bg/border < z-index:负 < block < float < inline < z-index:0 < z-index:正
z-index 只在同一层叠上下文内比较才有意义

层叠顺序详解

在同一个层叠上下文中，元素按照以下顺序层叠（从低到高）：

1. background / border（层叠上下文根部）
2. z-index: 负值（最底层）
3. block 流式布局子元素
4. float 子元素
5. inline / inline-block 子元素
6. z-index: auto / z-index: 0
7. z-index: 正值（最顶层）

关键点

  • z-index 负值在 background 之后，但在 block 布局元素之前
  • float 元素比 inline 元素低，但比 block 元素高
  • z-index: auto 等同于 z-index: 0 在同一层叠上下文中
  • 没有创建层叠上下文的父元素，其子元素与普通文档流元素一起比较

常见 z-index 陷阱

问题：为什么 z-index: 9999 的元素还是被遮挡？

// HTML
<div class="parent">
  <div class="child">z-index: 9999</div>
</div>

// CSS
.parent {
  position: relative;
  /* 没有 z-index，不创建层叠上下文 */
}
.child {
  position: absolute;
  z-index: 9999;
}

// 另一个元素
.other {
  position: relative;
  z-index: 100; /* 在 child 之上 */
}

⚠️ 关键：child 的 z-index 再高，也只能在 parent 的层叠上下文内层叠

层叠上下文边界法则

// 法则：子元素的 z-index 再高，也不能超出父层叠上下文

层叠上下文 A (z-index: 1)
  └── child (z-index: 9999)  ← 永远在 A 之内
      └── grandchild (z-index: 999999)  ← 永远在 child 之内

层叠上下文 B (z-index: 0)
  └── 任何元素  ← 都在 A 的 z-index: 1 之上

// 结果：B 内的任何元素都在 A 的 child (z-index: 9999) 之上！

getBoundingClientRect 检测

function isElementInViewport(el) {
  const rect = el.getBoundingClientRect();
  return (
    rect.top < window.innerHeight &&
    rect.bottom > 0 &&
    rect.left < window.innerWidth &&
    rect.right > 0
  );
}

elementFromPoint 检测遮挡

function isElementObscured(el) {
  const rect = el.getBoundingClientRect();
  const centerX = rect.left + rect.width / 2;
  const centerY = rect.top + rect.height / 2;
  
  const topElement = document.elementFromPoint(centerX, centerY);
  
  return !topElement || 
         (topElement !== el && !el.contains(topElement));
}

getComputedStyle 检测隐藏

function isStyleHidden(el) {
  const style = window.getComputedStyle(el);
  return (
    style.display === 'none' ||
    style.visibility === 'hidden' ||
    style.opacity === '0'
  );
}

判断题

1. 子元素的 z-index: 9999 一定比父元素的 z-index: 1 在上层？

✓ 正确
✗ 错误

答案：错误 — 子元素无法超越父层叠上下文的边界

2. opacity: 0.9 会创建新的层叠上下文吗？

✓ 是
✗ 否

答案：是 — opacity < 1 就会创建新层叠上下文

3. position: static 时 z-index 会生效吗？

✓ 会
✗ 不会

答案：不会 — z-index 只对 position 为 relative/absolute/fixed/sticky 生效

4. 使用 elementFromPoint 检测元素中心点，如果返回元素本身，说明元素可见且未被遮挡？

✓ 正确
✗ 不完全对

答案：正确 — 中心点命中自己且没有 display:none 等问题时成立

排序题

5. 按层叠顺序从低到高排列：① z-index: -1 ② block ③ z-index: 0 ④ z-index: 5

答案：①②③④
