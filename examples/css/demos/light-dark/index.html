CSS light-dark() 函数

自动响应明暗主题的颜色切换函数

基础卡片

这是一个使用 light-dark() 的基础卡片示例。切换系统主题，卡片的背景色、文字颜色和边框都会自动调整。

工作原理

:root {
color-scheme: light dark; /* 必须声明 */
--text: light-dark(#333, #ccc); /* 浅色模式用 #333，深色模式用 #ccc */
}

body {
color: var(--text); /* 自动响应主题切换 */
}

关键点：必须声明 color-scheme: light dark，浏览器才知道页面支持两种主题，从而正确切换 light-dark() 的返回值。

阴影效果适配

light-dark() 让阴影在浅色模式下柔和，在深色模式下明显

带主题适配阴影的卡片

阴影的模糊半径和颜色会根据当前主题自动调整

box-shadow: light-dark(
0 2px 8px rgba(0,0,0,0.08), /* 浅色模式：柔和阴影 */
0 2px 8px rgba(0,0,0,0.4) /* 深色模式：明显阴影 */
);

边框和分隔线

透明边框配合 light-dark() 可以创建主题感知的分隔线

渐变背景适配

不同的渐变色也可以根据主题切换

渐变背景示例
background: light-dark(
linear-gradient(135deg, #667eea 0%, #764ba2 100%),
linear-gradient(135deg, #1a1a2e 0%, #16213e 100%)
);

元素级别主题覆盖

通过设置 color-scheme 属性，可以强制特定元素使用特定主题

这个容器正常响应全局主题

这个容器强制使用深色主题（color-scheme: dark）

注意：虽然外层页面可能是浅色，但 light-dark() 在这里会返回深色值

.force-dark {
color-scheme: dark; /* 强制深色 */
background: #000;
}

与 prefers-color-scheme 对比

prefers-color-scheme

  • 基于用户系统偏好，不可覆盖
  • 需要重复定义属性
  • 更精确但代码冗长

light-dark()

  • 可被 color-scheme 覆盖
  • 代码简洁优雅
  • 适合组件库和设计系统

完整使用示例

:root {
color-scheme: light dark;

/* 语义化颜色变量 */
--surface: light-dark(#fff, #1a1a1a);
--surface-elevated: light-dark(#fafafa, #252525);
--text-primary: light-dark(#1a1a1a, #f5f5f5);
--text-secondary: light-dark(#666, #999);
--border: light-dark(#e0e0e0, #333);
--primary: light-dark(#007bff, #0d6efd);
}

.card {
background: var(--surface);
color: var(--text-primary);
border: 1px solid var(--border);
}
