CSS light-dark() 暗色模式切换

CSS Color Level 5 规范 | 交互演示

基础用法

当前模式：dark
使用 light-dark() 的盒子
background: light-dark(#ffffff, #1a1a1a); color: light-dark(#1a1a1a, #f5f5f5);

color-scheme: light dark 声明后，浏览器会自动根据系统设置选择配色。

卡片组件示例

卡片标题

这是一个使用 light-dark() 的卡片组件。切换系统配色方案时，卡片的背景、文字和边框颜色会自动适应。

.card { background: light-dark(#f8f9fa, #252525); color: light-dark(#333333, #e5e5e5); border: 1px solid light-dark(#dee2e6, #404040); }

按钮组件示例

.button { background: light-dark(#007bff, #0056b3); color: white; }

阴影效果示例

这个盒子有 light-dark() 阴影效果
box-shadow: light-dark( 0 4px 12px rgba(0, 0, 0, 0.15), 0 4px 12px rgba(0, 0, 0, 0.5) );

完整主题变量示例

:root { color-scheme: light dark; --text-primary: light-dark(#1a1a1a, #e5e5e5); --text-secondary: light-dark(#666666, #a0a0a0); --bg-primary: light-dark(#ffffff, #121212); --bg-secondary: light-dark(#f5f5f5, #1e1e1e); --border-color: light-dark(#e0e0e0, #333333); }
