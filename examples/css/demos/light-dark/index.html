CSS light-dark() 暗色模式切换函数

1. 基础颜色切换 核心功能

直接使用 light-dark(light-value, dark-value) 在两种颜色间切换，无需媒体查询。

代码风格
body { color: light-dark(#1a1a1a, #f0f0f0); background-color: light-dark(#ffffff, #121212); }

3. 代码高亮 代码块

light-dark() 可用于代码语法高亮，确保在暗色主题下也有良好可读性。

/* 亮色主题下关键词是红色 */ @media (prefers-color-scheme: dark) { /* 暗色主题下关键词是粉色 */ .code-keyword { color: #f97583; } }

4. 按钮样式

不同类型的按钮在明暗主题下的表现。

background-color: light-dark(#007bff, #4d9fff); color: light-dark(#fff, #121212);

5. 局部主题强制 进阶用法

通过设置 color-scheme: light 或 color-scheme: dark，可以强制某个区域使用特定主题，覆盖用户偏好。

强制浅色区域

此区域始终显示浅色主题，即使系统是暗色模式。

红色文字（浅色下）/ 橙色文字（深色下）
强制深色区域

此区域始终显示深色主题，即使系统是浅色模式。

红色文字（浅色下）/ 橙色文字（深色下）
工作原理：父元素的 color-scheme 会影响子元素中 light-dark() 的返回值。

6. 边框和阴影适配

light-dark() 可以用在任何接受颜色的 CSS 属性上。

带阴影的卡片

这个卡片的阴影在浅色主题下较淡，在深色主题下较深，符合真实世界的光照感知。

box-shadow: light-dark( 0 4px 16px rgba(0, 0, 0, 0.1), 0 4px 16px rgba(0, 0, 0, 0.5) );

7. 表单元素

输入框、标签等表单元素也能优雅地适配主题。

8. 与 prefers-color-scheme 对比

传统方式需要写多行媒体查询，而 light-dark() 一行搞定。

/* 传统方式：需要 @media 块 */ @media (prefers-color-scheme: light) { body { background: #fff; } } @media (prefers-color-scheme: dark) { body { background: #121212; } } /* light-dark() 方式：单行表达 */ body { background: light-dark(#fff, #121212); }
兼容性提示：light-dark() 从 2024 年 5 月起获得 Baseline 支持。 如需支持旧版浏览器，请使用 @media (prefers-color-scheme) 作为降级方案。
