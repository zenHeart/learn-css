CSS light-dark() 函数演示

根据配色方案自动切换亮色/暗色值的 CSS 颜色函数

部分支持

Safari 17.5+ · Chrome 123+ · Edge 123+ · Firefox (不支持)

配色方案切换

点击按钮切换当前配色方案，观察下方元素的颜色变化：

卡片组件

默认卡片
这是一张使用 light-dark() 的卡片组件，支持亮色和暗色主题自动切换。
卡片标题
悬停时阴影会变深，边框颜色也会随主题变化。

按钮组件

主按钮和次要按钮的边框、背景、文字颜色都会随主题切换。

表单控件

输入框的背景、边框、placeholder 颜色都会随主题切换，聚焦时边框高亮。

核心代码示例

/* 1. 声明支持 light 和 dark 配色方案 */
:root {
  color-scheme: light dark;
}

/* 2. 使用 light-dark() 直接切换颜色值 */
body {
  background-color: light-dark(#ffffff, #0f0f0f);
  color: light-dark(#1a1a1a, #f0f0f0);
}

/* 3. 应用到阴影（暗色模式需要更淡的阴影） */
.card {
  box-shadow: light-dark(
    0 2px 8px rgba(0, 0, 0, 0.08),
    0 2px 8px rgba(0, 0, 0, 0.4)
  );
}
