flex-flow 简写

flex-flow 是 flex-direction 和 flex-wrap 的简写：

flex-flow: row wrap; = flex-direction: row + flex-wrap: wrap
flex-flow: column nowrap; = flex-direction: column + flex-wrap: nowrap
