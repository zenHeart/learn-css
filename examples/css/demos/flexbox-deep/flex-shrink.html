缩小计算公式

简化计算：

溢出量 x (shrink x basis) / Sum(shrink x basis)

示例（容器 400px，三个 150px items）：
溢出量 = 450 - 400 = 50px
权重和 = 1x150 + 1x150 + 1x150 = 450
每个 item 收缩 = 50 x (1x150/450) = 16.67px
最终宽度 = 150 - 16.67 ~ 133px
