flex 简写 & align-self & order

flex 简写模式

简写等价值用途
flex: 0 0 100pxgrow:0, shrink:0, basis:100px固定尺寸，完全不伸缩
flex: 1grow:1, shrink:1, basis:0%等比伸缩，初始为0
flex: autogrow:1, shrink:1, basis:auto可伸缩，使用自身尺寸
flex: nonegrow:0, shrink:0, basis:auto完全不伸缩
flex: 2grow:2, shrink:1, basis:0%2倍伸缩比例
最常见错误：input { flex: 1; } 实际上等于 flex: 1 1 0%，初始尺寸是 0！
正确写法：input { flex: 1 1 auto; }

align-self 允许单个 item 覆盖容器 align-items 的设置

order 控制排列顺序

A
(order=3)
B
(order=1)
C
(order=2)
D
(order=0)
order 只改变视觉顺序，不改变 DOM 顺序！
屏幕阅读器仍按 DOM 顺序读取，对无障碍不友好。
order 默认为 0，数值越小越靠前。
