Sticky Footer 粘性页脚

Flexbox 实现 Sticky Footer

Header

内容区域

flex: 1 占据所有剩余空间

Footer - 始终在底部
html, body { height: 100%; } body { display: flex; flex-direction: column; } main { flex: 1; }
核心原理：flex: 1 让 main 区域占据所有剩余空间，footer 被推到最下方

常见错误写法

错误：使用 position: absolute
footer { position: absolute; bottom: 0; }
会导致 footer 覆盖内容，且不占文档流高度
正确：Flexbox
body { display: flex; flex-direction: column; min-height: 100vh; }
main { flex: 1; }
Footer 自然在底部，内容区域自适应
