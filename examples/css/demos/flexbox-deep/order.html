🔢 order 排列顺序

DOM 顺序 vs 视觉顺序

A
order=0
B
order=1
C
order=2
D
order=3
E
order=4
/* DOM: A → B → C → D → E */ /* 视觉: A → B → C → D → E (默认) */

典型应用：响应式布局

① 主要内容 (order:1)
② 侧边栏 (order:2)
③ 附加信息 (order:3)
④ 底部信息 (order:0)
💡 移动端优先：可以用 order 把主要内容放到最前面显示
⚠️ 无障碍警告：order 只改变视觉顺序，不改变 DOM 顺序！

屏幕阅读器按 DOM 顺序读取，不会受 order 影响。
这会导致视觉顺序与阅读顺序不一致，影响无障碍访问。

建议：尽量通过 HTML 结构调整顺序，order 仅用于视觉微调。

order 计算规则

规则：order 值相同时，按 DOM 顺序排列

order: 2 → 最靠后
order: 0 → 默认位置
order: -1 → 最靠前

可以使用负数让元素排到所有正数元素之前
