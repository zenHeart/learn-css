📈 flex-grow 放大比例

flex-grow 比例分配

容器宽度: 600px
item 基础总宽: 180px
剩余空间: 420px
60px
60px
60px
flex-grow: 1 1 1;
实际宽度：~200px each

计算公式

计算公式：

实际宽度 = 基础尺寸 + 剩余空间 × (grow / 总grow)

示例（容器 600px，三个 item 各 60px）：
剩余空间 = 600 - 60×3 = 420px
每个 item = 60 + 420×(1/3) = 200px

常见场景

flex: 1
fixed 120px
💡 flex: 1 让第一个 item 占据所有剩余空间，第二个保持固定 120px
