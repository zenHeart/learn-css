flex-basis 初始尺寸

flex-basis vs width 优先级

item
flex-basis: 200px; width: 100px; /* 结果: 200px */
优先级：max/min > flex-basis > width/height > 内容尺寸

flex-basis: auto vs 0

flex-basis: auto（默认）

auto
自适应内容
auto
使用 width 或内容尺寸作为基础，可正常自适应

flex-basis: 0

0
内容
0
初始尺寸为 0，内容被压缩再分配！

常见用法

flex: 0 0 200px; -> 固定 200px，不伸缩

flex: 1 1 auto; -> 可伸缩，使用 width/内容

flex: 1; -> 可伸缩，初始 0（常被误用！）

flex: none; -> 完全不伸缩 (0 0 auto)
