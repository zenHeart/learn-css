CSS color-mix() 颜色混合演示

基础语法

等比例混合
50% 红 + 50% 蓝
color-mix(in srgb, #ff0000 50%, #0000ff)
自定义比例
70% 红 + 30% 蓝
color-mix(in srgb, #ff0000 70%, #0000ff 30%)
与白色混合
50% 主色 + 50% 白 → 浅色
color-mix(in srgb, #3b82f6 50%, white)
与黑色混合
50% 主色 + 50% 黑 → 深色
color-mix(in srgb, #3b82f6 50%, black)

主题色混合实战

按钮状态
通过混合主色与白色/黑色，自动生成悬停态和激活态
色板变体
primary
light
dark
color-mix(in srgb, var(--primary) 70%, white/black)

状态色生成

成功状态
操作成功！您的更改已保存。
bg: color-mix(in srgb, #22c55e 15%, transparent)
警告状态
请注意，此操作不可撤销。
bg: color-mix(in srgb, #f59e0b 15%, transparent)
错误状态
发生错误，请重试。
bg: color-mix(in srgb, #ef4444 15%, transparent)

oklch 亮度混合（更自然的过渡）

同色相不同亮度
70% 亮度
+ 95% 亮度
+ 20% 亮度
color-mix(in oklch, oklch(70% 0.15 200) 50%, oklch(95%/0.1 200))

浏览器支持

✅ Chrome 111+、Firefox 113+、Safari 16.2+ 支持
