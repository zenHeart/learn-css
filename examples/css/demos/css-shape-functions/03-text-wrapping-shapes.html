CSS shape() 案例三：文字环绕异形图片

shape-outside: circle()

圆形图片文字环绕

CSS 的 shape-outside 属性允许文字环绕不规则形状的图片。通过定义 shape-outside，可以实现文字自然地贴合圆形边缘流动，而不是传统的矩形排列。 这项技术特别适合杂志风格的布局，让文字与图片形成有机的视觉结合。 结合 clip-path 裁剪图片形状，可以创造出优雅的图文混排效果。 shape-outside 不仅支持圆形，还支持 ellipse、polygon 等多种形状函数。

img { float: left; clip-path: circle(50% at 50% 50%); shape-outside: circle(50% at 50% 50%); }
shape-outside: ellipse()

椭圆图片文字环绕

使用 ellipse() 函数可以创建椭圆形状的文字环绕效果。相比圆形， 椭圆在横向布局中更加适用，可以在页面顶部放置一张宽幅的椭圆图片， 让文字在两侧自然流动。这种布局方式常见于个人简历、作品集展示等场景， 既展示了图片内容，又保证了文字的可读性。 椭圆的水平半径为 50%，垂直半径也是 50%，形成完美的椭圆形状。

img { float: left; clip-path: ellipse(50% 50% at 50% 50%); shape-outside: ellipse(50% 50% at 50% 50%); }
shape-outside: polygon()

六边形图片文字环绕

通过 polygon() 函数，我们可以创建六边形等更复杂形状的文字环绕。 六边形给人一种稳定、现代的视觉感受，适合科技、设计类网站的内容展示。 文字会精确地沿着六边形的每一条边流动，创造出独特的阅读体验。 这种不规则的图文布局打破了传统网格的束缚，让页面更加生动有趣。 结合 hover 动画，还可以实现悬停时形状变化的交互效果。

img { float: left; clip-path: polygon( 25% 0%, 75% 0%, 100% 50%, 75% 100%, 25% 100%, 0% 50% ); shape-outside: polygon( 25% 0%, 75% 0%, 100% 50%, 75% 100%, 25% 100%, 0% 50% ); }
shape-outside + transform

菱形图片文字环绕

菱形布局需要配合 transform: rotate() 来实现。由于 shape-outside 定义的形状不能直接旋转，我们需要将图片包裹在一个容器中，对容器应用 shape-outside，对图片应用 rotate(45deg)。这种技巧可以创建倾斜的 菱形图片，同时保持文字环绕的效果。在艺术展览、个人摄影作品集等场景中 非常适用，能够营造出独特的视觉冲击力。

.diamond-wrapper { float: left; shape-outside: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%); } img { transform: rotate(45deg); }
shape-outside: polygon() (右侧)

斜切角图片（文字在左）

使用 polygon() 可以创建带有斜切角的图片造型。将图片放置在右侧， 文字在左侧流动，可以创造出独特的杂志风布局。斜切的角度可以根据 视觉效果自由调整，本例中使用 40px 的斜切距离。这种技术在现代网页 设计中常用于卡片组件的装饰性处理，能够在不增加额外 HTML 元素的情况下 实现复杂的视觉效果。

img { float: right; clip-path: polygon( 0 0, calc(100% - 40px) 0, 100% 40px, 100% 100%, 0 100% ); shape-outside: polygon( 0 0, calc(100% - 40px) 0, 100% 40px, 100% 100%, 0 100% ); }
多图片 shape-outside 组合

叠加图片组文字环绕

通过叠加多张带有 shape-outside 的图片，可以创建更复杂的文字环绕效果。 在这个示例中，两张圆形图片叠加在一起，前景图片完全不透明， 背景图片半透明，文字沿着两个圆的边缘流动。这种技术常用于个人介绍、 团队展示等场景，可以展示多个人物头像的同时，保持版面的整洁和可读性。 通过调整 z-index 和 opacity，可以控制图片之间的层次关系。

.img-stack { position: relative; } .img-stack img:first-child { position: relative; z-index: 2; clip-path: circle(50%); shape-outside: circle(50%); } .img-stack img:last-child { position: absolute; top: 20px; left: 20px; z-index: 1; clip-path: circle(50%); shape-outside: circle(50%); opacity: 0.7; }
