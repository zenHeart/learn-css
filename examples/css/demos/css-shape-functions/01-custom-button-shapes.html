胶囊形按钮

使用 border-radius: 50px 实现胶囊形状

border-radius: 50px; background: linear-gradient(...);

圆形按钮

+

使用 border-radius: 50% 实现完美圆形

border-radius: 50%; width: 80px; height: 80px;

箭头按钮（hover 展开）

了解更多

clip-path 裁剪出三角形，hover 时展开

clip-path: polygon( 0 0, calc(100% - 20px) 0, 100% 50%, calc(100% - 20px) 100%, 0 100% );

六边形按钮

六边形

polygon 裁剪出六边形轮廓

clip-path: polygon( 25% 0%, 75% 0%, 100% 50%, 75% 100%, 25% 100%, 0% 50% );

菱形按钮

菱形

clip-path: polygon 实现 45 度旋转方形

clip-path: polygon( 50% 0%, 100% 50%, 50% 100%, 0% 50% );

兔子耳朵气泡

气泡按钮

复杂 polygon 裁剪出耳朵造型

clip-path: polygon( 0 45%, 15% 45%, 15% 0%, 30% 15%, 45% 0%, 45% 45%, 100% 45%, 100% 100%, 0 100% );

消息

polygon 裁剪出带三角箭头的气泡

动画变形按钮

变形中

keyframes 动画在圆形和菱形间切换

@keyframes btnMorph { 0%, 100% { clip-path: circle(50%); } 50% { clip-path: polygon( 50% 0%, 100% 50%, 50% 100%, 0% 50% ); } }
