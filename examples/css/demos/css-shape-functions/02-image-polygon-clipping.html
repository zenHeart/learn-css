CSS shape() 案例二：图片多边形裁剪

六边形（hover 扩展）

polygon 裁剪六边形，hover 时轻微放大

clip-path: polygon( 25% 0%, 75% 0%, 100% 50%, 75% 100%, 25% 100%, 0% 50% );

菱形（hover 变形）

hover 时从菱形变成倒菱形

clip-path: polygon( 50% 0%, 100% 50%, 50% 100%, 0% 50% );

三角形（hover 变化）

polygon 实现三角形裁剪

clip-path: polygon( 50% 0%, 100% 100%, 0% 100% );

斜切角（hover 加深）

右上角斜切造型，现代卡片风格

clip-path: polygon( 0 0, calc(100% - 30px) 0, 100% 30px, 100% 100%, 0 100% );

五边形

五边形裁剪，建筑/科技感

clip-path: polygon( 50% 0%, 100% 38%, 82% 100%, 18% 100%, 0% 38% );

八边形

八边形裁剪，规整对称

clip-path: polygon( 30% 0%, 70% 0%, 100% 30%, 100% 70%, 70% 100%, 30% 100%, 0% 70%, 0% 30% );

圆形头像

circle() 实现完美圆形裁剪

clip-path: circle(50% at 50% 50%);

椭圆

ellipse() 创建横向椭圆

clip-path: ellipse(50% 40% at 50% 50%);

胶囊形

ellipse 50% 50% 实现胶囊/药丸形

clip-path: ellipse(50% 50% at 50% 50%);

动画变形

keyframes 实现循环变形动画

@keyframes imgMorph { 0%, 100% { clip-path: circle(50%); } 50% { clip-path: polygon( 50% 0%, 100% 50%, 50% 100%, 0% 50% ); } }

四叶草形

12 个点的复杂 polygon

clip-path: polygon( 50% 0%, 60% 35%, 100% 35%, 75% 60%, 100% 100%, 60% 75%, 50% 100%, 40% 75%, 0% 100%, 25% 60%, 0% 35%, 40% 35% );

星形

10 个点的标准五角星

clip-path: polygon( 50% 0%, 61% 35%, 98% 35%, 68% 57%, 79% 91%, 50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35% );
