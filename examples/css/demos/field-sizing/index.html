CSS field-sizing 交互演示

表单元素根据内容自动调整尺寸，无需 JavaScript（需 Chrome 123+ 或 Chromium 内核浏览器）

Input 自动宽度

field-sizing: content
field-sizing: fixed（默认）
input { field-sizing: content; min-width: 80px; max-width: 300px; }

Textarea 自动高度

field-sizing: content
field-sizing: fixed（默认）
textarea { field-sizing: content; width: 300px; max-height: 200px; resize: none; }

Select 自动宽度

field-sizing: content
field-sizing: fixed（默认）
select { field-sizing: content; min-width: 100px; }

实际应用：标签输入框

聊天工具、邮件客户端中常见的标签输入框，标签数量不固定

CSS × JavaScript ×
.tag-input-wrapper input { field-sizing: content; min-width: 60px; border: none; outline: none; padding: 4px 8px; }
⚠️ field-sizing 目前为 Chromium 123+ 实验性功能。如浏览器不支持，演示中的 content 版本会回退为 fixed 行为。
