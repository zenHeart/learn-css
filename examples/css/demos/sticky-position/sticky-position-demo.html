什么是 Sticky 定位？

一句话理解
Sticky = relative + fixed 的混合体。元素在滚动时表现为 relative，达到阈值后表现为 fixed。

核心特性

  • 未滚动时：像 position: relative 一样占据文档流位置
  • 滚动超过阈值：像 position: fixed 一样固定在视口
  • 不会脱离文档流：占据的空间始终保留
  • 父容器是关键：父容器的高度和 overflow 属性直接影响 sticky 行为

与其他定位对比

定位类型 参照物 脱标 滚动行为
relative 元素原位置 否 随页面滚动
absolute 定位祖先 是 随容器滚动
fixed 视口 是 固定不动
sticky 滚动容器 否 阈值前随页面滚动，阈值后固定

工作原理图解

1 初始状态：sticky 元素在文档流中正常定位（relative 行为）
2 用户开始滚动，sticky 元素随页面移动
3 滚动超过 top 值设定的阈值
4 sticky 元素"粘"在视口指定位置（fixed 行为）
5 滚动到父容器底部，sticky 效果解除

必须条件

✓ 父容器不能有 overflow: hidden/auto/scroll
✓ 父容器高度必须大于 sticky 元素
✓ 必须指定 top/bottom/left/right 之一
✓ 祖先元素不能有 transform 属性

实际应用场景

📝 表单提交按钮固定

场景：长表单页面，提交按钮需要始终可见。
方案：使用 position: sticky + bottom: 0 让按钮固定在视口底部。

📊 表格列头固定

场景：数据表格很长，滚动时列头需要始终可见。
方案：给 thead th 设置 position: sticky + top: 0。

HTML 结构

<div class="card">
  <div class="card-content">
    <h3>卡片标题</h3>
    <p>卡片内容...</p>
  </div>
  <div class="card-footer">
    <button>操作按钮</button>
  </div>
</div>

CSS 样式

.card {
  position: relative; /* 关键：创建定位上下文 */
  background: white;
  border-radius: 12px;
  margin-bottom: 20px;
}

.card-footer {
  position: sticky;    /* 启用 sticky */
  bottom: 0;          /* 距离底部 0 时固定 */
  background: white;   /* 背景色覆盖下方内容 */
  padding: 12px 16px;
  border-top: 1px solid #eee;
}

button {
  width: 100%;
  padding: 12px;
  background: #007AFF;
  color: white;
  border: none;
  border-radius: 8px;
  cursor: pointer;
}

方案对比

方案 优点 缺点 适用场景
Sticky 包裹按钮 简单、原生支持 父容器 overflow 影响 大多数场景
按钮独立 sticky 更灵活 需要预留空间 按钮在内容区底部
Fixed 定位 不受父容器影响 需要 JS 控制显隐 复杂交互场景

iOS Safari 兼容处理

⚠️ iOS Safari 问题
iOS Safari 14.5 以下版本对 sticky 支持不完整，需要使用 -webkit- 前缀。
/* iOS Safari Hack */
.sticky-footer {
  position: sticky;
  position: -webkit-sticky; /* iOS Safari */
  bottom: 0;
  /* 添加 transform 触发 GPU 加速 */
  transform: translateZ(0);
}

降级方案

✅ 推荐降级写法
使用 @supports 检测浏览器支持情况，不支持时降级为 fixed。
@supports (position: sticky) {
  .sticky-element {
    position: sticky;
    top: 0;
  }
}

@supports not (position: sticky) {
  .sticky-element {
    position: fixed;
    bottom: 0;
    width: 100%;
  }
}

Sticky 不生效？按顺序检查！

1 是否指定了 top/bottom/left/right？
position: sticky 单独写不会生效，必须配合偏移值。
2 父容器是否有 overflow 设置？
overflow: hidden/auto/scroll 会阻断 sticky 效果。
3 父容器高度是否足够？
如果父容器比 sticky 元素还矮，就不会有滚动空间。
4 祖先元素是否有 transform？
transform 会创建新的 containing block，影响 sticky 参照。
5 是否在 flex 容器内？
flex 子元素的 sticky 行为可能不符合预期。

常见错误代码

错误 1：忘记写偏移值

❌ 错误写法
.sticky {
  position: sticky;
  /* 忘记写 top/bottom! */
}
✅ 正确写法
.sticky {
  position: sticky;
  top: 0; /* 必须写！ */
}

错误 2：父容器 overflow 阻断

❌ 错误写法
.parent {
  overflow: hidden; /* 阻断 sticky! */
}

.sticky {
  position: sticky;
  top: 0;
}
✅ 正确写法
.parent {
  overflow: visible; /* 或不设置 */
}

.sticky {
  position: sticky;
  top: 0;
}

错误 3：祖先元素有 transform

❌ 错误写法
.ancestor {
  transform: translateZ(0); /* 创建新的 containing block! */
}

.parent {
  /* sticky 效果会被影响 */
}

iOS Safari 特殊处理

iOS Safari 兼容清单
1. 使用 -webkit- 前缀
2. 确保父容器不是 overflow: hidden
3. 添加 transform: translateZ(0) 触发 GPU 加速
