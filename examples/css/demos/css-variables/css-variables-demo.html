基础语法

定义与使用

CSS 变量以 -- 开头，使用 var() 函数调用：

:root { --primary-color: #3b82f6; --spacing: 16px; } .button { background: var(--primary-color); padding: var(--spacing); }

实时演示

演示方块

var() 函数

color: var(--color); /* 基本用法 */ color: var(--color, #000); /* 带默认值 */ color: var(--color, #000, #fff); /* 多默认值 */

作用域与继承

DOM 树查找

CSS 变量会沿着 DOM 树向上查找：

:root { --color: blue; } /* 全局 */ .parent { --color: red; } /* 覆盖 */ .child { --color: green; } /* 最优先 */
:root (blue)
.parent (red)
.child (green) - 最优先

局部作用域

组件变量只在组件内部有效：

.card { --card-bg: white; /* 仅 .card 及其后代可用 */ background: var(--card-bg); } .card__title { /* 自动继承 --card-bg */ background: var(--card-bg); }

层级覆盖示例

  • 🔵 :root --color: blue (全局)
  • 🔴 .parent --color: red (覆盖 :root)
  • 🟢 .child --color: green (覆盖 .parent)
  • 📌 子元素会使用最近祖先定义的值

JavaScript 交互

读取变量

const styles = getComputedStyle(element); const color = styles.getPropertyValue('--primary-color'); console.log(color); // #3b82f6

设置变量

// 设置变量 element.style.setProperty('--primary-color', '#10b981'); // 带单位 element.style.setProperty('--spacing', '24px'); // 移除变量 element.style.removeProperty('--primary-color');

点击按钮改变我

组件变体

使用 CSS 变量实现按钮变体：

.button { --btn-bg: var(--primary); --btn-color: white; --btn-padding: 12px 24px; background: var(--btn-bg); color: var(--btn-color); padding: var(--btn-padding); } .button.secondary { --btn-bg: transparent; --btn-color: var(--primary); }
💡 主题切换最佳实践
  • 使用 data-theme 属性而非 class
  • 将主题变量定义在 :root 或 [data-theme] 上
  • 配合 localStorage 保存用户偏好

速查表

变量定义与使用

语法 说明
--name: value; 定义变量
var(--name) 使用变量
var(--name, fallback) 带默认值
:root 全局作用域

JavaScript API

方法 说明
getPropertyValue() 读取变量
setProperty() 设置变量
removeProperty() 移除变量

常见用途

  • ✅ 统一管理颜色、间距等设计 token
  • ✅ 主题切换（亮色/暗色/品牌色）
  • ✅ 组件变体（大小、颜色、样式覆盖）
  • ✅ 响应式设计（断点切换变量值）
  • ✅ 动画过渡（动态修改变量实现动画）
📌 命名规范
  • 使用 kebab-case: --primary-color
  • 使用语义化命名: --color-text-primary
  • 避免通用名称: --temp-1
