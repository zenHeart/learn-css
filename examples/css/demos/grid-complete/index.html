核心代码解析

.holy-grail {
  display: grid;
  /* 三栏：左侧 180px | 中间自适应 | 右侧 180px */
  grid-template-columns: 180px 1fr 180px;
  /* 两行内容区 + 固定头底 */
  grid-template-rows: 56px 1fr 44px;
  /* 具名网格区域 — 直观描述页面结构 */
  grid-template-areas:
    "header  header  header"
    "left    main    right"
    "footer  footer  footer";
  gap: 12px;
}

/* 移动端：全宽单列堆叠 */
@media (max-width: 600px) {
  .holy-grail {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "left"
      "main"
      "right"
      "footer";
  }
}
Responsive

响应式网格

使用 auto-fit / auto-fill 配合 minmax()，无需任何媒体查询即可自动响应式调整列数。auto-fit 在项目不足填满整行时会将空白空间分发给所有项目，而 auto-fill 则保持项目自身宽度不拉伸。

auto-fit vs auto-fill 对比

/* auto-fit：项目拉伸填满整行（常用） */
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

/* auto-fill：项目保持固定尺寸，不拉伸（适合均分布局） */
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));

/* minmax(min, max) 保证每列不小于 min，不大于 max */
/* 当容器宽度 < min 时，自动换行 */

12 列系统代码解析

.magazine-layout {
  display: grid;
  /* 12 列等宽轨道，配合 gap */
  grid-template-columns: repeat(12, 1fr);
  gap: 12px;
}

/* 头条占前 7 列，跨 2 行 */
.ml-hero    { grid-column: 1 / 8;  grid-row: 1 / 3; }
/* 侧栏占后 5 列，跨 2 行 */
.ml-sidebar { grid-column: 8 / 13; grid-row: 1 / 3; }
/* CTA 占前 4 列 */
.ml-cta     { grid-column: 1 / 5; }
/* 新闻占 5-9 列 */
.ml-news    { grid-column: 5 / 9; }
/* 引用占 9-13 列 */
.ml-quote   { grid-column: 9 / 13; }

Subgrid — 嵌套组件对齐

/* 父容器定义网格 */
.card-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

/* 子组件继承父网格轨道 */
.card-inner {
  grid-column: span 3;   /* 占满整行 */
  display: grid;
  grid-template-columns: subgrid; /* 继承父的 3 列定义 */
  gap: 16px;
}
.card-inner > * {
  grid-column: span 1;   /* 每项对齐到父网格的对应列 */
}
