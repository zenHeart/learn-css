CSS @layer 层叠优先级

层叠层 | 样式隔离 | !important 交互 | 框架集成

案例 1层叠顺序

层叠卡片
1 @layer base
#1a1a1a
2 @layer components
#3b82f6
3 @layer utilities
#22c55e
★ 未分层样式
#f59e0b (生效)
/* 层级定义（由低到高） */ @layer base { .card { background: #1a1a1a; } } @layer components { .card { background: #3b82f6; } } @layer utilities { .card { background: #22c55e; } } /* 未分层样式，优先级最高 */ .card { background: #f59e0b; }

后声明的层优先级更高。未分层样式的优先级最高。

案例 2!important 优先级反转

!important 反转了层叠顺序
@layer base { .badge { color: blue; } /* 蓝色文字 */ } @layer components { .badge { color: red !important; } /* !important 提升优先级 */ } /* 结果：蓝色文字生效（base 层 + !important） */

使用 !important 时，层叠顺序会反转：先声明的层优先级更高。

案例 3框架样式隔离

@layer framework { .btn { background: #374151; color: #d1d5db; } } /* 应用层在更高优先级 */ @layer app { .btn { background: #3b82f6; color: white; } }

框架样式在低层，应用样式在高层，后声明覆盖先声明。

案例 4UTILITY 类优先级控制

.text-red
@layer utilities { .text-red { color: red; } } @layer overrides { .text-red { color: #ef4444; } /* 覆盖 utilities */ }

utilities 层定义的 .red 被 overrides 层覆盖为更深的红色。

技巧预声明层顺序

/* 1. 先声明层的顺序（空层占位） */ @layer base, reset, components, utilities, overrides; /* 2. 然后填充内容，顺序已固定 */ @layer base { /* ... */ } @layer utilities { /* ... */ } @layer overrides { /* ... */ } /* 无论填充顺序如何，优先级始终： base < reset < components < utilities < overrides */

提前声明层顺序，即使后面填充内容的顺序不同，也不影响优先级。
