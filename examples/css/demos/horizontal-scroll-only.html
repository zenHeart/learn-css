限制只有水平方向滚动 - CSS Horizontal Scroll Only

核心原理

限制水平滚动的关键在于：
1. overflow-x: auto | scroll — 允许水平方向溢出时产生滚动条
2. overflow-y: hidden — 隐藏垂直方向溢出，禁止垂直滚动
3. 内容必须横向排列（flex/grid/inline-block）

⚠️ 踩坑警告：overflow-x: visible + overflow-y: hidden 组合是无效的！ MDN 明确说明：当 overflow-x 或 overflow-y 其中一个设为 visible，另一个设为 hidden/auto/scroll 时， visible 的一方会隐式转换为 auto。
方案一（推荐）
overflow-x: auto + overflow-y: hidden + white-space: nowrap

✅ 最简单直接的方式：overflow-x:auto 开启水平滚动，overflow-y:hidden 禁止垂直溢出， white-space:nowrap 确保内容不换行横向排列。
/* 核心 CSS */ overflow-x: auto; /* 允许水平滚动 */ overflow-y: hidden; /* 禁止垂直滚动 */ white-space: nowrap; /* 强制内容不换行 */

✅ Flexbox 方式更灵活，适合需要精确控制子元素大小的场景。 flex-shrink: 0 防止子元素被压缩。
display: flex; flex-wrap: nowrap; /* 强制不换行 */ overflow-x: auto; /* 允许水平滚动 */ overflow-y: hidden; /* 禁止垂直溢出 */ /* 子元素 */ flex-shrink: 0; /* 防止被压缩 */

✅ scroll-snap 让滚动停止时自动吸附到指定位置，适合轮播、卡片列表等场景。 scroll-snap-type: x mandatory 强制吸附，scroll-snap-align: start 定义吸附点。

💡 传统方法：使用 inline-block 排列元素，配合 white-space: nowrap。 注意：需要设置 font-size: 0 消除元素间的空白间隙。
/* 父容器 */ overflow-x: auto; overflow-y: hidden; white-space: nowrap; font-size: 0; /* 消除行内块间隙 */ /* 子元素 */ display: inline-block; min-width: 120px; font-size: 14px; /* 恢复字体大小 */

💡 CSS Grid 方式：grid-auto-flow: column 让网格按列方向自动填充，适合固定大小的卡片。
display: grid; grid-auto-flow: column; /* 沿列方向自动排列 */ overflow-x: auto; overflow-y: hidden; grid-auto-columns: 120px; /* 每列宽度 */ grid-gap: 12px; /* 间距 */

⚠️ 问题原因：根据 CSS 规范，当 overflow-x 和 overflow-y 其中一个设为 visible， 另一个设为 hidden/auto/scroll 时，visible 的一方会隐式转换为 auto。 因此 overflow-x: visible 实际上会变成 overflow-x: auto，但开发者期望它能滚动，实际却无法滚动。
/* ❌ 错误写法 — overflow-x: visible 无效！*/ overflow-x: visible; /* MDN 明确不推荐！*/ overflow-y: hidden; /* ✅ 正确写法 */ overflow-x: auto; overflow-y: hidden;
📖 参考资料：MDN overflow 文档 明确说明：设置一个轴为 visible，另一个轴为 hidden/auto/scroll 的组合是无效的，会导致未定义行为。
