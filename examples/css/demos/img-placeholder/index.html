img 标签无图片时背景色控制

学习如何使用 CSS 控制 img 标签在无图片或加载失败时的背景色占位

Demo 1: 错误方案 vs 正确方案

⚠️ 问题说明

直接给 img 元素设置 background-color 在图片加载失败时不会显示， 因为 img 是替换元素，其渲染由 src 内容决定。需要使用 wrapper 元素来实现背景色占位。

❌ 错误方案

直接在 img 上设置 background-color
图片加载失败，但背景色未显示。
浏览器显示默认破碎图标。

✅ 正确方案

使用 wrapper + background-color
使用 wrapper 作为背景色容器，
图片绝对定位覆盖。
