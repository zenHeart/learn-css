CSS Houdini Layout API — 居中布局

⚠️ Layout API 需要在 Chrome/Edge 中开启实验性功能：chrome://flags/#enable-experimental-web-platform-features

Worklet 实现

class CenteringLayout { async layout(children, edges, constraints, styleMap) { const availW = constraints.fixedInlineSize - edges.inline; const availH = constraints.fixedBlockSize - edges.block; const childFragments = []; for (const child of children) { const fragment = await child.layoutNextFragment({ availW, availH }); fragment.inlineOffset = edges.inlineStart + (availW - fragment.inlineSize) / 2; fragment.blockOffset = edges.blockStart + (availH - fragment.blockSize) / 2; childFragments.push(fragment); } return { autoBlockSize: availH, childFragments }; } } registerLayout('centering', CenteringLayout);

效果演示（Flexbox 模拟）

内容
/* CSS */ .center-container { display: layout(centering); }

关键参数

constraints.fixedInlineSize：容器宽度
edges.inline：左右 padding + border 之和
fragment.inlineOffset/blockOffset：子元素 x/y 坐标
