CSS Houdini Layout API — 居中布局

通过 registerLayout 注册居中布局算法，用 JS 完全控制子元素定位

⚠️ Layout API 需要在 Chrome/Edge 中开启实验性功能：chrome://flags/#enable-experimental-web-platform-features

Worklet 实现

class CenteringLayout { async layout(children, edges, constraints, styleMap) { const availableInlineSize = constraints.fixedInlineSize - edges.inline; const availableBlockSize = constraints.fixedBlockSize - edges.block; const childFragments = []; for (const child of children) { const fragment = await child.layoutNextFragment({ availableInlineSize, availableBlockSize }); // 居中放置 fragment.inlineOffset = edges.inlineStart + (availableInlineSize - fragment.inlineSize) / 2; fragment.blockOffset = edges.blockStart + (availableBlockSize - fragment.blockSize) / 2; childFragments.push(fragment); } return { autoBlockSize: availableBlockSize, childFragments }; } } registerLayout('centering', CenteringLayout);

效果演示（Fallback — Flexbox 模拟）

启用 Layout API 后，CSS 中使用 display: layout(centering) 即可实现相同效果

内容
/* CSS 使用 */ .center-container { display: layout(centering); /* 代替 flex 实现居中 */ width: 400px; height: 300px; }

关键参数说明

constraints.fixedInlineSize：容器宽度（类似 width）
edges.inline：左右 padding + border + scrollbar 之和
fragment.inlineOffset：子元素的 x 坐标
fragment.blockOffset：子元素的 y 坐标
