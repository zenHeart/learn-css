CSS Houdini Layout API

通过 registerLayout 注册自定义布局算法，像 display: flex 一样自定义布局逻辑

⚠️ Layout API 目前在 Chromium 中支持有限，且需要通过 HTTP 服务器 访问。
启动方式：python -m http.server 8080 或 npx serve .
浏览器支持： Chrome 65+（部分） Edge 79+（部分） Firefox ❌ Safari ❌

注意：Layout API 需要在 Chrome/Edge 中开启实验性功能。访问 chrome://flags/#enable-experimental-web-platform-features 启用。

居中布局（Centering）

演示如何用 Layout API 创建居中布局，childFragments 如何设置 inlineOffset/blockOffset 实现居中。

入门级

等分布局（Equal Columns）

演示水平等分布局，计算可用空间并分配给每个子元素。

进阶

瀑布流布局（Masonry）

演示用 Layout API 实现瀑布流效果，自动选择最短列放置元素。
