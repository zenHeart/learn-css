交互式体验 10 种 CSS 滤镜函数

💡 关于 CSS filter

CSS filter 属性为元素应用图形效果，如模糊、亮度调整、对比度调整等。 可以组合多个滤镜函数，按从左到右的顺序依次应用。

blur() 高斯模糊

模糊半径 5px 
filter: blur(5px);

预设值

brightness() 亮度调整

亮度 100% 
filter: brightness(100%);

预设值

contrast() 对比度调整

对比度 100% 
filter: contrast(100%);

预设值

drop-shadow() 投影

水平偏移 5px
垂直偏移 5px
模糊半径 8px 
filter: drop-shadow(5px 5px 8px rgba(0,0,0,0.4));

预设效果

grayscale() 灰度转换

灰度 50% 
filter: grayscale(50%);

预设值

hue-rotate() 色相旋转

旋转角度 90deg 
filter: hue-rotate(90deg);

预设值

invert() 反相

反相程度 50% 
filter: invert(50%);

预设值

opacity() 透明度

透明度 50% 
filter: opacity(50%);

预设值

saturate() 饱和度

饱和度 100% 
filter: saturate(100%);

预设值

sepia() 棕褐色

棕褐色 50% 
filter: sepia(50%);

预设值

🎨 滤镜组合效果

多个滤镜函数可以链式组合，创造丰富的视觉效果

contrast + brightness
增强对比与亮度
grayscale + contrast
高对比黑白
sepia + contrast + brightness
复古风格
saturate + hue-rotate
冷色调风格
saturate + brightness + sepia
暖色调风格
blur + brightness + contrast
柔焦效果
/* 常用组合示例 */

/* 高对比黑白 */
filter: grayscale(100%) contrast(150%);

/* 复古风格 */
filter: sepia(40%) contrast(110%) brightness(90%);

/* 冷色调 */
filter: saturate(140%) hue-rotate(180deg);

/* 柔焦 */
filter: blur(2px) brightness(110%) contrast(90%);
