✨ SVG 动画效果演示

纯 CSS + SMIL + JavaScript 实现的各种 SVG 动画效果

🔄 加载动画

<circle class="spin" stroke-dasharray="150" stroke-dashoffset="40"/> /* CSS */ @keyframes spin { from { transform: rotate(0deg); } to { transform: rotate(360deg); } } .spin { animation: spin 1s linear infinite; }

🌈 颜色渐变动画

<animate attributeName="stop-color" values="#667eea;#764ba2;#f093fb;#667eea" dur="3s" repeatCount="indefinite"/>

💓 脉冲动画

@keyframes pulse { 0%, 100% { transform: scale(1); opacity: 1; } 50% { transform: scale(1.1); opacity: 0.8; } } .pulse { animation: pulse 1.5s ease-in-out infinite; }

🎾 弹跳动画

@keyframes bounce { 0%, 100% { transform: translateY(0); } 50% { transform: translateY(-20px); } } .bounce { animation: bounce 1s ease-in-out infinite; }

✏️ 路径绘制动画

@keyframes draw { to { stroke-dashoffset: 0; } } .draw { stroke-dasharray: 300; stroke-dashoffset: 300; animation: draw 2s ease forwards; }

🌊 波浪动画

@keyframes waveMove { 0%, 100% { transform: translateX(0); } 50% { transform: translateX(10px); } } .wave-path { animation: waveMove 2s ease-in-out infinite; }

🌀 SMIL 旋转

<animateTransform attributeName="transform" type="rotate" from="0 50 50" to="360 50 50" dur="2s"/>

🚗 路径运动动画

<animateMotion dur="3s" repeatCount="indefinite"> <mpath href="#motionPath"/> </animateMotion>

📊 动画性能对比

属性 性能 说明
transform ✅ 好 GPU 加速，推荐使用
opacity ✅ 好 GPU 加速，推荐使用
fill, stroke ⚠️ 中 可能触发重绘
width, height ❌ 差 触发布局计算，避免使用
