# 做事的步骤
在编写 css 时注意先设置通用样式。在进行局部修订。
不要直接利用 class 进行布局。这样会导致在后续修改中基础样式被覆盖。

设计基础样式，统一在基本类中修改。
详细的位置字体等信息才需要去细调节。

## 视图影响逻辑
> 由于页面的点击事件,是基于元素的.而元素的范围与盒模型有关.
所有若元素的的尺寸发生变化,可能导致无法触发点击事件而导致错误.

在任何涉及界面的事件中需要确保元素的尺寸的视图事件没有影响!
通过键盘即可产生该效果.
