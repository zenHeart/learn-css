CSS Scroll & Overflow 交互式演示

overflow 属性值对比
对比 overflow 的五个主要属性值：visible、hidden、scroll、auto、clip。注意它们的滚动能力和裁剪行为差异。
overflow: visible
这是 visible 模式，内容会溢出容器边界并显示出来。滚动条不会出现。
overflow: hidden
这是 hidden 模式，内容被裁剪，无法滚动查看溢出部分。可以用 scrollTop 滚动。
overflow: scroll
这是 scroll 模式，始终显示滚动条，即使内容没有溢出。
overflow: auto
这是 auto 模式，仅在内容溢出时才显示滚动条，是最推荐的值。
overflow: clip
这是 clip 模式，严格裁剪溢出内容，禁止任何滚动（包括 JS scrollTop）。
overflow-x 与 overflow-y 独立控制
使用 overflow-x 和 overflow-y 可以分别控制水平和垂直方向的溢出行为。

跨浏览器兼容方案
完整的跨浏览器隐藏滚动条代码：
.hide-scrollbar {
  overflow: auto;              /* 保持滚动 */
  scrollbar-width: none;       /* Firefox: 隐藏滚动条 */
  -ms-overflow-style: none;    /* IE/Edge 旧版: 隐藏滚动条 */
}

.hide-scrollbar::-webkit-scrollbar {
  display: none;               /* Chrome/Safari/Edge: 隐藏滚动条 */
}

/* 自定义滚动条 */
.custom-scrollbar {
  overflow-y: auto;
}

.custom-scrollbar::-webkit-scrollbar {
  width: 6px;
}

.custom-scrollbar::-webkit-scrollbar-track {
  background: #1a1a2e;
  border-radius: 3px;
}

.custom-scrollbar::-webkit-scrollbar-thumb {
  background: #00d9ff;
  border-radius: 3px;
}

.custom-scrollbar::-webkit-scrollbar-thumb:hover {
  background: #00b8d9;
}
