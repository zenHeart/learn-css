text-overflow: ellipsis 工作原理

1 浏览器根据 white-space 和 overflow 属性判断容器是否需要截断文本
2 当文本超出容器宽度，overflow: hidden 裁剪溢出部分
3 text-overflow: ellipsis 让渲染引擎在截断位置插入省略号字符 "…"
4 省略号是渲染层附加的字符，不是 DOM 节点，无法通过 CSS 选择器单独控制

为什么 padding-right 能产生间距？

当给容器添加 padding-right: 16px 时：

  1. 容器内容区域减小 16px（右边距）
  2. 文本在更窄的内容区域内截断
  3. 省略号出现在更左侧的位置
  4. 省略号右侧有 16px 的留白（padding 区域）

关键点：这实际上不是省略号和文字之间的间距，而是省略号和容器右边缘之间的间距。 省略号始终紧贴最后一个可见字符。

padding-right vs padding-left 的区别

属性 效果 适用场景
padding-right 省略号左移，产生右间距 ✅ 推荐，最常用
padding-left 内容整体右移，省略号位置不变 ❌ 不影响省略号位置

推荐选择

✅ 首选：padding-right
简单、兼容、效果好，满足大多数场景
✅ 多行文本：-webkit-line-clamp + padding
配合 padding-bottom 控制多行省略号间距
⚠️ 需要前后都有间距：伪元素
可以精确控制省略号前后两端的间距
