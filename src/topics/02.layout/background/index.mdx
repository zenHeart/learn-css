# CSS background 背景属性完整指南

## 概述

CSS `background` 属性是用于控制元素背景的一组复合属性，涵盖颜色、图片、渐变、定位、尺寸、重复方式、固定方式等多个维度。本文档系统整理 background 相关的所有属性及其组合用法。

## 1. background-color 背景颜色

```css
background-color: #ff5733;
background-color: rgb(255, 87, 51);
background-color: hsl(14, 100%, 60%);
background-color: transparent;
```

**层叠规则**：背景颜色在最底层绘制，会被 `background-image` 覆盖。

## 2. background-image 背景图片

### 2.1 URL 图片

```css
background-image: url('bg.png');
background-image: url('https://example.com/bg.jpg');
```

### 2.2 CSS 渐变

**线性渐变 linear-gradient**

```css
/* 基本用法 */
background: linear-gradient(red, yellow);

/* 方向控制 */
background: linear-gradient(to right, red, yellow);           /* 从左到右 */
background: linear-gradient(to bottom right, red, yellow);    /* 左上到右下 */
background: linear-gradient(45deg, red, yellow);             /* 45度角 */
background: linear-gradient(to right, red 0%, yellow 50%, green 100%); /* 颜色停点 */
```

**径向渐变 radial-gradient**

```css
background: radial-gradient(circle, red, yellow);
background: radial-gradient(ellipse at top, red, yellow);
background: radial-gradient(circle at 30% 70%, red 0%, blue 100%);
```

**圆锥渐变 conic-gradient**

```css
background: conic-gradient(from 0deg, red, yellow, green, red);
background: conic-gradient(from 90deg at 50% 50%, red, yellow, green);
```

### 2.3 多层背景

```css
background-image: url('pattern.png'), linear-gradient(135deg, #667eea, #764ba2);
background-size: 50px 50px, 100% 100%;
```

## 3. background-repeat 重复方式

| 值 | 描述 |
|---|---|
| `repeat` | 默认，水平和垂直方向都重复 |
| `no-repeat` | 不重复 |
| `repeat-x` | 仅水平方向重复 |
| `repeat-y` | 仅垂直方向重复 |
| `round` | 缩放图片填满容器（不裁剪） |
| `space` | 平铺图片，留白填充（不裁剪） |

```css
background-repeat: round;  /* 图片缩放以完整填满，无裁剪 */
background-repeat: space;  /* 图片原始尺寸平铺，剩余空间均分留白 */
```

## 4. background-position 位置

```css
/* 关键字 */
background-position: top center;
background-position: bottom right;

/* 百分比/长度 */
background-position: 25% 75%;     /* x=25%, y=75% */
background-position: 10px 20px;

/* 混合 */
background-position: top 10px right 20px;
```

**定位原点**：默认以 `padding-box` 的左上角为原点（可通过 `background-origin` 更改）。

## 5. background-size 尺寸

| 值 | 描述 |
|---|---|
| `auto` | 保持图片原始尺寸 |
| `cover` | 缩放填满容器（可能裁剪） |
| `contain` | 缩放使图片完整显示（可能留白） |
| `<length>` | 具体尺寸，如 `100px 200px` |
| `<percentage>` | 相对容器尺寸，如 `50% 50%` |

```css
background-size: cover;        /* 填满容器，等比缩放，可能裁剪 */
background-size: contain;      /* 完整显示，等比缩放，可能留白 */
background-size: 100px auto;   /* 宽度100px，高度自动 */
background-size: 50% 50%;      /* 占容器50% */
```

## 6. background-attachment 固定方式

| 值 | 描述 |
|---|---|
| `scroll` | 背景随页面滚动（默认） |
| `fixed` | 背景固定在视口（视差效果） |
| `local` | 背景随元素内容滚动 |

```css
background-attachment: fixed;   /* 背景固定不随滚动 */
background-attachment: local; /* 元素内容滚动时背景随之滚动 */
```

**注意**：`fixed` 在可滚动元素上可能产生意外效果，慎用。

## 7. background-origin 起始区域

控制 `background-position` 的定位原点：

| 值 | 描述 |
|---|---|
| `padding-box` | 从 padding 边缘开始（默认） |
| `border-box` | 从 border 边缘开始 |
| `content-box` | 从 content 边缘开始 |

```css
background-origin: content-box;  /* 背景从内容区域开始绘制 */
background-clip: content-box;    /* 背景仅在内容区域可见 */
```

## 8. background-clip 裁剪区域

控制背景的绘制/显示区域：

| 值 | 描述 |
|---|---|
| `border-box` | 背景延伸至 border（默认） |
| `padding-box` | 背景在 padding 内 |
| `content-box` | 背景仅在 content 内 |
| `text` | 背景仅在文字内（需配合 `background-image`） |

```css
background-clip: text;           /* 文字彩色背景效果 */
-webkit-background-clip: text;
color: transparent;
```

## 9. background 简写

```css
/* 简写顺序（可缺省部分值） */
background: color image position/size repeat attachment origin clip;

/* 示例 */
background: #f0f0f0 url('bg.jpg') center/cover no-repeat fixed padding-box border-box;
```

**注意点**：
- `position` 和 `size` 之间用 `/` 分隔
- `origin` 和 `clip` 顺序固定：`origin` 在前，`clip` 在后
- 简写会重置未指定的子属性为默认值

## 10. 多层背景

CSS3 支持多个背景层叠加：

```css
background:
  linear-gradient(135deg, rgba(102,126,234,0.8), rgba(118,75,162,0.8)),
  url('photo.jpg') center/cover,
  #f5f5f5;
```

**绘制顺序**：第一层在最上面，最后一层在最下面。

## 11. 实战技巧

### 11.1 文字渐变

```css
background: linear-gradient(to right, #667eea, #764ba2);
-webkit-background-clip: text;
background-clip: text;
color: transparent;
```

### 11.2 棋盘格背景

```css
background-image: 
  linear-gradient(45deg, #ccc 25%, transparent 25%),
  linear-gradient(-45deg, #ccc 25%, transparent 25%),
  linear-gradient(45deg, transparent 75%, #ccc 75%),
  linear-gradient(-45deg, transparent 75%, #ccc 75%);
background-size: 20px 20px;
background-position: 0 0, 0 10px, 10px -10px, -10px 0;
```

### 11.3 斑点纹理

```css
background-image: radial-gradient(circle, #666 1px, transparent 1px);
background-size: 10px 10px;
```

### 11.4 边框内阴影

```css
background-clip: padding-box;
border: 1px solid rgba(0,0,0,0.1);
```

## 12. 浏览器兼容性和性能

- 渐变：`linear-gradient`, `radial-gradient`, `conic-gradient` 支持所有现代浏览器
- 多背景：IE9+ 支持
- `background-clip: text`：需要 `-webkit-` 前缀
- 性能：大量使用 `fixed` 背景或大图会影响滚动性能，优先使用 `scroll`
