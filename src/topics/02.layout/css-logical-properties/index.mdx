# CSS 逻辑属性 (margin-inline/block)

## 什么是 CSS 逻辑属性

CSS 逻辑属性（Logical Properties）是一组与书写模式（writing mode）和文本方向（direction）无关的 CSS 属性。它们根据内容的流动方向来定义尺寸和间距，而不是使用物理方向（如 top、left）。

### 物理属性 vs 逻辑属性

| 物理属性 | 逻辑属性 | 说明 |
|---------|---------|------|
| `margin-top` | `margin-block-start` | 块开始方向的边距 |
| `margin-bottom` | `margin-block-end` | 块结束方向的边距 |
| `margin-left` | `margin-inline-start` | 行内开始方向的边距 |
| `margin-right` | `margin-inline-end` | 行内结束方向的边距 |
| `width` | `inline-size` | 行内方向的尺寸 |
| `height` | `block-size` | 块方向的尺寸 |
| `top` | `inset-block-start` | 块开始位置 |
| `left` | `inset-inline-start` | 行内开始位置 |

## 为什么需要逻辑属性

### 传统 CSS 的问题

传统 CSS 使用物理方向，这在国际化场景下会造成问题：

```css
/* 英文页面：左侧留白 */
.sidebar { margin-left: 16px; }

/* 阿拉伯文页面：需要右侧留白 */
[dir="rtl"] .sidebar { margin-right: 16px; }
```

### 使用逻辑属性

```css
/* 自动适配所有书写模式 */
.sidebar { margin-inline-start: 16px; }
```

## 核心概念

### 1. 块方向 vs 行内方向

```
┌─────────────────────────────┐
│                             │
│         Block Direction      │
│            (↓ 或 →)          │
│                             │
│  Inline Direction → → → → →  │
│                             │
└─────────────────────────────┘
```

**块方向（Block Direction）**：内容块堆叠的方向
- 水平书写模式：从上到下（↓）
- 垂直书写模式：从右到左（→）

**行内方向（Inline Direction）**：文本流动的方向
- 水平书写模式：从左到右（→）
- 阿拉伯文：从右到左（←）

### 2. 书写模式

```css
/* 水平从左到右（默认） */
html { writing-mode: horizontal-tb; }

/* 水平从右到左（如阿拉伯文） */
html { writing-mode: horizontal-tb; direction: rtl; }

/* 垂直从左到右（如某些中文竖排） */
html { writing-mode: vertical-lr; }

/* 垂直从右到左（如日文竖排） */
html { writing-mode: vertical-rl; }
```

## 逻辑属性详解

### Margin 逻辑属性

```css
/* 单个属性 */
margin-block-start: 16px;   /* 块开始方向 */
margin-block-end: 16px;     /* 块结束方向 */
margin-inline-start: 16px;  /* 行内开始方向 */
margin-inline-end: 16px;     /* 行内结束方向 */

/* 简写 */
margin-block: 16px;         /* 上下 = block-start + block-end */
margin-inline: 16px;         /* 左右 = inline-start + inline-end */
margin-block: 8px 16px;     /* 8px = start, 16px = end */
margin-inline: 8px 16px;    /* 8px = start, 16px = end */
```

### Padding 逻辑属性

```css
/* 单个属性 */
padding-block-start: 16px;
padding-block-end: 16px;
padding-inline-start: 16px;
padding-inline-end: 16px;

/* 简写 */
padding-block: 16px;        /* 上下 */
padding-inline: 16px;      /* 左右 */
padding-block: 8px 16px;    /* start=8px, end=16px */
```

### Border 逻辑属性

```css
/* 边框宽度 */
border-block-start-width: 2px;
border-block-end-width: 2px;
border-inline-start-width: 2px;
border-inline-end-width: 2px;

/* 边框颜色 */
border-block-start-color: #3b82f6;
border-inline-end-color: #3b82f6;

/* 边框样式 */
border-block-start-style: solid;
border-inline-end-style: solid;

/* 简写 */
border-block: 2px solid #3b82f6;
border-inline: 2px dashed #22c55e;
```

### 尺寸逻辑属性

```css
/* 宽度/高度 vs 行内尺寸/块尺寸 */
width: 200px;
height: 100px;

/* 对应的逻辑属性 */
inline-size: 200px;   /* 相当于 width */
block-size: 100px;    /* 相当于 height */

/* min/max */
min-inline-size: 100px;
max-inline-size: 300px;
min-block-size: 50px;
max-block-size: 200px;
```

### Position 逻辑属性

```css
/* 物理定位 */
top: 0;
left: 0;
right: 0;
bottom: 0;

/* 逻辑定位 */
inset-block-start: 0;
inset-block-end: 0;
inset-inline-start: 0;
inset-inline-end: 0;

/* 简写 */
inset-block: 0;        /* block-start + block-end */
inset-inline: 0;      /* inline-start + inline-end */
inset: 0 10px 20px 30px;  /* top right bottom left */
```

## 实战案例

### 案例 1：基础边距

/* 物理属性（固定方向） */
.card-physical {

  padding-right: 16px;

  padding-inline: 16px;

  padding-inline-start: 12px;
}

/* 引用块 */
.blockquote {
  border-inline-start: 4px solid #22c55e;
  padding-inline-start: 16px;
  font-style: italic;

  padding-inline: 16px;

### 案例 4：流式布局

{/* @playground id="flow-layout" mode="demo" */}

```css
/* 文章内容 */
.article {
  max-inline-size: 65ch;
  margin-inline: auto;
  padding-inline: 16px;
}

/* 侧边栏 */
.sidebar {
  float: inline-start;
  inline-size: 200px;
  margin-inline-end: 24px;
}

/* 段落首行缩进 */
.paragraph {
  text-indent: 2em;
  /* 注意：text-indent 本身不受 writing-mode 影响 */
}
```

### 案例 5：响应式逻辑属性

```css
/* 自适应容器 */
.container {
  inline-size: 100%;
  max-inline-size: 1200px;
  padding-inline: 16px;
  margin-inline: auto;
}

/* 网格项 */
.grid-item {
  padding-block: 16px;
  padding-inline: 12px;
  border-block-end: 1px solid #e5e5e5;
}

/* 卡片列表 */
.card-list {
  display: grid;
  gap: 16px;  /* grid-gap 是物理属性 */
}
```

## 属性对照表

### Margin

| 物理属性 | 逻辑属性 | LTR 相当于 | RTL 相当于 |
|---------|---------|-----------|-----------|
| margin-top | margin-block-start | margin-top | margin-top |
| margin-bottom | margin-block-end | margin-bottom | margin-bottom |
| margin-left | margin-inline-start | margin-left | margin-right |
| margin-right | margin-inline-end | margin-right | margin-left |

### Padding

| 物理属性 | 逻辑属性 | LTR 相当于 | RTL 相当于 |
|---------|---------|-----------|-----------|
| padding-top | padding-block-start | padding-top | padding-top |
| padding-bottom | padding-block-end | padding-bottom | padding-bottom |
| padding-left | padding-inline-start | padding-left | padding-right |
| padding-right | padding-inline-end | padding-right | padding-left |

### Position/inset

| 物理属性 | 逻辑属性 | LTR 相当于 | RTL 相当于 |
|---------|---------|-----------|-----------|
| top | inset-block-start | top | top |
| bottom | inset-block-end | bottom | bottom |
| left | inset-inline-start | left | right |
| right | inset-inline-end | right | left |

### Border

| 物理属性 | 逻辑属性 |
|---------|---------|
| border-top | border-block-start |
| border-bottom | border-block-end |
| border-left | border-inline-start |
| border-right | border-inline-end |

## 浏览器兼容性

逻辑属性已获得主流浏览器的支持：

| 浏览器 | 支持版本 |
|-------|---------|
| Chrome | 69+ |
| Firefox | 41+ |
| Safari | 12.1+ |
| Edge | 79+ |

### 需要注意的兼容性

```css
/* inset-inline/block 在旧版浏览器可能需要前缀 */
@supports not (inset-inline: 0) {
  [dir="ltr"] { left: 0; }
  [dir="rtl"] { right: 0; }
}
```

## 最佳实践

### 1. 优先使用逻辑属性

```css
/* ❌ 使用物理属性 */
.element {
  margin-left: 16px;
  padding-top: 16px;
}

/* ✅ 使用逻辑属性 */
.element {
  margin-inline-start: 16px;
  padding-block-start: 16px;
}
```

### 2. 结合 CSS 自定义属性

```css
:root {
  --space-inline: 16px;
  --space-block: 8px;
}

.component {
  padding-inline: var(--space-inline);
  padding-block: var(--space-block);
}
```

### 3. 使用逻辑属性实现居中

```css
/* 物理属性居中 */
.center-physical {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}

/* 逻辑属性居中 */
.center-logical {
  position: absolute;
  inset-block-start: 50%;
  inset-inline-start: 50%;
  transform: translate(-50%, -50%);
}
```

### 4. 逻辑属性与 grid/flexbox

```css
.grid {
  display: grid;
  gap: 16px;  /* grid-gap 本身就是逻辑属性 */
}

.flex-container {
  gap: 12px;
  padding-inline: 16px;
}
```

## 与 RTL 的关系

### 阿拉伯文示例

```html
<!-- 英文页面 -->
<article dir="ltr">
  <div class="highlight">突出显示</div>
  <p>正文内容...</p>
</article>

<!-- 阿拉伯文页面 -->
<article dir="rtl">
  <div class="highlight">突出显示</div>
  <p>正文内容...</p>
</article>
```

```css
.highlight {
  /* LTR: 左侧边框，RTL: 右侧边框 */
  border-inline-start: 4px solid #f59e0b;
  padding-inline-start: 12px;
}
```

### 检测书写模式

```css
/* 针对特定书写模式 */
[dir="rtl"] .icon-arrow {
  transform: scaleX(-1);
}

/* 或者使用 CSS 容器查询 */
@container style(writing-mode: vertical-rl) {
  .card { inline-size: 200px; }
}
```
