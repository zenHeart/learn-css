📏 Table Cell 省略号不生效 — 解决方案

❌ 错误演示：默认 table-layout: auto（省略号不生效）
这是一段很长的文字内容，超出单元格宽度后需要显示省略号，但是省略号不生效
原因：默认 table-layout: auto 时，单元格宽度由内容决定，内容永远不会被"溢出"
✅ 正确方案一：table-layout: fixed + width
这是一段很长的文字内容，超出单元格宽度后显示省略号 ✓
关键代码： table-layout: fixed + width: 300px
✅ 正确方案二：多列表格 + 固定宽度
第一列的省略号内容 第二列的较长文字内容，也会省略显示省略号 第三列
第二行第一列 第二行第二列内容文字很长很长 第二行第三列
📋 省略号生效的五个必要条件

检查清单（缺一不可）

  • table-layout: fixed; — 表格使用固定布局
  • width: 200px;（或 %） — 表格宽度必须 > 0
  • overflow: hidden; — 溢出内容隐藏
  • white-space: nowrap; — 禁止文字换行
  • text-overflow: ellipsis; — 溢出显示省略号
🔄 table-layout: auto vs fixed 对比
特性 table-layout: auto table-layout: fixed
布局算法 自动，内容决定列宽 固定，由定义决定列宽
省略号支持 ❌ 不支持 ✅ 支持
渲染性能 较慢（计算所有内容） 较快（只需计算首行）
适用场景 内容不确定的表格 需精确控制列宽的表格
⚠️ 常见踩坑
踩坑 1 没有设置 table-layout: fixed
踩坑 2 table 的 width 为 0 或未设置
踩坑 3 没有设置 white-space: nowrap
踩坑 4 overflow 不是 hidden（默认值是 visible）
📝 完整代码模板
<style>
table {
  table-layout: fixed;  /* 必须：固定表格布局 */
  width: 300px;          /* 必须：宽度 > 0 */
}

td {
  overflow: hidden;      /* 必须：隐藏溢出 */
  white-space: nowrap;   /* 必须：禁止换行 */
  text-overflow: ellipsis; /* 必须：显示省略号 */
}
</style>

<table>
  <tr>
    <td>很长很长的文字内容...</td>
  </tr>
</table>
