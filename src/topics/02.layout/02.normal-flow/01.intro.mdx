# CSS 正常流式布局

**详解正常流式布局**

---

## 概述
正常流式布局是按照浏览器的默认布局规则,铺排各元素。

> 正常流式布局的重点是善用默认布局保证内容的可读性,,而不要与其对抗大量修改,达到**顺木之天以致其性**的效果。


## 默认布局的机制

默认布局按照如下流程进行。
1. 每个元素按照默认属性生成布局盒,典型的布局盒有两种
	1. 块级盒,内容区宽度为父元素宽度的 100%,内容区高度为包含内容的高度。
	2. 内联盒,内容区宽高均为内容实际到小
2. 根据默认的位置铺排元素
	1. 块元素按照默认的模式一行一行排列
	2. 内联盒,按照文档结构,前后联接,当宽度大于一行的宽度时,进行换行
3. 对于垂直方向堆叠的元素,会出现 margin 塌陷。
