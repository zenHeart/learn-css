# CSS background 属性详解

## 概述

CSS `background` 属性是用于设置元素背景的一组简写属性，涵盖了背景颜色、图片、重复方式、定位、大小等。本文详细说明各个属性的用法和注意事项。

{/* @playground id="basic-usage" mode="demo" */}

## 1. background-color 背景颜色

设置纯色背景：

```css
.element {
  background-color: red;
  background-color: #ff0000;
  background-color: rgb(255, 0, 0);
  background-color: hsl(0, 100%, 50%);
}
```

### 透明背景

```css
.transparent {
  background-color: transparent;
}
```

{/* @playground id="color-examples" mode="demo" */}

## 2. background-image 背景图片

设置背景图片，支持 URL 和渐变：

```css
/* 图片背景 */
.image-bg {
  background-image: url('path/to/image.png');
}

/* 多层图片 */
.multi-bg {
  background-image: 
    url('front.png'),
    url('back.png');
}
```

### 渐变背景

#### 线性渐变 (linear-gradient)

```css
.linear {
  /* 从上到下（默认） */
  background-image: linear-gradient(red, yellow);
  
  /* 从左到右 */
  background-image: linear-gradient(to right, red, yellow);
  
  /* 对角线 */
  background-image: linear-gradient(to bottom right, red, yellow);
  
  /* 带角度 */
  background-image: linear-gradient(45deg, red, yellow);
  
  /* 多节点 */
  background-image: linear-gradient(red 0%, yellow 50%, blue 100%);
}
```

{/* @playground id="linear-gradient" mode="demo" */}

#### 径向渐变 (radial-gradient)

```css
.radial {
  /* 从中心向外扩散（默认椭圆） */
  background-image: radial-gradient(red, yellow);
  
  /* 圆形渐变 */
  background-image: radial-gradient(circle, red, yellow);
  
  /* 指定圆心位置 */
  background-image: radial-gradient(at 50% 50%, red, yellow);
  
  /* 多节点 */
  background-image: radial-gradient(red 0%, yellow 50%, blue 100%);
}
```

{/* @playground id="radial-gradient" mode="demo" */}

#### 圆锥渐变 (conic-gradient)

```css
.conic {
  /* 从中心旋转 */
  background-image: conic-gradient(red, yellow, red);
  
  /* 从指定角度开始 */
  background-image: conic-gradient(from 0deg at 50% 50%, red, yellow, blue, red);
}
```

{/* @playground id="conic-gradient" mode="demo" */}

### repeating- 重复渐变

```css
/* 重复线性渐变 */
.repeating-linear {
  background-image: repeating-linear-gradient(
    45deg,
    transparent,
    transparent 10px,
    rgba(255,255,255,0.1) 10px,
    rgba(255,255,255,0.1) 20px
  );
}

/* 重复径向渐变 */
.repeating-radial {
  background-image: repeating-radial-gradient(
    circle,
    transparent,
    transparent 10px,
    rgba(255,255,255,0.1) 10px,
    rgba(255,255,255,0.1) 20px
  );
}
```

## 3. background-repeat 背景重复

控制背景图片的重复方式：

```css
.repeat {
  /* 两个方向都重复（默认） */
  background-repeat: repeat;
  
  /* 只在横方向重复 */
  background-repeat: repeat-x;
  
  /* 只在纵方向重复 */
  background-repeat: repeat-y;
  
  /* 不重复 */
  background-repeat: no-repeat;
  
  /* 均匀铺满（CSS3） */
  background-repeat: space;
  
  /* 圆润铺满（CSS3） */
  background-repeat: round;
}
```

{/* @playground id="background-repeat" mode="demo" */}

## 4. background-position 背景位置

设置背景图片的起始位置：

```css
.position {
  /* 关键字 */
  background-position: top;
  background-position: bottom right;
  
  /* 百分比 */
  background-position: 50% 50%;
  
  /* 像素值 */
  background-position: 10px 20px;
  
  /* 混合 */
  background-position: center top;
}
```

### 多背景位置（CSS3）

```css
.multi-position {
  background-position: 
    0% 0%,
    100% 100%;
}
```

{/* @playground id="background-position" mode="demo" */}

## 5. background-size 背景尺寸

控制背景图片的大小：

```css
.size {
  /* 关键字 */
  background-size: auto;      /* 保持原始尺寸 */
  background-size: cover;     /* 铺满，可能被裁剪 */
  background-size: contain;   /* 完整显示，可能留白 */
  
  /* 数值 */
  background-size: 100px 200px;
  background-size: 50% 50%;
  
  /* 单独设置宽度，高度自适应 */
  background-size: 100px auto;
}
```

{/* @playground id="background-size" mode="demo" */}

## 6. background-attachment 背景附件

控制背景图片是固定还是随页面滚动：

```css
.attachment {
  /* 随内容滚动（默认） */
  background-attachment: scroll;
  
  /* 相对于视口固定 */
  background-attachment: fixed;
  
  /* 相对于内容固定（仅内容滚动时） */
  background-attachment: local;
}
```

{/* @playground id="background-attachment" mode="demo" */}

## 7. background-origin 背景定位区域

设置背景图片的定位参考区域：

```css
.origin {
  /* 从 padding-box 开始（默认） */
  background-origin: padding-box;
  
  /* 从 border-box 开始 */
  background-origin: border-box;
  
  /* 从 content-box 开始 */
  background-origin: content-box;
}
```

## 8. background-clip 背景绘制区域

设置背景的绘制（显示）区域：

```css
.clip {
  /* 绘制到 border-box（默认值） */
  background-clip: border-box;
  
  /* 绘制到 padding-box */
  background-clip: padding-box;
  
  /* 绘制到 content-box */
  background-clip: content-box;
  
  /* 绘制到文本（文字着色） */
  background-clip: text;
}
```

## 9. background 简写属性

`background` 是上述所有属性的简写：

```css
/* 完整语法 */
.element {
  background: 
    <bg-color> 
    <bg-image> 
    <bg-position> 
    <bg-size> 
    <bg-repeat> 
    <bg-origin> 
    <bg-clip> 
    <bg-attachment>;
}

/* 示例 */
.shorthand {
  background: 
    #f0f0f0 
    url('image.png') 
    no-repeat 
    center / cover;
}

/* 常见简写 */
.simple {
  background: url('bg.png') no-repeat center;
  background: linear-gradient(to right, red, blue);
  background: #ff0000;
}
```

### 多层背景（CSS3）

```css
.layers {
  background: 
    linear-gradient(to bottom, rgba(255,0,0,0.3), transparent),
    url('mountains.jpg') no-repeat center / cover,
    #333;
}
```

## 10. 多层背景详解

CSS3 支持多层背景，每层从下到上叠加：

```css
.multi-bg {
  background:
    /* 第3层（最上）：渐变条纹 */
    repeating-linear-gradient(
      45deg,
      transparent,
      transparent 10px,
      rgba(255,255,255,0.1) 10px,
      rgba(255,255,255,0.1) 20px
    ),
    /* 第2层：图片 */
    url('pattern.png') no-repeat center,
    /* 第1层（最下）：颜色 */
    #1a1a2e;
}
```

### 注意事项

- 每层按顺序从下到上叠加
- 可以混合使用颜色、图片、渐变
- 每层可以独立设置位置、大小、重复方式
- 简洁写法中，各层用逗号分隔

## 实际应用

### 1. 全屏背景图 + 渐变叠加

```css
.hero {
  background: 
    linear-gradient(
      to bottom,
      rgba(0,0,0,0.5),
      rgba(0,0,0,0.8)
    ),
    url('hero-bg.jpg') no-repeat center / cover;
  min-height: 100vh;
}
```

### 2. 卡片悬停效果

```css
.card {
  background: 
    linear-gradient(135deg, #667eea, #764ba2);
  transition: background 0.3s ease;
}

.card:hover {
  background: 
    linear-gradient(135deg, #764ba2, #667eea);
}
```

### 3. 纹理背景

```css
.texture {
  background: 
    url('noise.png'),
    linear-gradient(to bottom, #f5f5f5, #e0e0e0);
  background-blend-mode: overlay;
}
```

### 4. 进度条/条纹动画

```css
.striped {
  background: repeating-linear-gradient(
    45deg,
    #f0f0f0,
    #f0f0f0 10px,
    #e0e0e0 10px,
    #e0e0e0 20px
  );
  animation: stripes 1s linear infinite;
}

@keyframes stripes {
  0% { background-position: 0 0; }
  100% { background-position: 40px 0; }
}
```

## 最佳实践

1. **使用简写属性时注意顺序**：先写颜色/图片，再写位置，最后写尺寸
2. **渐变作为图片处理**：`background-image` 才是渐变的正确属性
3. **`cover` vs `contain`**：cover 填满可能裁剪，contain 完整显示可能留白
4. **多层背景时注意性能**：过多层背景可能影响渲染性能
5. **`fixed` 附件慎用**：会影响滚动性能，尤其在移动端
