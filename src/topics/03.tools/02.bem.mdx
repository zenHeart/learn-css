# BEM 命名规范

**详解CSS BEM命名规范的概念、规则和实践方法**

---

## 概述

BEM 是一套 CSS 组织规范，相比原生 CSS 解决了如下问题：

- 定义了一套 CSS 命名标准，增强 CSS 维护性
- 避免样式冲突和全局污染
- 提高代码的可读性和可维护性
- 便于团队协作和代码复用

BEM 是 `Block`、`Element`、`Modifier` 的首字母缩写。

## 核心概念

### Block (块)

块代表一个独立的视图组件，是页面上可以独立存在的功能单元。

**命名规则**：
- 块按照功能命名，例如 `nav`、`menu`、`button`
- 块名应该描述其用途，而不是外观
- 块之间使用 `-` 连字符分隔

```html
<!-- ✅ 正确：表示错误信息 -->
<div class="error"></div>

<!-- ❌ 错误：只说明了样式，未说明功能 -->
<div class="red-text"></div>
```

**块的特点**：
- 块不能影响页面布局环境
- 不能在块的样式中包含 `margin`、`position` 等影响外部布局的属性
- 块应该是独立的，可以在页面任何位置使用

```css
/* ✅ 正确的块样式 */
.menu {
  font-family: Arial, sans-serif;
  font-size: 16px;
  color: #333;
}

/* ❌ 错误：包含了影响布局的属性 */
.menu {
  margin: 20px;
  position: absolute;
  top: 100px;
}
```

### Element (元素)

元素是块的一部分，是组成块的功能单元，不能独立于块存在。

**命名规则**：
- 元素和块之间用 `__` 双下划线分隔
- 元素同样需要按照功能命名
- 格式：`block__element`

```html
<div class="menu">
  <div class="menu__item">
    <a class="menu__link" href="#">首页</a>
  </div>
  <div class="menu__item">
    <a class="menu__link" href="#">产品</a>
  </div>
</div>
```

```css
.menu__item {
  display: inline-block;
  padding: 10px;
}

.menu__link {
  color: #333;
  text-decoration: none;
}

.menu__link:hover {
  color: #007bff;
}
```

**元素的特点**：
- 元素只能是块的一部分，不能独立使用
- 一个元素总是块的一部分，而不是另一个元素的一部分
- 不能创建 `block__element__element` 这样的结构

```html
<!-- ❌ 错误：元素嵌套元素 -->
<div class="menu">
  <div class="menu__item">
    <div class="menu__item__text"></div>
  </div>
</div>

<!-- ✅ 正确：扁平化结构 -->
<div class="menu">
  <div class="menu__item">
    <div class="menu__text"></div>
  </div>
</div>
```

### Modifier (修饰符)

修饰符用来定义块或元素的外观、状态或行为。

**命名规则**：
- 修饰符和块/元素之间用 `--` 双连字符分隔
- 格式：`block--modifier` 或 `block__element--modifier`

```html
<!-- 块修饰符 -->
<div class="button button--large">大按钮</div>
<div class="button button--primary">主要按钮</div>

<!-- 元素修饰符 -->
<div class="menu">
  <div class="menu__item menu__item--active">
    <a class="menu__link menu__link--disabled" href="#">首页</a>
  </div>
</div>
```

```css
/* 基础块样式 */
.button {
  display: inline-block;
  padding: 8px 16px;
  border: 1px solid #ccc;
  background: #f5f5f5;
  text-decoration: none;
  color: #333;
}

/* 尺寸修饰符 */
.button--small {
  padding: 4px 8px;
  font-size: 12px;
}

.button--large {
  padding: 12px 24px;
  font-size: 18px;
}

/* 主题修饰符 */
.button--primary {
  background: #007bff;
  color: white;
  border-color: #007bff;
}

.button--danger {
  background: #dc3545;
  color: white;
  border-color: #dc3545;
}
```

## 修饰符的类型

### 1. 布尔型修饰符

表示某种状态的存在或不存在：

```html
<div class="tab tab--active">激活标签</div>
<div class="form__field form__field--error">错误字段</div>
<div class="menu__item menu__item--selected">选中项</div>
```

### 2. 键值型修饰符

表示特定的值：

```html
<div class="button button--size-large">大按钮</div>
<div class="text text--color-red">红色文本</div>
<div class="grid grid--columns-3">三列网格</div>
```

```css
.button--size-small { padding: 4px 8px; }
.button--size-medium { padding: 8px 16px; }
.button--size-large { padding: 12px 24px; }

.text--color-red { color: #dc3545; }
.text--color-blue { color: #007bff; }
.text--color-green { color: #28a745; }
```

## 与其他方法论的比较

### BEM vs 普通CSS

```css
/* 普通CSS - 容易冲突 */
.menu { }
.menu ul { }
.menu ul li { }
.menu ul li a { }
.menu ul li a.active { }

/* BEM - 明确且不易冲突 */
.menu { }
.menu__list { }
.menu__item { }
.menu__link { }
.menu__link--active { }
```

### BEM的优势

1. **避免样式冲突**：每个选择器都是独特的
2. **提高可读性**：从类名就能理解结构关系
3. **便于维护**：修改某个组件不会影响其他组件
4. **易于理解**：新团队成员能快速理解代码结构

## 在JavaScript中使用BEM

```javascript
// 动态添加修饰符
const button = document.querySelector('.button');

// 添加状态
button.classList.add('button--loading');

// 切换状态
button.classList.toggle('button--active');

// 移除状态
button.classList.remove('button--disabled');
```

## 最佳实践

### 1. 命名建议

```css
/* ✅ 推荐：语义化命名 */
.search-form { }
.search-form__input { }
.search-form__button { }
.search-form--compact { }

/* ❌ 避免：基于外观的命名 */
.red-button { }
.small-text { }
.left-sidebar { }
```

### 2. 组件独立性

```css
/* ✅ 推荐：组件内部完全独立 */
.card {
  /* 内部样式 */
}

.card__title {
  /* 不依赖外部样式 */
}

/* ❌ 避免：依赖外部选择器 */
.page .card .title {
  /* 依赖特定的HTML结构 */
}
```

### 3. 修饰符使用

```html
<!-- ✅ 推荐：保留基础类 -->
<div class="button button--large button--primary">

<!-- ❌ 避免：只使用修饰符 -->
<div class="button--large-primary">
```

### 4. 避免过度嵌套

```html
<!-- ✅ 推荐：扁平化结构 -->
<div class="article">
  <div class="article__header">
    <h1 class="article__title">标题</h1>
  </div>
  <div class="article__content">
    <p class="article__text">内容</p>
  </div>
</div>

<!-- ❌ 避免：过度嵌套 -->
<div class="article__header__title__text">
```

## 常见问题和解决方案

### Q: 类名太长怎么办？

A: 适当使用缩写，但要保持团队一致性：

```css
.nav { }           /* navigation */
.btn { }           /* button */
.img { }           /* image */
.txt { }           /* text */
```

### Q: 如何处理响应式？

A: 使用状态修饰符结合媒体查询：

```css
.menu--mobile {
  display: none;
}

@media (max-width: 768px) {
  .menu { display: none; }
  .menu--mobile { display: block; }
}
```

### Q: 第三方组件如何集成？

A: 创建包装器或使用混合方法：

```css
.my-component {
  /* 自定义样式 */
}

.my-component .third-party-widget {
  /* 第三方组件样式覆盖 */
}
```
