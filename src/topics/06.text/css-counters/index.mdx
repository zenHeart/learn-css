# CSS Counters 计数器

CSS 计数器是一种强大的自动编号功能，可以实现章节编号、列表编号等场景，无需 JavaScript。

## 基本概念

CSS 计数器由三部分组成：
- **counter-reset**：初始化（创建）计数器
- **counter-increment**：递增计数器
- **counter()**：在 content 中使用计数器

## 基本语法

```css
/* 1. 初始化计数器 */
body {
  counter-reset: section;  /* 创建一个名为 section 的计数器，初始值为 0 */
}

/* 2. 递增计数器 */
h1 {
  counter-increment: section;  /* 每次遇到 h1，section 加 1 */
}

/* 3. 显示计数器 */
h1::before {
  content: "第 " counter(section) " 章";  /* 输出：第 1 章、第 2 章... */
}
```

## 计数器值详解

### counter-reset

| 语法 | 说明 |
|------|------|
| `counter-reset: name` | 创建计数器，初始值 0 |
| `counter-reset: name 1` | 创建计数器，初始值 1 |
| `counter-reset: name1 name2` | 同时创建多个计数器 |
| `counter-reset: none` | 不重置任何计数器 |

### counter-increment

| 语法 | 说明 |
|------|------|
| `counter-increment: name` | 每次递增 1 |
| `counter-increment: name 2` | 每次递增 2 |
| `counter-increment: name1 name2` | 同时递增多个计数器 |
| `counter-increment: none` | 不递增任何计数器 |

### counter() 函数

```css
/* 基本用法 */
content: counter(section);

/* 带样式的编号 */
content: counter(section, upper-roman);  /* I, II, III... */
content: counter(section, lower-alpha);  /* a, b, c... */

/* 嵌套计数器 */
content: counter(chapter) "." counter(section);
```

### 计数器样式

| 样式 | 示例输出 |
|------|----------|
| `decimal` | 1, 2, 3... |
| `decimal-leading-zero` | 01, 02, 03... |
| `lower-alpha` | a, b, c... |
| `upper-alpha` | A, B, C... |
| `lower-roman` | i, ii, iii... |
| `upper-roman` | I, II, III... |
| `lower-greek` | α, β, γ... |

## 实战案例

### 1. 章节编号

```css
/* 初始化章节计数器 */
body {
  counter-reset: chapter;
}

/* 递增并显示 */
h2 {
  counter-increment: chapter;
}

h2::before {
  content: "第 " counter(chapter) " 章、";
}
```

### 2. 多级编号（章节.小节）

```css
body {
  counter-reset: chapter section;
}

h2 {
  counter-increment: chapter;
  counter-reset: section;
}

h2::before {
  content: counter(chapter) "、";
}

h3 {
  counter-increment: section;
}

h3::before {
  content: counter(chapter) "." counter(section) "、";
}
```

### 3. 有序列表样式

```css
ol {
  counter-reset: item;
  list-style: none;
}

li {
  counter-increment: item;
}

li::before {
  content: counter(item) ".";
  margin-right: 0.5em;
  font-weight: bold;
}
```

### 4. 表格行号

```css
table {
  counter-reset: row-number;
}

tr {
  counter-increment: row-number;
}

tr td:first-child::before {
  content: counter(row-number);
  font-weight: bold;
}
```

## counters() 函数 - 嵌套计数

```css
/* 使用 counters 处理嵌套列表 */
ul {
  counter-reset: item;
  list-style: none;
}

li {
  counter-increment: item;
}

li::before {
  content: counters(item, ".") " ";
}

/* 输出：
 * 1 顶层项
 * 1.1 子项
 * 1.2 子项
 * 2 顶层项
 * 2.1 子项
 */
```

## 注意事项

1. **作用域**：计数器在 reset 之后开始生效，子元素可以访问父元素的计数器
2. **默认从 0 开始**：如果不指定初始值，计数器从 0 开始，display 时会显示 1
3. **性能**：CSS 计数器在渲染时计算，性能开销很小
4. **兼容性**：现代浏览器都支持，但 IE8 及以下不支持
