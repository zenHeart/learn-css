# CSS overscroll-behavior 完整指南

## 学习目标

- 理解「滚动链」（Scroll Chaining）现象及其带来的问题
- 掌握 `overscroll-behavior` 三个值的含义与区别
- 能够在弹窗、抽屉、横向滚动等场景中正确应用
- 了解与 `touch-action` 的分工差异
- 识别 iOS Safari 的兼容性问题并掌握解决方案

---

## 核心概念

### 滚动链（Scroll Chaining）

当你在一个**可滚动区域**（如弹窗内部）滚动到边界后，继续滚动会导致**外层父容器开始滚动**的现象，称为「滚动链」。

**常见问题场景：**
- 打开模态弹窗后，在弹窗内滚动到底部，继续拖动会让背景页面滚动（滚动穿透）
- 在移动端使用横向轮播组件，垂直方向滑动时会触发整个页面滚动
- 嵌套滚动区域（父容器和子容器都有滚动条）时，内部滚动到边界会「溢」到父容器

```
┌─────────────────────────────┐
│  背景页面（可滚动）           │
│  ┌───────────────────────┐  │
│  │  弹窗（可滚动）         │  │ ← 弹窗滚动到底后
│  │  ...                   │  │   继续拖动会...
│  │  ...                   │  │
│  └───────────────────────┘  │
│                             │ ← ...触发背景页面滚动（滚动穿透）
└─────────────────────────────┘
```

### overscroll 触发时机

`overscroll` 事件在滚动**到达边界后继续拖动**时触发（rubber-band 弹性回弹区域）。

- 桌面端：滚动条拖到头后继续拖动
- 移动端：触摸滚动到边界后继续拖动（iOS 的 rubber-band 效果）

### 与 touch-action 的区别

| 特性 | `overscroll-behavior` | `touch-action` |
|------|----------------------|----------------|
| 作用 | 控制滚动到边界后的行为（是否传播给父容器） | 控制触摸手势的默认行为（是否允许滚动/缩放） |
| 解决的问题 | 滚动链、滚动穿透 | 意外触发浏览器默认手势（如缩放、拖动滚动） |
| 典型场景 | 弹窗内滚动禁止影响背景 | 移动端禁用双击缩放、允许/禁止特定方向滚动 |
| 兼容性 | 现代浏览器（iOS Safari 16+） | 所有现代浏览器 |

**协作关系：** 两者解决不同问题，通常需要同时使用。例如移动端横向轮播：

```css
.carousel {
  touch-action: pan-y;  /* 禁止垂直方向触摸默认行为 */
  overflow-x: auto;
}
.carousel-inner {
  overscroll-behavior: contain; /* 横向滚动到边界后不触发父容器垂直滚动 */
}
```

## 属性详解

### 语法

```css
overscroll-behavior: auto;        /* 默认 */
overscroll-behavior: contain;      /* 阻止滚动传播 */
overscroll-behavior: none;         /* 完全禁止 overscroll 效果（包括 rubber-band） */

overscroll-behavior-x: auto;       /* 单独控制水平方向 */
overscroll-behavior-y: contain;    /* 单独控制垂直方向 */
```

### 三个值的区别

#### `auto`（默认值）

不做任何限制，滚动行为正常传播。

```css
.modal {
  overscroll-behavior: auto; /* 默认值，等同于不写 */
}
```

#### `contain`

**阻止滚动传播**——当在此元素内部滚动到边界后，**不会**触发父容器的滚动。

- 弹窗内容滚动到底后，继续拖动**不会**让背景页面滚动
- 内部滚动区域拥有独立的滚动边界，不会影响外部

```css
.modal {
  overscroll-behavior: contain; /* 滚动隔离 */
}
```

#### `none`

在 `contain` 的基础上，**同时禁用浏览器自带的弹性回弹（rubber-band）效果**。

```css
.scroll-section {
  overscroll-behavior: none; /* 无弹性回弹，无滚动传播 */
}
```

### 双向控制

```css
/* 水平方向禁止传播，垂直方向允许默认行为 */
.scroller {
  overscroll-behavior-x: contain;
  overscroll-behavior-y: auto;
}
```

## 实战案例

### 案例 1：弹窗防止背景滚动（最常用）

**问题：** 打开弹窗后，在弹窗内滚动，背景页面也跟着滚动（滚动穿透）。

**解决方案：** 在弹窗上设置 `overscroll-behavior: contain`。

```css
/* 弹窗内容容器 */
.modal-body {
  overscroll-behavior: contain;
  overflow-y: auto; /* 确保内容可滚动 */
}
```

**效果对比：**

| 值 | 弹窗滚动到边界后继续拖动 |
|---|---|
| `auto`（默认） | 背景页面开始滚动 ❌ |
| `contain` | 弹窗内容有轻微回弹，但背景不动 ✅ |
| `none` | 完全无回弹，背景不动 ✅ |

> 💡 推荐使用 `contain`，在大多数场景下能完美解决问题，且不改变原生滚动体验。

**完整示例代码：** `examples/css/demos/overscroll-behavior/modal-dialog-scroll-lock.html`

---

### 案例 2：移动端横向轮播垂直滚动锁定

**问题：** 在移动端使用横向轮播组件，用户本想水平滑动但手指稍有倾斜，垂直方向的滚动会触发整个页面滚动，导致轮播无法正常使用。

**解决方案：** 轮播容器设置 `overscroll-behavior: contain` + `touch-action: pan-y`。

```css
.carousel {
  overflow-x: auto;
  overscroll-behavior: contain; /* 横向滚动到边界后不触发父容器滚动 */
  touch-action: pan-y;         /* 禁止垂直方向的触摸默认行为 */
  -webkit-overflow-scrolling: touch;
}
```

**为什么需要两个属性？**

- `overscroll-behavior: contain` — 处理**滚动链**：轮播横向滚到头后继续拖动，不会触发页面垂直滚动
- `touch-action: pan-y` — 处理**手势识别**：明确告诉浏览器这个元素只响应水平触摸手势

**完整示例代码：** `examples/css/demos/overscroll-behavior/horizontal-carousel-scroll-lock.html`

---

### 案例 3：可滚动区域边界控制（嵌套滚动场景）

**问题：** 页面有多个嵌套的可滚动区域，内部区域滚动到边界后继续拖动会影响外层区域。

**解决方案：** 在需要隔离滚动的区域设置 `overscroll-behavior: contain`。

```css
.chat-container {
  display: flex;
  flex-direction: column;
  height: 100vh;
}

.message-list {
  flex: 1;
  overflow-y: auto;
  overscroll-behavior: contain; /* 消息列表滚动隔离 */
}

.sidebar {
  overflow-y: auto;
  overscroll-behavior: contain; /* 侧边栏滚动隔离 */
}
```

**嵌套滚动的黄金法则：**
- 明确哪些区域需要「独立滚动」
- 在这些区域上统一加 `overscroll-behavior: contain`
- 避免滚动行为意外传播

**完整示例代码：** `examples/css/demos/overscroll-behavior/nested-scroll-isolation.html`

## 兼容性与坑点

### 浏览器支持

| 特性 | Chrome | Firefox | Safari | Edge |
|------|--------|---------|--------|------|
| `overscroll-behavior` | 63+ | 59+ | 16+ | 18+ |
| `overscroll-behavior-x/y` | 63+ | 59+ | 16+ | 18+ |

移动端：
- **iOS Safari 16+** 支持 `contain` 和 `none`
- **iOS Safari 15 及以下** 不支持，使用 polyfill 或降级方案

### iOS Safari 坑点

#### 坑点 1：iOS Safari 16 以下完全不兼容

**表现：** 弹窗设置 `overscroll-behavior: contain` 毫无效果，滚动穿透依然发生。

**原因：** iOS Safari 16 以下没有实现此属性。

**降级方案：**

```javascript
// 检测是否支持 overscroll-behavior
const supportsOverscroll = CSS.supports('overscroll-behavior', 'contain');

if (!supportsOverscroll) {
  // 降级：使用 JavaScript 方案阻止滚动穿透
  document.body.style.overflow = 'hidden';
  
  // 或者使用 touch 事件监听手动阻止
  modal.addEventListener('touchmove', (e) => {
    const scrollable = e.currentTarget;
    const { scrollTop, scrollHeight, clientHeight } = scrollable;
    const isAtTop = scrollTop === 0;
    const isAtBottom = scrollTop + clientHeight >= scrollHeight;
    
    if (isAtTop && e.deltaY < 0) e.preventDefault();
    if (isAtBottom && e.deltaY > 0) e.preventDefault();
  }, { passive: false });
}
```

#### 坑点 2：`-webkit-overflow-scrolling: touch` 的交互问题

**表现：** 开启惯性滚动后，`overscroll-behavior` 的 rubber-band 效果可能异常。

**解决方案：** iOS Safari 16+ 可以移除 `-webkit-overflow-scrolling: touch`，新版浏览器已原生支持惯性滚动。

```css
.scroller {
  overflow-y: auto;
  /* iOS Safari 16+ 不再需要这一行 */
  /* -webkit-overflow-scrolling: touch; */
  overscroll-behavior: contain;
}
```

#### 坑点 3：`overscroll-behavior: none` 在部分场景失效

**表现：** 设置 `none` 后，弹性回弹效果仍然出现。

**解决方案：** 在需要完全禁止的场景，加上 `overflow: hidden` 辅助：

```css
.modal-content {
  overscroll-behavior: none;
  overflow: hidden; /* 配合使用，确保无回弹 */
}
```

### 调试技巧

1. **DevTools 检查：** 在 Elements 面板查看元素的 `overscroll-behavior` 计算值
2. **模拟触摸设备：** Chrome DevTools → Toggle device toolbar → 选择 iPhone/Android 设备
3. **惯性滚动测试：** 必须在真机上测试模拟器的触摸模拟不完全准确
