# CSS Scroll Snap 滚动捕捉机制

CSS Scroll Snap 提供了一套声明式的 API，让开发者可以控制滚动行为——当用户停止滚动时，容器会自动「吸附」到指定的捕捉点（snap point）。这套机制被广泛用于移动端轮播图、全屏滚动场景、相册浏览等交互中。

## 核心概念

Scroll Snap 涉及两类元素：

| 角色 | 作用 | 关键属性 |
|------|------|----------|
| **Snap Container**（滚动容器） | 定义滚动轴向和吸附强度 | `scroll-snap-type`、`scroll-padding` |
| **Snap Child**（捕捉目标） | 声明吸附对齐方式 | `scroll-snap-align`、`scroll-snap-stop` |

> 💡 类似于 Flexbox/Grid：父容器建立上下文，子元素在父容器定义的规则下排列。

## scroll-snap-type 属性

`scroll-snap-type` 定义在**滚动容器**上，指定滚动方向和吸附模式。

```css
.container {
  scroll-snap-type: <axis> <strictness>;
}
```

### 轴向（axis）

| 值 | 含义 | 典型场景 |
|----|------|----------|
| `x` | 水平方向吸附 | 轮播图、横向列表 |
| `y` | 垂直方向吸附 | 全屏垂直滚动、问答列表 |
| `both` | 两个方向同时吸附 | 2D 网格、画廊 |
| `block` | 沿块级方向（默认 `y`） | 同 `y` |
| `inline` | 沿行内方向（默认 `x`） | 同 `x` |

### 严格度（strictness）

| 值 | 行为 | 适用场景 |
|----|------|----------|
| `mandatory` | 滚动停止后**必须**吸附到最近的捕捉点 | 轮播图、翻页（用户体验更可预期） |
| `proximity` | 仅当滚动停止位置**靠近**捕捉点时才吸附 | 避免强制吸附导致内容被遮挡 |

> ⚠️ **mandatory 的陷阱**：如果容器内某个子元素高度大于视口，`mandatory` 会导致中间部分**永远无法滚动到**。此时应改用 `proximity`。

### 缩写语法

```css
/* 单值：只指定轴向，严格度默认为 proximity */
scroll-snap-type: x;
scroll-snap-type: y;

/* 双值：明确指定轴向和严格度 */
scroll-snap-type: x mandatory;
scroll-snap-type: y proximity;
scroll-snap-type: both mandatory;
```

### 与 overflow 的配合

Scroll Snap **必须**配合 `overflow` 属性使用——只有当内容超出容器时才会触发滚动，从而触发吸附行为。

```css
.carousel {
  overflow-x: auto;    /* 水平溢出滚动 */
  scroll-snap-type: x mandatory;
}

.carousel::-webkit-scrollbar {
  display: none;        /* 隐藏滚动条 */
}
```

> 💡 `overflow: hidden` 会阻止滚动，`overflow: auto` 或 `overflow: scroll` 才能触发 Snap。

## scroll-snap-align 属性

`scroll-snap-align` 定义在**子元素**上，指定该元素的哪个边/点作为吸附对齐点。

```css
.child {
  scroll-snap-align: <alignment>;
}
```

| 值 | 含义 |
|----|------|
| `none` | 不作为捕捉目标（默认值） |
| `start` | 子元素**顶部/左侧**对齐容器**顶部/左侧** |
| `end` | 子元素**底部/右侧**对齐容器**底部/右侧** |
| `center` | 子元素**中心**对齐容器**中心** |

### 双向分别设置

```css
/* 第一个值：block 方向（垂直），第二个值：inline 方向（水平） */
.card {
  scroll-snap-align: start center;
}
```

### 实战对齐策略

| 场景 | 推荐对齐值 | 原因 |
|------|-----------|------|
| 全屏轮播图 | `center` | 视觉焦点居中，体验流畅 |
| 垂直列表 | `start` | 符合自然阅读习惯（从上到下） |
| 相册网格 | `start` | 紧凑排列，不留空白 |
| 中心对齐卡片 | `center` | 突出当前项 |

## scroll-snap-stop 属性

`scroll-snap-stop` 控制在滚动时是否**禁止跳过**捕捉点。

```css
.child {
  scroll-snap-stop: normal;  /* 默认：可以跳过 */
  scroll-snap-stop: always;  /* 必须停在每个捕捉点 */
}
```

### 使用场景

```css
/* 问卷场景：强制逐题滚动，防止用户跳过 */
.question {
  scroll-snap-type: y mandatory;
  scroll-snap-stop: always;
}
```

> ⚠️ 截至 2024 年，`scroll-snap-stop` 在 Safari 和部分浏览器中支持度有限，使用前请检查 [Can I Use](https://caniuse.com/css-snappoints)。

## scroll-padding 属性

`scroll-padding` 类似于普通 `padding`，但作用于滚动容器的**滚动区域**（可视区域），调整捕捉点的有效位置。

```css
.carousel {
  scroll-snap-type: x mandatory;
  scroll-padding: 20px;          /* 所有方向内缩 20px */
  scroll-padding-inline: 10px;   /* 仅水平方向 */
}
```

### 典型用法：留出固定头部空间

```css
.page {
  scroll-snap-type: y mandatory;
  scroll-padding-top: 60px;      /* 顶部固定导航占 60px */
}

.section {
  scroll-snap-align: start;
}
```

## scroll-margin 属性

`scroll-margin` 作用于**子元素**，增加元素的滚动吸附「外边距」，使吸附点偏离元素实际边缘。

```css
.highlight-card {
  scroll-snap-align: start;
  scroll-margin: 16px;           /* 吸附时元素实际距容器边缘 16px */
}
```

### scroll-padding vs scroll-margin 对比

| 属性 | 作用对象 | 效果 |
|------|---------|------|
| `scroll-padding` | 容器 | 调整容器内边距，影响所有捕捉点 |
| `scroll-margin` | 子元素 | 单独调整某个子元素的吸附位置 |

## 移动端轮播图实战

### 完整轮播图模板

```html
<div class="carousel">
  <div class="carousel__item">1</div>
  <div class="carousel__item">2</div>
  <div class="carousel__item">3</div>
  <div class="carousel__item">4</div>
</div>

<style>
.carousel {
  display: flex;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
  scroll-snap-type: x mandatory;
  gap: 12px;
  -webkit-overflow-scrolling: touch; /* iOS 惯性滚动 */
}

.carousel::-webkit-scrollbar { display: none; } /* 隐藏滚动条 */

.carousel__item {
  flex: 0 0 85%;                /* 每项占 85% 宽度，留出前后项阴影 */
  height: 200px;
  scroll-snap-align: center;     /* 中心对齐 */
  border-radius: 12px;
  background: linear-gradient(135deg, #667eea, #764ba2);
}
</style>
```

### 关键参数说明

| 参数 | 值 | 说明 |
|------|-----|------|
| `flex: 0 0 85%` | 非整除宽度 | 露出下一张的部分，引导用户继续滑动 |
| `scroll-snap-align: center` | 居中对齐 | 每次吸附到视口中央 |
| `-webkit-overflow-scrolling: touch` | iOS 惯性滚动 | 提升移动端滚动手感 |

### 指示器（分页点）

```html
<div class="carousel">
  <!-- items... -->
</div>
<div class="dots">
  <span class="dot active"></span>
  <span class="dot"></span>
  <span class="dot"></span>
  <span class="dot"></span>
</div>

<script>
const carousel = document.querySelector('.carousel');
const dots = document.querySelectorAll('.dot');

carousel.addEventListener('scroll', () => {
  const index = Math.round(carousel.scrollLeft / carousel.offsetWidth);
  dots.forEach((d, i) => d.classList.toggle('active', i === index));
});
</script>
```

## 兼容性与性能

### 浏览器支持

| 特性 | Chrome | Firefox | Safari | Edge |
|------|--------|---------|--------|------|
| `scroll-snap-type` | 69+ | 68+ | 11+ | 79+ |
| `scroll-snap-align` | 69+ | 68+ | 11+ | 79+ |
| `scroll-snap-stop` | 51+ | 😐 部分 | 😐 部分 | 79+ |
| `scroll-padding` | 69+ | 68+ | 14+ | 79+ |

> 📊 数据来源：[Can I Use - CSS Scroll Snap](https://caniuse.com/css-snappoints)

### 性能注意事项

1. **避免在 Snap 容器上使用 JS 动画控制 scroll**：滚动和动画会相互冲突
2. **`will-change: scroll-position`**：提前告知浏览器将改变滚动位置，帮助优化
3. **避免嵌套过深**：Snap 容器嵌套过深会增加滚动计算的复杂度
4. **`overscroll-behavior: contain`**：防止滚动越界时触发父容器滚动
5. **移动端 `100vh` 问题**：移动浏览器地址栏会影响 `100vh` 计算，建议使用 `100dvh`（dynamic viewport height）

### 降级策略

```css
.carousel {
  /* 现代浏览器：使用 Scroll Snap */
  scroll-snap-type: x mandatory;

  /* 旧版 Firefox / IE：使用基于点的旧语法（已废弃但仍被部分浏览器支持） */
  scroll-snap-points-x: repeat(80%);
}
```

## 常见问题

### Q: 为什么滚动后没有吸附？
检查：1) 容器是否有 `overflow` 属性且值不是 `visible`；2) 子元素尺寸是否真的超出了容器。

### Q: mandatory 导致内容被遮挡怎么办？
使用 `proximity` 替代，或重新设计子元素尺寸避免超过视口。

### Q: 如何禁止在某个方向吸附？
使用 `scroll-snap-type: [x|y|both]` 中只开启需要的方向。
