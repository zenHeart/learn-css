# CSS `touch-action` 属性

`touch-action` 是 CSS 属性，用于控制特定区域的触摸手势行为，决定浏览器是否处理某种触摸手势或如何处理。

## 语法

```css
touch-action: auto | none | manipulation | pan-x | pan-y | pan-left | pan-right | pan-up | pan-down | pinch-zoom
```

## 属性值详解

### `auto`（默认值）

浏览器的默认行为完全生效。浏览器会处理所有触摸手势，如滚动、缩放、双击缩放等。

```css
.element {
  touch-action: auto;
}
```

### `none`

完全禁用触摸手势。元素及其子元素不会触发任何浏览器默认的触摸行为，包括滚动、缩放、双击等。

```css
.element {
  touch-action: none;
}
/* 常用于：游戏控件、复杂手绘区域、自定义手势识别 */
```

### `manipulation`

允许滚动和缩放，但**禁用双击缩放**。这是移动端优化的常用值，提供了流畅的单指滚动和捏合缩放。

```css
.element {
  touch-action: manipulation;
}
/* 常用于：移动端地图、图片查看器、需要缩放的 Web 应用 */
```

### `pan-x`

仅允许水平滚动（左右滑动）。垂直滚动和缩放被禁用。

```css
.element {
  touch-action: pan-x;
}
/* 常用于：水平滚动的轮播图、横向时间线 */
```

### `pan-y`

仅允许垂直滚动（上下滑动）。水平滚动和缩放被禁用。

```css
.element {
  touch-action: pan-y;
}
/* 常用于：垂直滚动的列表、长文章阅读区域 */
```

### `pan-left` / `pan-right` / `pan-up` / `pan-down`

允许沿指定方向的滚动，仅当滑动方向与指定方向匹配时才触发滚动。

```css
.element {
  /* 仅允许向左滑动 */
  touch-action: pan-left;
  
  /* 仅允许向上滑动 */
  touch-action: pan-up;
}
/* 常用于：抽屉式导航、滑动删除、边缘滑动触发 */
```

### `pinch-zoom`（可选）

允许捏合缩放（需要与其他值组合使用）。

```css
.element {
  touch-action: pinch-zoom;
}
```

## 组合值

`pan-x` 和 `pan-y` 可以组合使用：

```css
.element {
  /* 同时允许水平和垂直滚动（等同于省略 touch-action 的某些场景） */
  touch-action: pan-x pan-y;
  
  /* 允许水平滚动和缩放 */
  touch-action: pan-x pinch-zoom;
}
```

## 使用场景

### 1. 禁用缩放

```css
.game-controls {
  touch-action: none; /* 游戏手柄区域禁止缩放 */
}

.article-content {
  touch-action: pan-y; /* 文章区域只能上下滚动 */
}
```

### 2. 单轴滚动

```css
/* 横向轮播图 - 只允许水平滚动 */
.carousel {
  touch-action: pan-x;
}

/* 垂直列表 - 只允许垂直滚动 */
.list {
  touch-action: pan-y;
}
```

### 3. 边缘滑动触发

```css
.drawer-handle {
  touch-action: pan-right; /* 从右侧边缘向右滑动打开抽屉 */
}
```

### 4. 移动端优化

```css
/* 推荐用于移动端可滚动区域：允许滚动和缩放，禁用双击缩放 */
.scrollable {
  touch-action: manipulation;
}
```

## `touch-action` vs `pointer-events`

| 特性 | `touch-action` | `pointer-events` |
|------|----------------|------------------|
| **作用对象** | 触摸手势 | 指针事件（鼠标/触摸/触控笔） |
| **主要用途** | 控制滚动、缩放等浏览器行为 | 控制元素是否成为事件目标 |
| **典型场景** | 禁用区域缩放、限制滚动方向 | 禁用元素的点击/交互 |
| **相互关系** | 不影响 `pointer-events` | 不影响触摸手势行为 |

```css
/* 例子：重叠元素的交互控制 */
.upper-layer {
  pointer-events: none; /* 鼠标事件穿透，但触摸手势仍受 touch-action 控制 */
}

.no-gestures {
  touch-action: none; /* 禁用触摸手势，但指针事件仍可触发 */
}
```

## 浏览器兼容性

| 属性值 | Chrome | Firefox | Safari | Edge |
|--------|--------|---------|--------|------|
| `auto` | ✅ 36+ | ✅ 52+ | ✅ 13+ | ✅ 12+ |
| `none` | ✅ 36+ | ✅ 52+ | ✅ 13+ | ✅ 12+ |
| `manipulation` | ✅ 36+ | ✅ 52+ | ✅ 13+ | ✅ 12+ |
| `pan-x` / `pan-y` | ✅ 36+ | ✅ 52+ | ✅ 13+ | ✅ 12+ |
| `pan-left/right/up/down` | ✅ 36+ | ✅ 52+ | ✅ 13+ | ✅ 12+ |
| `pinch-zoom` | ✅ 36+ | ✅ 52+ | ✅ 13+ | ✅ 12+ |

> ⚠️ 移动端浏览器支持略有差异，部分旧版本 Android 浏览器可能不完全支持所有值。

## 实践建议

1. **优先使用 `manipulation`**：移动端可滚动内容推荐使用，禁用双击缩放以提升滚动性能。

2. **合理限制滚动方向**：明确的单轴滚动可提升用户体验，减少误触。

3. **游戏和特殊场景用 `none`**：需要完全自定义手势处理时使用。

4. **注意性能**：不当的 `touch-action` 可能导致不必要的触摸事件处理。
