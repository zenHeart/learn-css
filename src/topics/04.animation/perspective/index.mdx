# CSS perspective

## Overview

`perspective` 属性为 3D 变换元素创建透视效果，让子元素看起来在三维空间中透视变形。它决定了观察者距离元素有多远，从而影响 3D 效果的强烈程度。

## 核心概念

理解 `perspective` 之前，需要理解 3D 变换中的几个关键概念：

- **视锥体（Viewing Frustum）**: 想象一个从观察点发射出去的金字塔形空间，CSS perspective 定义了这个金字塔的"高度"
- **消失点（Vanishing Point）**: 平行线在远处汇聚的点，perspective-origin 决定了这个点的位置
- **Z 轴**: 垂直于屏幕的轴，正值朝向你，负值远离你

```css
.scene {
  perspective: 500px;
}
```

## perspective 属性详解

### 语法

```css
perspective: <length> | none;
```

### 值

| 值 | 描述 |
|---|---|
| `none` | 默认值，不创建透视（默认值） |
| `<length>` | 观察者与 z=0 平面的距离，必须为正数 |

### perspective 距离的影响

**距离越小，3D 效果越强烈；距离越大，3D 效果越弱。**

```css
/* 小距离 = 强烈 3D 效果 */
.intense {
  perspective: 200px;
}

/* 大距离 = 微弱 3D 效果 */
.subtle {
  perspective: 1000px;
}
```

### 直观对比

假设有一个旋转的盒子：

```
perspective: 100px    perspective: 500px    perspective: 1000px
    ___                      ___                      ___
   /   \                    /   \                    /   \
  |  ▣  |  ← 强烈          |  ▣  |  ← 中等          |  ▣  |  ← 微弱
   \___/                    \___/                    \___/
   
   变形明显                   变形适中                   接近平面
```

## perspective-origin 属性

`perspective-origin` 定义了观察者的视角位置，即消失点所在的位置。

### 语法

```css
perspective-origin: <position>;
/* 例如: perspective-origin: center; */
/* 例如: perspective-origin: top left; */
/* 例如: perspective-origin: 25% 75%; */
```

### 默认值

默认值为 `50% 50%`（即 `center`），消失点在元素的中心。

### 效果演示

```css
.scene {
  perspective: 500px;
}

/* 消失点在中心 */
.center {
  perspective-origin: center;
}

/* 消失点在顶部左侧 */
.top-left {
  perspective-origin: top left;
}

/* 消失点在右下角 */
.bottom-right {
  perspective-origin: bottom right;
}
```

## transform-style: preserve-3d

要让子元素真正保留其 3D 变换（不被压平），需要在父元素上使用 `transform-style: preserve-3d`。

### 语法

```css
transform-style: flat | preserve-3d;
```

| 值 | 描述 |
|---|---|
| `flat` | 默认值，子元素被压平到父元素的平面 |
| `preserve-3d` | 子元素保留其 3D 空间位置 |

### 为什么需要 preserve-3d？

```css
/* 没有 preserve-3d，子元素会被压平 */
.parent-flat {
  transform: rotateY(45deg);
}

.parent-flat .child {
  transform: rotateX(45deg);
  /* 实际效果：子元素只是被父元素的 2D 变换影响，而非真正的 3D */
}

/* 有 preserve-3d，子元素在真正的 3D 空间中 */
.parent-3d {
  transform-style: preserve-3d;
  transform: rotateY(45deg);
}

.parent-3d .child {
  transform: rotateX(45deg);
  /* 实际效果：子元素在 3D 空间中独立变换 */
}
```

## perspective 放在哪里：父元素 vs 当前元素

这是一个常见的混淆点。

### 错误理解

直接在应用 3D 变换的元素上设置 `perspective`：

```css
/* ❌ 错误：perspective 不会生效 */
.cube {
  transform: rotateX(-30deg) rotateY(30deg);
  perspective: 500px; /* 这个 perspective 是给 .cube 的子元素用的，不是 .cube 本身 */
}
```

### 正确做法

`perspective` 应该设置在**包含 3D 变换子元素的父元素**上：

```css
/* ✅ 正确：perspective 作用在父元素 */
.scene {
  perspective: 500px;
}

.cube {
  transform: rotateX(-30deg) rotateY(30deg);
}
```

### 透视原理图解

```
         观察者位置 (perspective-origin)
              ↓
              │
    ┌─────────────────────┐
    │    perspective:      │
    │    500px            │
    │    ↓                │
    │    │                │
    │    │   ┌───┐        │
    │    └───│ A │──┐     │
    │        └───┘  │     │
    │               │ Z轴 │
    └───────────────┴─────┘
              ↑
         z=0 平面
```

## 常见使用场景

### 1. 3D 卡片翻转效果

```css
.card-container {
  perspective: 1000px;
}

.card {
  width: 200px;
  height: 260px;
  position: relative;
  transform-style: preserve-3d;
  transition: transform 0.6s;
}

.card.flipped {
  transform: rotateY(180deg);
}

.card-front,
.card-back {
  position: absolute;
  width: 100%;
  height: 100%;
  backface-visibility: hidden;
  border-radius: 12px;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 24px;
  font-weight: bold;
  color: white;
}

.card-front {
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}

.card-back {
  background: linear-gradient(135deg, #f093fb 0%, #f5576c 100%);
  transform: rotateY(180deg);
}
```

```html
<div class="card-container">
  <div class="card">
    <div class="card-front">Front</div>
    <div class="card-back">Back</div>
  </div>
</div>
```

### 2. 3D 旋转木马（Carousel）

```css
.carousel {
  perspective: 1000px;
  height: 200px;
  display: flex;
  align-items: center;
}

.carousel-item {
  width: 120px;
  height: 160px;
  position: absolute;
  left: 50%;
  margin-left: -60px;
  transform-style: preserve-3d;
  transition: transform 0.5s;
}

.carousel-item:nth-child(1) { transform: rotateY(0deg) translateZ(200px); }
.carousel-item:nth-child(2) { transform: rotateY(60deg) translateZ(200px); }
.carousel-item:nth-child(3) { transform: rotateY(120deg) translateZ(200px); }
.carousel-item:nth-child(4) { transform: rotateY(180deg) translateZ(200px); }
.carousel-item:nth-child(5) { transform: rotateY(240deg) translateZ(200px); }
.carousel-item:nth-child(6) { transform: rotateY(300deg) translateZ(200px); }
```

### 3. 3D 按钮悬停效果

```css
.button-3d {
  perspective: 500px;
}

.button-3d-inner {
  background: linear-gradient(135deg, #11998e 0%, #38ef7d 100%);
  padding: 16px 32px;
  border-radius: 8px;
  color: white;
  font-weight: bold;
  transform-style: preserve-3d;
  transition: transform 0.3s;
  transform: rotateX(0);
}

.button-3d:hover .button-3d-inner {
  transform: rotateX(-15deg) translateY(-5px);
  box-shadow: 0 20px 40px rgba(17, 153, 142, 0.4);
}
```

## perspective vs perspective() 函数

这两个都可以创建透视效果，但使用位置不同：

| 属性 | 位置 | 作用对象 |
|------|------|----------|
| `perspective` | CSS 属性，在父元素上 | 所有子元素 |
| `perspective()` | transform 属性值，在元素自身 | 元素本身及其后代 |

```css
/* 方式 1：perspective 属性 */
.scene {
  perspective: 500px;
}

.cube {
  transform: rotateX(-30deg);
}

/* 方式 2：perspective() 函数 */
.cube {
  transform: perspective(500px) rotateX(-30deg);
}
```

**区别**：perspective 属性创建的是共享视锥，所有子元素共用一个消失点；perspective() 函数为每个元素创建独立的视锥。

对于较旧版本，可能需要供应商前缀：

```css
.scene {
  -webkit-perspective: 500px;
  perspective: 500px;
}

.cube {
  -webkit-transform-style: preserve-3d;
  transform-style: preserve-3d;
}
```

## 性能优化建议

1. **使用 transform 而非改变位置属性**：3D 变换会触发 GPU 加速
2. **避免过多的 3D 嵌套**：每个 `preserve-3d` 都会增加渲染成本
3. **合理设置 perspective 值**：过小的值（如 50px）会产生过度变形，过大（如 5000px）效果不明显
4. **使用 `will-change`**：对于复杂的 3D 场景，提前告知浏览器进行优化

```css
.cube {
  will-change: transform;
}
```

## 总结对比表

| 属性 | 默认值 | 作用 |
|------|--------|------|
| `perspective` | `none` | 创建 3D 视锥，确定观察距离 |
| `perspective-origin` | `50% 50%` | 确定消失点位置 |
| `transform-style` | `flat` | 决定子元素是否保留 3D 空间 |
| `backface-visibility` | `visible` | 决定元素背面是否可见 |
