# CSS 基础概念

## css 规则集

```css
header,p {
    background: red;
    color: red;
}
```

## css 申名
除了常规的描述元素样式的规则集，
css 还提供对用户代理的字体等控制。或根据用户代理的特性使用不同的规则集。
描述这些特征的结构为 css 申名。

### 规则集合

### at-rules
css 申名，用来描述 css 的行为。基本结构如下

```css
@IDENTIFIER (RULE)
```

* `@IDENTIFIER` 标识符，描述何种规则
* `(RULE)` 申名该标识符对应的规则

典型的 `@rules` 如下

* `@charset` 定义样式表的字符集
* `@import` 告诉 css 引擎导入额外的样式表
* **嵌套规则集合** 可以嵌套在规则集内部使用
  * `@media` 当设备匹配查询条件时，声明起作用
  * `@supports` — 当浏览器支持语法时，声明起作用

## 知识点
1. css 规则集
   1. 选择器，描述 css 申名块作用于哪些元素
   2. 声明块，有多条申名组成的规则集合，描述元素的特征
      1. `属性名`，描述的特定特征
      2. `:，;` `:` 分隔属性和值，`;` 分隔多条申名
      3. `值` 描述属性具有的特征
2. css 声明
   1. `规则集合`,一系列规则集组成的描述元素结构的声明
   2. `At规则集合`,以 `@` 开头的申名
