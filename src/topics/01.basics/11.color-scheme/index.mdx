# CSS `color-scheme` 颜色方案适配

## 概述

`color-scheme` 是 CSS Color Adjustment Module Level 1 规范中定义的属性，用于**声明页面或元素支持的色彩方案**。当用户在操作系统中选择了「亮色模式」或「暗黑模式」后，浏览器会自动将 `color-scheme` 声明了对应方案的页面 UI（滚动条、表单控件、拼写检查下划线等）调整为匹配的颜色。

配合 `light-dark()` 颜色函数和 `prefers-color-scheme` 媒体查询，开发者可以构建响应操作系统主题偏好的用户体验。

## 语法详解

```css
/* 关键词形式 */
color-scheme: normal;
color-scheme: light;
color-scheme: dark;
color-scheme: light dark;       /* 同时支持亮色和暗黑 */
color-scheme: only light;       /* 仅亮色，禁止浏览器覆盖 */

/* 全局值 */
color-scheme: inherit;
color-scheme: initial;
color-scheme: revert;
color-scheme: revert-layer;
color-scheme: unset;
```

### 值说明

| 值 | 说明 |
|---|---|
| `normal` | 使用页面默认配色，等同于未声明 |
| `light` | 页面支持操作系统亮色模式 |
| `dark` | 页面支持操作系统暗黑模式 |
| `light dark` | 同时支持两种模式，由用户偏好决定 |
| `only light` | 强制仅亮色，防止浏览器（如 Chrome Auto Dark Mode）覆盖 |
| `only dark` | 强制仅暗黑 |

## 受影响的 UI 元素

`color-scheme` 声明后，浏览器会自动调整以下 UI 的默认颜色：

- **画布背景色**（`canvas` 背景）
- **滚动条**（滚动条轨道和滑块）
- **表单控件**（输入框、按钮、复选框等的默认颜色）
- **浏览器提供的 UI**（拼写检查下划线等）

## 与 `light-dark()` 配合使用

`light-dark()` 是 CSS Color Module Level 5 新增的颜色函数，与 `color-scheme` 配合使用可以实现声明式的双主题适配：

```css
:root {
  color-scheme: light dark;
}

body {
  color: light-dark(#1a1a1a, #f0f0f0);
  background-color: light-dark(#f0f0f0, #1a1a1a);
}
```

当操作系统为亮色模式时，`light-dark(a, b)` 返回第二个参数 `b`；暗黑模式时返回第一个参数 `a`。

### 与 CSS 变量的配合

```css
:root {
  color-scheme: light dark;

  /* 使用 CSS 变量集中管理颜色 */
  --text-primary: light-dark(#1a1a1a, #f0f0f0);
  --text-secondary: light-dark(#666666, #a0a0a0);
  --surface: light-dark(#ffffff, #1a1a1a);
  --border: light-dark(#e0e0e0, #333333);
}

body {
  color: var(--text-primary);
  background-color: var(--surface);
}

.card {
  border: 1px solid var(--border);
}
```

### 与 `prefers-color-scheme` 媒体查询的对比

| 特性 | `color-scheme` + `light-dark()` | `prefers-color-scheme` 媒体查询 |
|---|---|---|
| 声明方式 | 声明式，声明支持哪些方案 | 条件式，按方案编写不同样式 |
| UI 调整 | 浏览器自动调整原生 UI | 仅调整自定义样式 |
| 代码量 | 少（每个属性一行搞定） | 多（需要重复写两组样式） |
| 适用场景 | 主题色、固定的双主题 | 复杂的差异化样式 |

```css
/* 使用 prefers-color-scheme：大量重复代码 */
@media (prefers-color-scheme: light) {
  body { color: #1a1a1a; background: #f0f0f0; }
  .card { border-color: #e0e0e0; }
}
@media (prefers-color-scheme: dark) {
  body { color: #f0f0f0; background: #1a1a1a; }
  .card { border-color: #333333; }
}

/* 使用 color-scheme + light-dark()：简洁声明 */
:root { color-scheme: light dark; }
body { color: light-dark(#1a1a1a, #f0f0f0); background: light-dark(#f0f0f0, #1a1a1a); }
.card { border-color: light-dark(#e0e0e0, #333333); }
```

## HTML 配合：`<meta>` 标签

为了让 `color-scheme` 在页面加载时立即生效（避免闪烁），应在 `<head>` 中添加 `<meta>` 标签，且位于任何 CSS 之前：

```html
<head>
  <meta name="color-scheme" content="light dark">
  <link rel="stylesheet" href="styles.css">
</head>
```

> 注意：`color-scheme` CSS 属性和 `<meta name="color-scheme">` 的作用相同。CSS 属性可以对单个元素生效，`<meta>` 标签则作用于整个文档。

## 实际应用场景

### 1. 全站双主题支持

```css
/* 在根元素上声明 */
:root {
  color-scheme: light dark;
}

/* 表单控件自动适配 */
input, textarea, select {
  background-color: light-dark(#ffffff, #2d2d2d);
  color: light-dark(#000000, #f0f0f0);
  border-color: light-dark(#cccccc, #444444);
}
```

### 2. 仅亮色模式的组件

```css
/* 强制仅亮色的区域（如品牌色块） */
.brand-block {
  color-scheme: only light;
  background-color: #007bff;
  color: #ffffff; /* 固定使用白色文本 */
}
```

### 3. 分区域声明

```css
header {
  color-scheme: only light;   /* 头部固定亮色 */
}

main {
  color-scheme: light dark;   /* 内容区跟随系统 */
}

footer {
  color-scheme: only dark;    /* 页脚固定暗黑 */
}
```

### 4. 完整主题切换系统

```css
/* 基础声明 */
:root {
  color-scheme: light dark;
  color: light-dark(#1a1a1a, #f0f0f0);
  background-color: light-dark(#ffffff, #121212);
}

/* CSS 变量集中管理 */
:root {
  --color-bg: light-dark(#ffffff, #121212);
  --color-surface: light-dark(#f5f5f5, #1e1e1e);
  --color-text: light-dark(#1a1a1a, #e0e0e0);
  --color-border: light-dark(#e0e0e0, #333333);
  --color-primary: light-dark(#0066cc, #4da3ff);
}

/* 应用变量 */
body { background: var(--color-bg); color: var(--color-text); }
.card { background: var(--color-surface); border: 1px solid var(--color-border); }
button { background: var(--color-primary); color: light-dark(#fff, #000); }
```

## 浏览器兼容性

`color-scheme` 属于 **Baseline（广泛可用）** 功能，自 **2022 年 1 月** 起已在所有主流浏览器中得到支持。

| 特性 | Chrome | Firefox | Safari | Edge |
|---|---|---|---|---|
| `color-scheme` | ✅ 81+ | ✅ 96+ | ✅ 13.1+ | ✅ 81+ |

`light-dark()` 函数兼容性稍晚：

| 特性 | Chrome | Firefox | Safari | Edge |
|---|---|---|---|---|
| `light-dark()` | ✅ 123+ | ✅ 113+ | ✅ 17.5+ | ✅ 123+ |

### 渐进增强

```css
/* 基础方案：使用 CSS 变量 + 媒体查询 */
:root { --bg: #fff; --text: #1a1a1a; }

@media (prefers-color-scheme: dark) {
  :root { --bg: #1a1a1a; --text: #f0f0f0; }
}

/* 增强：使用 light-dark() 简化代码 */
@supports (color: light-dark(red, blue)) {
  :root { color-scheme: light dark; }
  :root { --bg: light-dark(#fff, #1a1a1a); --text: light-dark(#1a1a1a, #f0f0f0); }
}
```
