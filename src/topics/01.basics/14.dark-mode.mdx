# 暗黑模式实现

## 概述

暗黑模式是一种显示模式，使用深色背景和浅色文本，能够减少眼睛疲劳，节省电池电量，并在低光环境下提供更好的用户体验。

## 实现方案

### 1. 采用 CSS 全局变量

使用CSS自定义属性（CSS变量）是实现暗黑模式最灵活和可维护的方法。

#### 基础变量定义

```css
:root {
  /* 亮色模式变量 */
  --bg-color: #ffffff;
  --text-color: #333333;
  --border-color: #e1e1e1;
  --card-bg: #ffffff;
  --button-bg: #007bff;
  --button-text: #ffffff;
  --link-color: #007bff;
  --shadow: rgba(0, 0, 0, 0.1);
}

/* 暗色模式变量 */
[data-theme="dark"] {
  --bg-color: #1a1a1a;
  --text-color: #ffffff;
  --border-color: #444444;
  --card-bg: #2d2d2d;
  --button-bg: #66b3ff;
  --button-text: #000000;
  --link-color: #66b3ff;
  --shadow: rgba(255, 255, 255, 0.1);
}
```

#### 应用变量到组件

```css
/* 使用变量的样式 */
body {
  background-color: var(--bg-color);
  color: var(--text-color);
  transition: background-color 0.3s ease, color 0.3s ease;
}

.card {
  background-color: var(--card-bg);
  border: 1px solid var(--border-color);
  box-shadow: 0 2px 8px var(--shadow);
  transition: all 0.3s ease;
}

.button {
  background-color: var(--button-bg);
  color: var(--button-text);
  border: 1px solid var(--button-bg);
}

a {
  color: var(--link-color);
}

.input {
  background-color: var(--card-bg);
  border: 1px solid var(--border-color);
  color: var(--text-color);
}
```

### 2. 使用 prefers-color-scheme 媒体查询

利用系统级别的颜色方案偏好自动切换主题。

```css
/* 默认亮色模式 */
:root {
  --bg-color: #ffffff;
  --text-color: #333333;
  --border-color: #e1e1e1;
}

/* 系统暗色模式 */
@media (prefers-color-scheme: dark) {
  :root {
    --bg-color: #1a1a1a;
    --text-color: #ffffff;
    --border-color: #444444;
  }
}

/* 应用样式 */
body {
  background-color: var(--bg-color);
  color: var(--text-color);
  transition: background-color 0.3s ease, color 0.3s ease;
}
```

### 3. 混合方案：支持手动切换和系统偏好

```css
/* 默认跟随系统 */
:root {
  --bg-color: #ffffff;
  --text-color: #333333;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg-color: #1a1a1a;
    --text-color: #ffffff;
  }
}

/* 手动设置覆盖系统偏好 */
[data-theme="light"] {
  --bg-color: #ffffff;
  --text-color: #333333;
}

[data-theme="dark"] {
  --bg-color: #1a1a1a;
  --text-color: #ffffff;
}

/* 应用样式 */
body {
  background-color: var(--bg-color);
  color: var(--text-color);
}
```

## 完整的暗黑模式设计系统

### 颜色设计原则

1. **对比度充足**：确保文本和背景有足够的对比度
2. **眼睛友好**：使用偏灰的黑色而非纯黑色
3. **品牌一致性**：保持品牌色彩在暗色模式下的识别度
4. **层次清晰**：通过不同深度的背景色创建视觉层次

## JavaScript 主题切换

### 基础主题切换功能

```javascript
class ThemeManager {
  constructor() {
    this.themes = ['light', 'dark', 'auto'];
    this.currentTheme = this.getStoredTheme() || 'auto';
    this.init();
  }
  
  init() {
    this.applyTheme(this.currentTheme);
    this.setupEventListeners();
  }
  
  // 获取存储的主题
  getStoredTheme() {
    return localStorage.getItem('theme');
  }
  
  // 存储主题设置
  setStoredTheme(theme) {
    localStorage.setItem('theme', theme);
  }
  
  // 获取系统偏好
  getSystemTheme() {
    return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
  }
  
  // 应用主题
  applyTheme(theme) {
    this.currentTheme = theme;
    
    if (theme === 'auto') {
      const systemTheme = this.getSystemTheme();
      document.documentElement.setAttribute('data-theme', systemTheme);
    } else {
      document.documentElement.setAttribute('data-theme', theme);
    }
    
    this.setStoredTheme(theme);
    this.updateToggleButton();
  }
  
  // 切换主题
  toggleTheme() {
    const currentIndex = this.themes.indexOf(this.currentTheme);
    const nextIndex = (currentIndex + 1) % this.themes.length;
    const nextTheme = this.themes[nextIndex];
    
    this.applyTheme(nextTheme);
  }
  
  // 设置特定主题
  setTheme(theme) {
    if (this.themes.includes(theme)) {
      this.applyTheme(theme);
    }
  }
  
  // 更新切换按钮
  updateToggleButton() {
    const button = document.querySelector('[data-theme-toggle]');
    if (button) {
      button.textContent = this.getThemeLabel(this.currentTheme);
      button.setAttribute('aria-label', `切换到${this.getNextThemeLabel()}`);
    }
  }
  
  // 获取主题标签
  getThemeLabel(theme) {
    const labels = {
      light: '☀️',
      dark: '🌙',
      auto: '🔄'
    };
    return labels[theme] || '🔄';
  }
  
  // 获取下一个主题标签
  getNextThemeLabel() {
    const currentIndex = this.themes.indexOf(this.currentTheme);
    const nextIndex = (currentIndex + 1) % this.themes.length;
    const nextTheme = this.themes[nextIndex];
    
    const labels = {
      light: '亮色模式',
      dark: '暗色模式',
      auto: '跟随系统'
    };
    return labels[nextTheme] || '跟随系统';
  }
  
  // 设置事件监听器
  setupEventListeners() {
    // 监听系统主题变化
    window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', (e) => {
      if (this.currentTheme === 'auto') {
        this.applyTheme('auto');
      }
    });
    
    // 监听切换按钮点击
    document.addEventListener('click', (e) => {
      if (e.target.matches('[data-theme-toggle]')) {
        this.toggleTheme();
      }
    });
    
    // 监听键盘快捷键 (Ctrl/Cmd + Shift + L)
    document.addEventListener('keydown', (e) => {
      if ((e.ctrlKey || e.metaKey) && e.shiftKey && e.key === 'L') {
        e.preventDefault();
        this.toggleTheme();
      }
    });
  }
}

// 初始化主题管理器
const themeManager = new ThemeManager();

// 暴露全局方法
window.setTheme = (theme) => themeManager.setTheme(theme);
window.toggleTheme = () => themeManager.toggleTheme();
```

## 浏览器开发者工具测试

### Chrome 开发者工具

在 Chrome 中测试暗黑模式：

1. 打开开发者工具 (F12)
2. 打开命令面板 (Ctrl+Shift+P / Cmd+Shift+P)
3. 输入 "Rendering"
4. 选择 "Show Rendering"
5. 在 "Emulate CSS media feature prefers-color-scheme" 下拉菜单中选择：
   - `prefers-color-scheme: dark`
   - `prefers-color-scheme: light`
   - `No emulation`

### Firefox 开发者工具

在 Firefox 中测试：

1. 打开开发者工具 (F12)
2. 在设置中启用 "检查器" > "切换 prefers-color-scheme 仿真"
3. 在检查器工具栏中会出现模拟按钮

## 最佳实践

### 1. 渐进增强

```css
/* 基础样式（亮色模式） */
body {
  background: white;
  color: black;
}

/* 暗色模式增强 */
@media (prefers-color-scheme: dark) {
  body {
    background: #1a1a1a;
    color: white;
  }
}
```

### 2. 图片适配

```css
/* 图片在暗色模式下的处理 */
.logo {
  filter: none;
}

[data-theme="dark"] .logo {
  filter: brightness(0.8) contrast(1.2);
}

/* 或者使用不同的图片 */
.logo-light {
  display: block;
}

.logo-dark {
  display: none;
}

[data-theme="dark"] .logo-light {
  display: none;
}

[data-theme="dark"] .logo-dark {
  display: block;
}
```

### 3. 动画和过渡

```css
/* 确保主题切换时的平滑过渡 */
* {
  transition: background-color 0.3s ease, 
              color 0.3s ease, 
              border-color 0.3s ease,
              box-shadow 0.3s ease;
}

/* 禁用动画的用户偏好 */
@media (prefers-reduced-motion: reduce) {
  * {
    transition: none !important;
    animation: none !important;
  }
}
```

### 4. 可访问性考虑

```css
/* 确保充足的对比度 */
:root {
  --text-on-primary: white; /* 4.5:1 对比度 */
  --text-on-secondary: #333; /* 7:1 对比度 */
}

/* 焦点指示器 */
.button:focus-visible {
  outline: 2px solid var(--color-primary);
  outline-offset: 2px;
}

/* 高对比度模式支持 */
@media (prefers-contrast: high) {
  :root {
    --border-primary: currentColor;
    --shadow-md: none;
  }
}
```
