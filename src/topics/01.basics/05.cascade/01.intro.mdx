## 什么是层叠
层叠规则确定了 css 中申明的属性会如何作用在元素上。
参考 [css 4 层叠规范](https://www.w3.org/TR/css-cascade-4/#cascading) 层叠规则按照权重总结如下

1. 若定义的属性值包含 `!important` 则优先级最高
2. 按照申明的方式
   1. 元素 `style` 属性上申明的样式
   2. `style` 标签定义的内联样式
   3. `link` 标签引入的外部样式
   4. 浏览器的的默认计算属性
3. 采用不同选择器选中的同一个元素,采用遵从选择器权重规则
4. 按照申明顺序,相同权重申明后面的会覆盖前面的申明

## 选择器权重 (selector specificity)

选择器权重叫做 **selector specificity** .
当采用不同选择器在一个元素上申明相同 css 属性时,
浏览器为了解决哪个 css 规则被采用定义的一套规范.

### 核心规则

不同选择器在设定元素 css 属性时具有不同权重,
权重等级如下:

-   id 选择器权重为 `0,1,0,0`
-   类选择器,属性选择器,伪类选择器 `0,0,1,0`
-   元素选择器,伪元素选择器权重为 `0,0,0,1`

此外还有如下规则

-   通用选择器 `*` 没有权重
-   结合符对选择器没有贡献
