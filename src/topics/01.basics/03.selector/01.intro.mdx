# selector

**css 选择器详解**

---

## 概述

选择器机制解决了如何选择 html 元素来设置 css 属性的问题。
选择器学习的核心点包括:

1. 选择器的作用原理
    1. 选择器如何生效
    2. 选择器特殊性 解决了采用不同方式的选择器,设定同一个 html 元素的层叠规则
2. 选择器类型 解决了在不同场景如何选择 html 元素的问题

## 属性选择器

属性选择器基于元素的属性进行匹配的选择器。
常用选择器如下:

-   **[attr]** 包含此属性值的元素均会被选中
-   **[attr=value]** 包含属性且属性值等于 value 的元素
-   **[attr~=value]** 包含属性且为以空格分隔的值中包含 value 的元素
-   **[attr|=value]** 包含属性且值已 value 开头后接 `-` 的元素
    > 多用于语言属性的选择
-   **[attr^=value]** 包含属性且属性值以 value 开头的元素
-   **[attr*=value]** 包含属性且属性值中有 value 的元素
-   **[att$=value]** 包含属性且属性值以 value 结尾的元素

额外的特性包括

-   **[attr operator value i]** 其中 i 为修饰符表示忽略对值大小写的比较,例如 `a[href="TEST" i]` 匹配超链接中包含 `TEST` 的字符其中忽略大小写。参看例子 [属性 i](./examples/selector/ignore-case-selector.html)

## 元素
* `:empty` 选择子节点为空的元素,参考示例 [空节点](./examples/selector/empty.html)
* `:last-of-type` 选中子节点中最后一次出现的某类元素,参考示例 [末尾同类节点](./examples/selector/last-of-type.html)
* `:only-of-type` 选中子节点中唯一出现的某类元素,参考示例 [唯一某类节点](./examples/selector/only-of-type.html)
