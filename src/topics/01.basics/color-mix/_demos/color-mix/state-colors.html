Badge 标签

/* 从主色 + 目标色各 50% 混合 */ --success: color-mix(in srgb, var(--primary), #22c55e 50%); --success-bg: color-mix(in srgb, var(--success) 12%, transparent); /* Badge 样式 */ .badge { background: var(--success-bg); color: var(--success); border: 1px solid var(--success-border); }

按钮状态变体

💡 技巧：将 success/warning/danger 等目标状态色与主色按固定比例混合，可以得到色调统一的状态色系。 例如 --success = color-mix(in srgb, var(--primary), #22c55e 50%) 可以让所有状态色都带有主色的色调。
