推荐选型指南

场景 推荐颜色空间 原因
主题色派生 oklch 饱和度自然，亮度感知均匀
状态色生成 srgb 符合传统设计直觉，简单可靠
调深/调浅 oklch / hwb 保持色相，增加黑色或白色
渐变增强 oklch 混合过渡平滑，避免色相跳变
透明度混合 srgb 透明色在 srgb 中处理更一致
精确物理混色 srgb-linear 基于光强度的物理混色，无 gamma 校正

实战代码对比

/* 生成浅色变体 — oklch 更自然 */ --primary-light: color-mix(in oklch, var(--primary), #fff 30%); --primary-light: color-mix(in oklch, var(--primary), #fff 20%); /* 生成深色变体 — oklch 保持饱和度 */ --primary-dark: color-mix(in oklch, var(--primary), #000 25%); /* 灰度混合 — srgb 和 oklch 结果不同 */ color-mix(in srgb, #fff 50%, #000); /* 灰色 #808080 */ color-mix(in oklch, #fff 50%, #000); /* 浅灰 #adadad */ /* 渐变过渡 — oklch 避免色相跳变 */ background: linear-gradient( 135deg, color-mix(in oklch, #667eea, white 15%), color-mix(in oklch, #667eea 50%, #764ba2 50%), color-mix(in oklch, #764ba2, white 15%) );
