🎨 color-mix() 主题色动态混合

主题切换

color-mix() 自动在 oklch 空间中混合品牌色，生成派生色系，无需手动定义每种状态颜色

颜色条对比

--brand-muted
--brand-subtle
--brand
--brand-light
--brand-dark
从同一 --brand 主色，通过 color-mix() 自动生成 5 个派生色

按钮组件示例

/* CSS 核心逻辑 */ :root { --brand: oklch(55% 0.2 250); --brand-light: color-mix(in oklch, var(--brand), #fff 25%); --brand-dark: color-mix(in oklch, var(--brand), #000 25%); --brand-subtle: color-mix(in oklch, var(--brand), #fff 88%); --brand-muted: color-mix(in oklch, var(--brand), #000 88%); }
