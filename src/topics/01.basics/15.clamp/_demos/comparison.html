这是一个使用媒体查询实现的响应式字体。

这是一个使用 clamp() 实现的响应式字体。

字体大小会随着视口平滑连续地变化。

💻 代码对比
媒体查询方式
.text {
  font-size: 14px;
}

/* 4个断点，4处代码 */
@media (min-width: 480px) {
  .text {
    font-size: 18px;
  }
}

@media (min-width: 768px) {
  .text {
    font-size: 24px;
  }
}

@media (min-width: 1024px) {
  .text {
    font-size: 32px;
  }
}
clamp() 方式
/* 一行代码搞定 */
.text {
  font-size:
  clamp(
    14px,
    4vw,
    32px
  );
}

🏆 clamp() 的优势
📝 代码量少
一行 clamp() 替代多行媒体查询代码
🔄 平滑过渡
值的变化是连续的，而非跳跃式的
🛠️ 易于维护
所有逻辑集中在一处，无需多处修改
📱 真正流体
完美适配任何视口尺寸，无固定断点
⚡ 运行时计算
基于当前视口实时计算，性能更好
🎯 精确控制
可以精确控制最小值、最大值和变化率
