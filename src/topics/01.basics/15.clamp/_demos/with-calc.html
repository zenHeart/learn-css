📐 clamp() + calc() 基础

高级字体大小计算

font-size: clamp(1rem, 1rem + 2vw, 2rem)

💡 这种写法可以确保最小字体不小于 1rem，同时在计算中加入了基础值。

📝 CSS 代码

font-size: clamp(
  1rem,
  1rem + 2vw,
  2rem
);

📐 clamp() + 自定义属性

使用 CSS 自定义属性

结合 var() 和 clamp() 创建可复用的流体设计系统。

📝 CSS 代码

:root {
  --min-size: 1rem;
  --max-size: 2.5rem;
  --scale: 3vw;
}

.text {
  font-size: clamp(
    var(--min-size),
    var(--scale),
    var(--max-size)
  );
}
💡 最佳实践公式

流体排版 (推荐)

流体间距

gap: clamp(minPX, minPX + scaleVW, maxPX);

流体组件尺寸
