# CSS light-dark() 函数

## 概述

`light-dark()` 是 CSS Color Level 5 引入的颜色函数，专门用于简化明暗主题切换。这个函数接受两个颜色值作为参数，根据当前使用的主题（Light 或 Dark）自动返回对应的颜色。

## 为什么需要 light-dark()

传统的明暗模式切换通常需要这样写：

```css
:root {
  --text-color: #333;  /* Light 模式 */
  --bg-color: #fff;    /* Light 模式 */
}

@media (prefers-color-scheme: dark) {
  :root {
    --text-color: #ccc;  /* Dark 模式 */
    --bg-color: #1a1a1a; /* Dark 模式 */
  }
}
```

使用 `light-dark()` 可以简化为：

```css
:root {
  color-scheme: light dark;
  --text-color: light-dark(#333, #ccc);
  --bg-color: light-dark(#fff, #1a1a1a);
}
```

## 基础语法

```css
light-dark(<color>, <color>)
```

### 参数说明

| 参数 | 说明 |
|------|------|
| 第一个 `<color>` | Light 模式下使用的颜色 |
| 第二个 `<color>` | Dark 模式下使用的颜色 |

### 返回值规则

- 当使用的主题是 `light` 或未知时，返回第一个颜色
- 当使用的主题是 `dark` 时，返回第二个颜色

## 核心概念：color-scheme

`light-dark()` 的工作依赖于 `color-scheme` 属性。只有同时声明了 `color-scheme: light dark`，浏览器才能正确地在两种颜色之间切换。

### color-scheme 可选值

| 值 | 说明 |
|----|------|
| `light` | 页面适合浅色主题 |
| `dark` | 页面适合深色主题 |
| `normal` | 正常使用浏览器默认 |

```css
:root {
  /* 声明支持两种主题 */
  color-scheme: light dark;
}
```

### 使用方式

#### 1. 全局声明

```css
:root {
  color-scheme: light dark;
}
```

#### 2. 元素级别覆盖

```css
.dark-only-component {
  color-scheme: dark;  /* 强制这个组件使用深色模式 */
}
```

## 实际应用场景

### 1. 基础文本颜色

```css
body {
  color-scheme: light dark;
  color: light-dark(#1a1a1a, #e5e5e5);
  background: light-dark(#ffffff, #1a1a1a);
}
```

### 2. 边框和分隔线

```css
.card {
  border: 1px solid light-dark(rgba(0,0,0,0.1), rgba(255,255,255,0.1));
}
```

### 3. 阴影效果

```css
.button {
  box-shadow: 
    light-dark(
      0 2px 8px rgba(0,0,0,0.1),
      0 2px 8px rgba(0,0,0,0.3)
    );
}
```

### 4. 系统颜色组合

```css
:root {
  color-scheme: light dark;
}

.button {
  background: Canvas;
  color: light-dark(black, white);
  border: 1px solid light-dark(CanvasText, rgba(255,255,255,0.2));
}
```

### 5. 渐变背景

```css
.hero {
  background: light-dark(
    linear-gradient(135deg, #667eea 0%, #764ba2 100%),
    linear-gradient(135deg, #1a1a2e 0%, #16213e 100%)
  );
}
```

### 6. 覆盖特定元素

```css
.force-dark {
  color-scheme: dark;
  background: #000;
}

.force-dark .text {
  /* 这里 light-dark() 会返回深色值 */
  color: light-dark(black, white);
}
```

## 与 prefers-color-scheme 的对比

| 特性 | `light-dark()` | `prefers-color-scheme` |
|------|----------------|----------------------|
| 触发方式 | 浏览器/系统主题 | 用户主题偏好 |
| 覆盖能力 | 可被 `color-scheme` 覆盖 | 不可覆盖 |
| 代码量 | 更简洁 | 较冗长 |
| 灵活性 | 较低 | 较高 |

```css
/* prefers-color-scheme - 用户优先 */
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #1a1a1a;
  }
}

/* light-dark() - 可被覆盖 */
:root {
  color-scheme: light dark;
  --bg: light-dark(#fff, #1a1a1a);
}

.admin-mode {
  color-scheme: dark;  /* 强制深色，--bg 也会变为深色值 */
}
```

## 最佳实践

### 1. 始终声明 color-scheme

```css
:root {
  color-scheme: light dark;
}
```

### 2. 结合自定义属性

```css
:root {
  color-scheme: light dark;
  
  /* 定义颜色变量 */
  --surface: light-dark(#fff, #1a1a1a);
  --text-primary: light-dark(#1a1a1a, #f5f5f5);
  --text-secondary: light-dark(#666, #999);
  --border: light-dark(#e0e0e0, #333);
}

/* 使用变量 */
.card {
  background: var(--surface);
  color: var(--text-primary);
  border: 1px solid var(--border);
}
```

### 3. 使用系统颜色

```css
:root {
  color-scheme: light dark;
}

.body {
  background: light-dark(Canvas, Canvas);
  color: light-dark(CanvasText, CanvasText);
}
```

### 4. 优雅降级

```css
.button {
  /* 回退颜色 */
  background: #007bff;
}

@supports (color: light-dark(red, red)) {
  .button {
    background: light-dark(#007bff, #0056b3);
  }
}
```

## 未来展望：schemed-value()

`light-dark()` 是向更通用的 `schemed-value()` 函数迈出的第一步。未来这个函数将支持：

- 任意数量的颜色方案
- 任意 CSS 属性值，不仅仅是颜色
- 自定义颜色方案名称

```css
/* 未来可能的语法 */
body {
  color-scheme: dark light custom;
  color: schemed-value(
    light #333,
    dark #ccc,
    custom purple
  );
}
```

## 完整示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <style>
    :root {
      color-scheme: light dark;
    }
    
    body {
      font-family: system-ui, sans-serif;
      transition: background-color 0.3s, color 0.3s;
    }
    
    .card {
      padding: 20px;
      border-radius: 8px;
      border: 1px solid light-dark(#e0e0e0, #333);
      background: light-dark(#fff, #1a1a1a);
      color: light-dark(#1a1a1a, #f5f5f5);
      margin: 16px;
    }
    
    .button {
      padding: 10px 20px;
      border-radius: 6px;
      border: none;
      background: light-dark(#007bff, #0d6efd);
      color: white;
      cursor: pointer;
    }
    
    .button:hover {
      background: light-dark(#0056b3, #0b5ed7);
    }
  </style>
</head>
<body>
  <div class="card">
    <h1>light-dark() 示例</h1>
    <p>这个页面会自动响应系统明暗模式。</p>
    <button class="button">点击按钮</button>
  </div>
</body>
</html>
```
