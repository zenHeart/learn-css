# CSS :has() 关系选择器详解

## 什么是 :has()

`:has()` 是 CSS 关系型伪类（Pseudo-class），俗称「父选择器」。它允许你根据元素的后代或兄弟元素来选择该元素。`:has()` 是 CSS Selectors Level 4 规范中引入的功能，是 CSS 选择器历史上革命性的突破。

### 基本语法

```css
/* 选择包含 .featured 子元素的 section */
section:has(.featured) {
  /* styles */
}

/* 选择紧邻 h2 的 h1 */
h1:has(+ h2) {
  /* styles */
}
```

### 语法详解

```
:has(<relative-selector-list>)
```

- `<relative-selector-list>`：相对选择器列表，用逗号分隔
- 相对选择器：相对于 `:has()` 所在元素进行匹配
- 支持复杂的选择器组合

## 核心概念

### 1. 关系型伪类

`:has()` 是一种「关系型伪类」，它建立元素之间的关系：

| 伪类类型 | 示例 | 说明 |
|---------|------|------|
| 关系型 | `:has()` | 根据与其他元素的关系选择 |
| 状态型 | `:hover` | 根据用户交互状态选择 |
| 结构型 | `:first-child` | 根据文档结构选择 |

### 2. 父选择器

传统 CSS 无法直接选择「父元素」，`:has()` 首次实现了这一能力：

```css
/* 选择包含图片的文章 */
article:has(img) { }

/* 选择包含特定子元素的容器 */
.card:has(.badge) { }
```

### 3. 前向选择

`:has()` 支持「前向选择」，即选择「后面有特定兄弟元素的元素」：

```css
/* 选择紧跟在 h2 后面的段落 */
p:has(+ h2) { }

/* 选择 h1 后面的所有兄弟元素 */
h1:has(~ *) { }
```

### 4. 与 :is()/:where() 组合

`:has()` 可以与 `:is()`、`:where()` 组合使用，实现更复杂的选择：

```css
/* 使用 :is() 简化选择器 */
article:is(:has(h1), :has(h2)) { }

/* 使用 :where() 无权重选择器 */
:where(.dark-mode):has(img) { }
```

## 实战案例

### 案例 1：父元素选择

{/* @playground id="parent-selector" mode="demo" */}

```css
/* 选择包含 .featured 商品的 section */
section:has(.featured) {
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}

/* 选择包含勾选状态复选框的 label */
label:has(input[type="checkbox"]:checked) {
  color: #22c55e;
  font-weight: 600;
}
```

### 案例 2：兄弟选择

{/* @playground id="sibling-selector" mode="demo" */}

```css
/* 选择紧邻 h2 的 h1（相邻兄弟） */
h1:has(+ h2) {
  margin-bottom: 0;
  padding-bottom: 0;
}

/* h2 成为 h1 的对比标题 */
h2:has(~ p) {
  color: #64748b;
}
```

### 案例 3：逻辑组合

{/* @playground id="logical-combinators" mode="demo" */}

```css
/* OR 关系：包含 video 或 audio */
body:has(video, audio) {
  --media-indicator: 1;
}

/* AND 关系：同时包含 video 和 audio */
body:has(video):has(audio) {
  --media-indicator: 2;
}

/* NOT 关系：不包含特定元素 */
article:has(.ad):not(:has(.featured)) {
  opacity: 0.6;
}
```

### 案例 4：表单状态

{/* @playground id="form-states" mode="demo" */}

```css
/* 选择获得焦点的 input 所在的 form */
form:has(input:focus) {
  border-color: #3b82f6;
}

/* 选择包含已选中单选框的 fieldset */
fieldset:has(input[type="radio"]:checked) {
  background: #f0f9ff;
}

/* 选择验证失败的 input 所在的 div */
div:has(input:invalid) .error-message {
  display: block;
}
```

### 案例 5：布局状态

{/* @playground id="layout-states" mode="demo" */}

```css
/* 选择包含溢出内容的容器 */
.container:has(*:overflow) {
  outline: 2px dashed #f59e0b;
}

/* 选择包含绝对定位元素的相对定位容器 */
.relative-container:has(> .absolute-child) {
  outline: 2px solid #8b5cf6;
}
```

## 兼容性

`:has()` 已获得主流浏览器的广泛支持：

| 浏览器 | 支持版本 |
|-------|---------|
| Chrome | 105+ |
| Firefox | 121+ |
| Safari | 15.4+ |
| Edge | 105+ |

### 降级方案

对于不支持的浏览器，可以使用 JavaScript 回退：

```javascript
// 检测支持性
if (!CSS.supports('selector(:has(*))')) {
  // 使用 JavaScript 实现类似功能
  document.querySelectorAll('.card').forEach(card => {
    if (card.querySelector('.badge')) {
      card.classList.add('has-badge');
    }
  });
}
```

## 性能注意事项

### ⚠️ 避免在 :root 或 body 上使用

```css
/* ❌ 性能差的写法 */
:root:has(.dark-mode) { }
body:has(.modal) { }
```

这些选择器会强制浏览器在每次 DOM 变化时重新评估整个文档。

### ✅ 性能好的写法

```css
/* ✅ 限定在更具体的容器内 */
.sidebar:has(.collapsed) { }
.modal-backdrop:has(.modal) { }
```

### 性能优化建议

1. **限制范围**：在更具体的父元素上使用 `:has()`
2. **避免复杂选择器**：`:has()` 内部的选择器越简单越好
3. **避免嵌套**：`a:has(b:has(c))` 性能很差
4. **考虑静态替代**：如果可能，使用 class 或 data 属性

## 与 jQuery has() 的对比

| 特性 | CSS :has() | jQuery :has() |
|------|-----------|---------------|
| 语法 | `parent:has(child)` | `parent.has(child)` |
| 权重 | 继承父元素权重 | 固定权重 |
| 性能 | 浏览器原生优化 | JavaScript 实现 |
| 动态更新 | 依赖 CSS 渲染引擎 | 需要手动触发 |

## 常见用法汇总

```css
/* 购物车有商品时显示数量 */
.cart:has(.item) .badge { display: flex; }

/* 侧边栏有折叠项时显示指示器 */
.aside:has(.collapsed) .toggle { visibility: visible; }

/* 表单有错误时高亮整个表单 */
.form:has(.error) { border-color: #ef4444; }

/* 列表有选中项时启用批量操作 */
.list:has(.selected) .bulk-actions { display: flex; }
```
