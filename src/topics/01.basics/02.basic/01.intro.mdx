# CSS 基础语法

**讲解 css 中涉及的基础概念**

-----

## css 基本格式

```css
p {
	color:red;
}
```

一条 css 规则包含如下几部分
* **选择器** 为上面的 p 标签
* **申明** 采用 `<property>:<value>;`的格式,设置选择器匹配元素所应用的规则
  * **属性** `color` 为设置 p 标签的颜色
  * **值** `red` 为设置的颜色

> css 的重点就是属性的学习
