# CSS 属性分类参考

## 定位属性

### 视窗平面定位属性

这些属性决定了元素在视窗中的位置：


| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `position` | 定位方式 | `static`, `relative`, `absolute`, `fixed`, `sticky` |
| `top` | 距离顶部距离 | `10px`, `50%`, `auto` |
| `right` | 距离右侧距离 | `10px`, `50%`, `auto` |
| `bottom` | 距离底部距离 | `10px`, `50%`, `auto` |
| `left` | 距离左侧距离 | `10px`, `50%`, `auto` |


```css
.positioned {
  position: absolute;
  top: 50px;
  left: 100px;
}
```

### 垂直定位属性

决定了元素在 z 轴的层叠次序：

| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `z-index` | 层叠顺序 | `0`, `1`, `999`, `-1` |

```css
.modal {
  position: fixed;
  z-index: 1000;
}
```

### 裁剪属性

决定了定位后的元素若溢出包含块，溢出区域的处理问题：

| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `clip` | 裁剪区域（已废弃） | `rect(0, 100px, 100px, 0)` |
| `clip-path` | 裁剪路径 | `circle(50%)`, `polygon(...)` |

## 布局属性

### 元素显示特性属性

这些属性决定了元素以何种模型进行显示：

| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `display` | 显示类型 | `block`, `inline`, `flex`, `grid`, `none` |
| `visibility` | 可见性 | `visible`, `hidden`, `collapse` |
| `overflow` | 溢出处理 | `visible`, `hidden`, `scroll`, `auto` |
| `overflow-x` | 水平溢出 | `visible`, `hidden`, `scroll`, `auto` |
| `overflow-y` | 垂直溢出 | `visible`, `hidden`, `scroll`, `auto` |

```css
.container {
  display: flex;
  overflow: hidden;
}

.hidden-element {
  visibility: hidden;
}
```

### 元素排布特性属性

决定了元素以何种方式进行对齐：

| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `float` | 浮动方向 | `left`, `right`, `none` |
| `clear` | 清除浮动 | `left`, `right`, `both`, `none` |

```css
.sidebar {
  float: left;
  width: 200px;
}

.clearfix::after {
  content: "";
  display: block;
  clear: both;
}
```

## 尺寸属性

### 宽度属性

| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `width` | 宽度 | `100px`, `50%`, `auto` |
| `min-width` | 最小宽度 | `100px`, `10em` |
| `max-width` | 最大宽度 | `500px`, `100%` |

### 高度属性

| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `height` | 高度 | `100px`, `50%`, `auto` |
| `min-height` | 最小高度 | `100px`, `10em` |
| `max-height` | 最大高度 | `500px`, `100vh` |

```css
.container {
  width: 100%;
  max-width: 1200px;
  min-height: 100vh;
}
```

> 注意：尺寸属性只针对块元素，和以块元素显示的行内元素。

## 外边距属性

| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `margin` | 外边距（简写） | `10px`, `10px 20px`, `auto` |
| `margin-top` | 上外边距 | `10px`, `1em`, `auto` |
| `margin-right` | 右外边距 | `10px`, `1em`, `auto` |
| `margin-bottom` | 下外边距 | `10px`, `1em`, `auto` |
| `margin-left` | 左外边距 | `10px`, `1em`, `auto` |

```css
.centered {
  margin: 0 auto; /* 水平居中 */
}

.spaced {
  margin: 20px 10px; /* 上下20px，左右10px */
}
```

## Flexbox 属性

### 容器属性

| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `display` | 显示类型 | `flex`, `inline-flex` |
| `flex-direction` | 主轴方向 | `row`, `column`, `row-reverse` |
| `flex-wrap` | 换行设置 | `nowrap`, `wrap`, `wrap-reverse` |
| `flex-flow` | 方向和换行（简写） | `row wrap` |
| `justify-content` | 主轴对齐 | `flex-start`, `center`, `space-between` |
| `align-items` | 交叉轴对齐 | `flex-start`, `center`, `stretch` |
| `align-content` | 多行对齐 | `flex-start`, `center`, `space-around` |
| `gap` | 间距 | `10px`, `10px 20px` |

### 项目属性

| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `flex` | 弹性（简写） | `1`, `0 1 auto`, `none` |
| `flex-grow` | 放大比例 | `0`, `1`, `2` |
| `flex-shrink` | 缩小比例 | `1`, `0` |
| `flex-basis` | 基础大小 | `auto`, `100px`, `50%` |
| `align-self` | 单独对齐 | `auto`, `center`, `flex-end` |
| `order` | 排序 | `0`, `1`, `-1` |

```css
.flex-container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 20px;
}

.flex-item {
  flex: 1;
}

.flex-item--featured {
  flex: 2;
  order: -1;
}
```

|------|------|----------|
| `display` | 显示类型 | `grid`, `inline-grid` |
| `grid-template-columns` | 列定义 | `1fr 2fr`, `repeat(3, 1fr)` |
| `grid-template-rows` | 行定义 | `100px auto`, `repeat(2, 1fr)` |
| `grid-template-areas` | 区域定义 | `"header header" "sidebar main"` |

| `align-content` | 容器垂直对齐 | `start`, `center`, `space-around` |

### 项目属性

| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `grid-column` | 列位置（简写） | `1 / 3`, `span 2` |
| `grid-row` | 行位置（简写） | `1 / 3`, `span 2` |
| `grid-area` | 区域位置 | `header`, `1 / 1 / 2 / 3` |
| `justify-self` | 单独水平对齐 | `start`, `center`, `stretch` |
| `align-self` | 单独垂直对齐 | `start`, `center`, `stretch` |

  display: grid;

## 过渡和动画属性

### 过渡属性

| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `transition` | 过渡（简写） | `all 0.3s ease` |
| `transition-property` | 过渡属性 | `all`, `opacity`, `transform` |
| `transition-duration` | 过渡时间 | `0.3s`, `300ms` |
| `transition-timing-function` | 过渡函数 | `ease`, `linear`, `cubic-bezier(...)` |
| `transition-delay` | 过渡延迟 | `0s`, `0.1s` |

### 动画属性

| 属性 | 描述 | 取值示例 |
|------|------|----------|
| `animation` | 动画（简写） | `slideIn 1s ease-in-out` |
| `animation-name` | 动画名称 | `slideIn`, `fadeOut` |
| `animation-duration` | 动画时间 | `1s`, `500ms` |
| `animation-timing-function` | 动画函数 | `ease`, `linear` |
| `animation-delay` | 动画延迟 | `0s`, `0.5s` |
| `animation-iteration-count` | 播放次数 | `1`, `infinite`, `3` |
| `animation-direction` | 播放方向 | `normal`, `reverse`, `alternate` |
| `animation-fill-mode` | 填充模式 | `none`, `forwards`, `backwards` |
| `animation-play-state` | 播放状态 | `running`, `paused` |

```css
.fade-in {
  opacity: 0;
  transition: opacity 0.3s ease-in-out;
}

.fade-in.active {
  opacity: 1;
}

@keyframes slideIn {
  from { transform: translateX(-100%); }
  to { transform: translateX(0); }
}

.slide-animation {
  animation: slideIn 0.5s ease-out forwards;
}
```

## 属性继承性

### 可继承属性

这些属性会自动从父元素继承到子元素：

- 所有字体相关属性（`font-family`, `font-size`, `font-weight` 等）
- 所有文本相关属性（`color`, `text-align`, `line-height` 等）
- `list-style` 系列属性
- `cursor`
- `visibility`

### 不可继承属性

这些属性不会自动继承：

- 所有盒模型属性（`width`, `height`, `margin`, `padding`, `border` 等）
- 所有定位属性（`position`, `top`, `left` 等）
- 所有背景属性（`background` 系列）
- 所有布局属性（`display`, `float` 等）

### 强制继承

可以使用 `inherit` 关键字强制继承：

```css
.child {
  border: inherit; /* 继承父元素的边框 */
  margin: inherit; /* 继承父元素的外边距 */
}
```
